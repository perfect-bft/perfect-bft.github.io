## 2.在管理端设备管理添加设备

<div class="img-hover-container">

![余位显示屏配置说明](../img/toll-space-display-04.png)

</div>

1. 设备类型选择：**显示屏—LKF**
2. 添加板卡的ip：192.168.0.111
3. **勾选余位显示屏功能**
4. **其他的信息全部由软件这边默认好的不用修改**
