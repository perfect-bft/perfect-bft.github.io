第四步：运行代码删除图片
打开包代码：ossutil ls oss://xjyboss
回车后按 ctrl+C 结束
然后输入删除代码清理图片
删除代码：ossutil rm oss://xjyboss  --min-age 168h -r
168h=7天，这条代码的意思删除数据只保留7天的图片
