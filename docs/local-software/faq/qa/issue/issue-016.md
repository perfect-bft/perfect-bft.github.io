我们一般会遇到软件在使用中提示这种情况，提示检查数据库配置，这种的话都是数据库没有启动的

解决方法：左键点击电脑此电脑。找到管理。点击进去。找到服务和应用程序，点击进去，然后点击服务，，在里面输入mysqlcx就会找到我们软件的默认数据库点击启动就好了
