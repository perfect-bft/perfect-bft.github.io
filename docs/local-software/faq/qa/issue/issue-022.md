软件升级的方式：

## 收费软件：

![图片](../../img/faq-issue-022-01.png)

点下系统设置里面选择关于然后点击强制更新

![图片](../../img/faq-issue-022-02.png)

点了确认升级之后会出现一个进度条

![图片](../../img/faq-issue-022-03.png)

进度条满了之后会出现一个安装界面

![图片](../../img/faq-issue-022-04.png)

![图片](../../img/faq-issue-022-05.png)

点击立刻安装选择是，然后重新登录就升级完成了

## 管理软件：

![图片](../../img/faq-issue-022-06.png)

点击左下角系统设置

![图片](../../img/faq-issue-022-07.png)

管理软件安装的时候这个安装数据库的勾选要取消  然后立即安装即可

![图片](../../img/faq-issue-022-08.png)
