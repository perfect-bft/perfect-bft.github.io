设备连不上软件，报错值不能为 null

这种情况是管理端这里加密模式选择了自定义 然后没有填写密钥就会报错收费端连不上设备 报错值不能为null，改成不加密就行了，或者加密过的相机的话，把密钥填写进去然后重启一下收费端软件​
