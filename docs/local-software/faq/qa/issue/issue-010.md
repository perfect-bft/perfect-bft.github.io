一位多车说明书配置
比如一位业主2台车：粤BD1111和粤BD2222

添加第一台车粤BD1111 车位组设置：A栋6楼  车位数：1

添加第二台车粤BD2222 车位组选择：A栋6楼  车位数：1

这样就是一位2车设置  可以查到车位组下面的车辆信息

车位组相当于一个虚拟名称随便定义一个名称

车位数量就是有多少个车位

如果上面车位数设置成2个这样就相当于2位2车

如果3车1位的话在添加一台车粤BD3333 车位组就选择：A栋6楼车位数量就设置 1个

一位多车两种模式

简单模式：
管理端车类管理里面，勾选车位占用简单模式的。假如AB两车一位，A车进来是月卡
B车进来是临时  A车出去了
B车还是临时车会一直计费，B没出场的时候，A车再进来还是月卡车，B车出场的时候会收取从入场时间到出场时间的全部费用

��杂模式：
同样的AB两车，A进场月卡，B进场临时，A出场的时候B就会转换成月卡，A再进场时候A就是临时，这种模式下可能会出现两个车都收费的情况，但是只会计算同时在场的费用，只有一台车在场的时候肯定是月卡车不会计费的

单车计费模式：
AB为1位2车   A进入车场为月卡车 B临时车进入   A车出场时，B停止计费 但是不转为月卡车    A车再入场 A车为月租车 B又开始计费  就是A B车始终只会有一个车产生费用
