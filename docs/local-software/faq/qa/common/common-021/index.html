3.1.11.21 录入车牌长度增加

车辆管理中添加车牌号码，录入车牌长度不够。

1.使用工具（没有请联系售后）连接数据库，修改参数​

2.双击车场对应的数据库，在右侧搜索employeeplate，右键，设计该表​

3.将PlateNo的长度改成50,并保存​

4.重启数据库服务​

5.重启管理端，就可以增长车牌长度了​
