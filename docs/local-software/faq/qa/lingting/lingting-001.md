一、商户登陆会生活pc端
1网址：https://mch-web.tianquetech.com/login
2点进去后来到登陆页面

![图片](../../img/faq-lingting-001-01.png)

3账户密码登陆：请支付时，审核通过后，会自动向您给的联系人手机号发送短信，短信里面有对应账号密码
手机验证码登陆：输入签约人的手机号，获取验证码后，点击登陆在选择对应的商户登陆进去

![图片](../../img/faq-lingting-001-02.png)

4然后点击账户信息

![图片](../../img/faq-lingting-001-03.png)

5最后点击下载

![图片](../../img/faq-lingting-001-04.png)
