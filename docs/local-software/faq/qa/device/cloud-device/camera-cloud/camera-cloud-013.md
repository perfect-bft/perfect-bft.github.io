#### 相机接线注意事项：

485接线要接A2B2不然不会显示和播报哦

![图片](../../../../img/faq-camera-cloud-013-01.png)

## 相机配置
### 1找到售后人员或者相机厂家要到相机搜索工具

![图片](../../../../img/faq-camera-cloud-013-02.png)

### 2 进入工具后，点击搜索设备，搜索出附近所有的在线设备

![图片](../../../../img/faq-camera-cloud-013-03.png)

### 3在浏览器里输入相机的ip登陆
相机默认密码
账户：admin
密码：admin

![图片](../../../../img/faq-camera-cloud-013-04.png)

### 4登陆之后找到高级设置→高级网络→mqqt点击进去进行配置
### 服务器地址：mqda.cxzntc.com（只需要更改这个其他的不需要操作）
## 如果要配置oss储存服务器地址要加http://哦
## 平台配置：
1.在单位管理哪里选择对应的单位点击创建免布线车场
根据提示一步一步创建单位→小区→车场→通道→设备这些
操作如下图：

![图片](../../../../img/faq-camera-cloud-013-05.png)

### 2.在设备管理这里点击新增或者修改通道设备信息
迁里马相机设备类型=相机-TQLM
选择好相机和板卡后把序列号填进去就可以啦
操作如下图

![图片](../../../../img/faq-camera-cloud-013-10.png)

![图片](../../../../img/faq-camera-cloud-013-11.png)
