## 余位屏主板配置

1、服务器器地址添加平台的IP地址：39.108.252.185

2、工作模式选择UDP服务端。

其他的不用改

![图片](../../../../img/faq-yzl-screen-001-01.png)

平台设置
1、车场管理里面设置数据上传，车场管理-更多配置信息

![图片](../../../../img/faq-yzl-screen-001-02.png)

2、在第三方推送配置里面添加

第三方平台：免布线余位屏

第三方接口：随便填个数字

Topic:device/TX/46:FD:9E:4F:AD:1A (红色是主板的ID号）每块主板的ID都不同，前缀都一样。

颜色：文字的显示颜色，0代表红色，1-绿色  2-蓝色  3-黄色 4-青色  5-紫色 6-白色

文字：填写的文字信息会直接显示在余位屏上

是否分区：0代表分区  1-否

其他的不用改

![图片](../../../../img/faq-yzl-screen-001-03.png)
