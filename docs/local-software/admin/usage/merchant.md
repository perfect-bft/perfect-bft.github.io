# 商家优免管理

### A：商户信息

<div class="img-hover-container">

![商家优免管理](../../img/admin-usage-merchant-01.png)

</div>

#### 1.商家信息

点击增加后会出现这个页面

<div class="img-hover-container">

![商家优免管理](../../img/admin-usage-merchant-02.png)

</div>

按照商家名称与地址填写，登陆账户与登录密码则为登录我们商家优免平台的账号密码，（注意黄字内容）可透支金额就是这个商家能在车场这边透支多少钱的意思

#### 2.优免规则

<div class="img-hover-container">

![商家优免管理](../../img/admin-usage-merchant-03.png)

</div>

在软件上只能选择添加按时全免减免规则，需要添加其他的减免规则得在平台上登录我们给您的账号进行添加与修改。
