:::caution 安装前请注意
- 下载后请先**解压** `.rar` 压缩包再运行安装程序（如未安装解压软件，可前往 [7-Zip 官网](https://www.7-zip.org/) 下载）。
- 管理端分 **MySQL 版本**（需先安装 MySQL，详见「管理端 → 1.9 下载并注册管理端」）。
- 收费端首次运行需**配置数据库**（系统已预置默认配置，直接确定即可）。
- 多网卡电脑请注意选择**正确的本机 IP**（详见「收费端 → 2.4 运行收费端 → 查看自己电脑的ip」）。
:::
