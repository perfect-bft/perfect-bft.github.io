软件下载

以下为智慧停车场本地部署软件的安装包（.rar 压缩包，点击卡片即可下载）。

如何选择版本
  • 64 位：适用于 Windows 7 / 10 / 11 的 64 位操作系统（绝大多数现代电脑）。
  • 32 位（Lite 版）：适用于较老的 32 位系统或低配置设备。
  • 不确定系统位数？右键「此电脑」→「属性」即可查看。

安装前请注意
  • 下载后请先解压 .rar 压缩包再运行安装程序（如未安装解压软件，可前往 7-Zip 官网 下载）。
  • 管理端分 MySQL 版本（需先安装 MySQL，详见「管理端 → 1.9 下载并注册管理端」）。
  • 收费端首次运行需配置数据库（系统已预置默认配置，直接确定即可）。
  • 多网卡电脑请注意选择正确的本机 IP（详见「收费端 → 2.4 运行收费端 → 查看自己电脑的ip」）。
