本地软件

智慧停车场本地部署软件的使用说明，包含软件下载、管理端、收费端与常见问题四大部分。

软件下载​

本地部署软件安装包（管理端 / 收费端，含 64 位与 32 位 Lite 版），点击即可下载 .rar 压缩包。

管理端​

停车场管理后台，用于配置车场基础信息、管理车辆与访客、查询报表与统计、配置用户权限等。

  • 下载并注册：mysql 版本软件安装流程
  • 管理端使用说明：基础信息、车辆信息、访客信息、商家优免、报表查询、统计查询、用户权限、系统设置
  • 常用功能：无感支付开通、电子台账、公众号、电子发票、复杂计费模式、单双号限行、非机动车刷卡

收费端​

岗亭收费客户端，用于车辆进出收费、值班交接、通道设备配置等。

  • 运行收费端：配置数据库、查看本机 IP
  • 收费端使用说明：岗亭收费、代理服务、值班详情、岗亭换班、进出测试、进出记录、系统设置
  • 硬件对接：迪虎语音对讲、余位显示屏、ETC 开通流程

常见问题​

使用过程中遇到的问题汇总，共 200+ 篇，覆盖功能配置、设备对接、支付开票、异常排查等。

  • 常见问题问答文档：无牌车扫码、小程序建场、相机识别异常、账号分配、公告发布等
  • 对接过的支付配置：银联、微信、支付宝等各类支付渠道的对接说明
  • 开票：车主开电子发票、手续费发票申请等
  • 设备相关：相机、岗亭一体机、语音对讲、余位屏等硬件问题

使用前注意​

环境要求
  • 管理端分 MySQL 版本（需先安装 MySQL，见「mysql版本软件安装流程」）
  • 收费端首次运行需配置数据库（系统已预置默认配置，直接确定即可）
  • 多网卡电脑请注意选择正确的本机 IP（见「查看自己电脑的ip」）
