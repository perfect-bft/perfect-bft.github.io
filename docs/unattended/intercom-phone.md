# 对讲话机系统

:::tip 核心功能
对讲话机是车主与管理中心通话的**终端设备**，安装于出入口岗亭或车道旁，支持一键呼叫、远程对讲。
:::

### 主要特性

- **工业级设计**：金属外壳，防暴防破坏
- **高清拾音**：内置高灵敏度麦克风，嘈杂环境清晰通话
- **大音量喇叭**：户外环境也能听清
- **防水防尘**：IP65 防护等级，适合户外安装
- **按键背光**：夜间清晰可见

## 安装规范

### 安装位置

:::tip 推荐安装方式
- **安装高度**：离地 **1.2m ~ 1.5m**，方便车主操作
- **安装位置**：出入口车道侧方，车主无需下车即可触及
- **防护箱**：建议加装防护箱，防雨防晒防破坏
:::

### 接线规范

| 接口 | 接线说明 |
|------|----------|
| 电源 | DC 12V，注意正负极 |
| 对讲卡 | RJ11/RJ45 连接对讲卡 |
| 开闸按钮 | 常开按钮，连接对讲卡输入 |

## 配置步骤

### 云模式配置

1. 话机连接对讲卡
2. 对讲卡插入 4G SIM 卡或连接 WiFi
3. 在云平台添加设备，获取设备编号
4. 话机拨号输入设备编号，完成绑定
5. 测试呼叫功能

### 局域网模式配置

1. 话机连接对讲卡
2. 对讲卡通过以太网连接局域网
3. 在管理平台配置话机 IP 地址
4. 测试呼叫功能

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 无法呼叫 | 网络未连接 / 设备未绑定 | 检查网络状态，重新绑定设备 |
| 听不到声音 | 喇叭故障 / 音量太低 | 检查喇叭接线，调高音量 |
| 对方听不清 | 麦克风故障 / 环境噪声大 | 检查麦克风，调整安装位置 |
| 按键无反应 | 电源故障 / 按键损坏 | 检查电源，更换按键 |
