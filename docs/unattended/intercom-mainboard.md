# 对讲主板规格

> 来源：《对讲主板规格书 V1.0》

用于车场出入口可视对讲、扫码支付、广告轮播的 Linux 系统主板，通常搭配显示屏、对讲卡 / 话机、摄像头组合使用。

## 1. 产品特点

- 采用 Linux 系统架构，更稳定，杜绝卡顿死机。
- 统一的对讲板管理平台，支持批量下发图片及后续批量升级。
- 内置车场显示业务：空闲视频 / 图片轮播、过车图文显示、扫码支付显示。
- 内置中 / 英文万用语音包。
- 支持远程开关闸功能。
- 支持 TCP / HTTP / MQTT 通信方式。
- 支持任意品牌本地摄像头上云。
- 支持可视对讲功能，提供原生云坐席平台直接对讲 / Web 对接 SDK。
- 支持二维码主扫 / 被扫功能。
- 支持有线 / WIFI 方式联网。
- 支持多场景 AI 功能扩展。

## 2. 硬件接口

- 一路 LVDS，最高分辨率支持 **1920×1080**。
- 继电器。
- 网口。
- 5V 供电。
- 一路外部触发按键输入接口。
- 电源接口。
- 喇叭。
- 麦克风。
- TF 卡槽。
- 双 USB。
- 预留 SIM 卡接口。
- 预留 485 接口。

## 3. 基本电性规格

| 项目 | 规格 |
| --- | --- |
| 工作电压 | 12V ±5% |
| 静态电流 | ≤ 5A |
| 工作温度 | -20 ℃ ~ 85 ℃ |
| 功放输出功率 | （规格书未给出） |
| 背光接口电压 | 12V / 5V（跳线帽选择） |
| LVDS 接口电压 | 3.3V / 5V（跳线帽选择） |

## 4. 应用场合

- 车牌识别一体机。
- 商业显示广告机。
- 可视对讲设备机。
- 校园智能报警盒子。
