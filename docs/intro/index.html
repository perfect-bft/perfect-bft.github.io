网站使用方法

欢迎使用资料站！本页教你怎么用这个网站：怎么浏览、怎么搜索、怎么下载、遇到问题去哪找。看完这一页，你就能自己找到 90% 想要的内容。

一、网站有哪些内容​

本站按「栏目 → 分类 → 文档」三级组织，左侧边栏从上到下的栏目是：

栏目里面有什么
首页站点入口与总览
网站公告本页（使用方法）+ 更新公告（置顶）
案例相册现场实拍、安装效果等图文案例
智慧通行设备上云、平台功能（订单/车辆/统计等）教程
本地软件管理端 / 收费端说明，以及「常见问题」汇总
无人值守无人值守相关方案与设置
硬件相关相机、主板、模块、防砸等硬件资料
下载空间工具、固件、资料下载（与硬件相关同级）

想直接找东西，别一层层翻——用下面的搜索最快。

二、怎么浏览（侧边栏导航）​

  • 页面左侧是侧边栏，按上面的栏目逐级展开。
  • 点栏目名可以展开 / 收起；点具体的文档即可查看内容。
  • 每篇文档顶部有面包屑（如 本地软件 > 常见问题），随时点面包屑返回上级。
  • 栏目默认是收起状态（例如「施工相关」就是默认折叠的），点一下标题即可展开，避免侧边栏太长。
  • 当前正在看的文档，在侧边栏里会高亮显示，方便定位。

三、怎么搜索（最常用，重点看这里）​

资料站内置了全文搜索引擎，文档标题和正文都能搜。这是找内容最快的方式。

3.1 打开搜索框​

有两种方式：

  1. 点搜索框：页面右上角的导航栏里有一个「放大镜 🔍」图标 / 搜索框，点一下就打开。

  2. 用快捷键（推荐）：

    • Windows / Linux：按 Ctrl + K
    • macOS：按 Cmd + K

    在任何页面直接按快捷键，搜索框会立即弹出，不用先去点。

3.2 怎么搜​

  1. 在搜索框里输入关键词，比如：
    • 收费端、管理端
    • 上云、C5H 上云
    • 地感防砸、布线
    • 月卡、储值、对账、开票
  2. 输入时会实时过滤出匹配的结果，不用等、不用点搜索按钮。
  3. 用上下方向键选择结果，按 回车 或鼠标点击即可跳转到对应文档。

3.3 中文搜索小技巧​

  • 尽量用 2 个字以上的词，例如搜「收费」比只搜「收」更准；搜「地感防砸」比「防砸」更聚焦。
  • 搜不到时，换个说法再试：比如搜「月卡」不行就试试「固定车」；搜「发票」不行就试试「开票」。
  • 搜索是按词匹配的，输入完整的设备型号（如 C5H、R5L）也能精准定位到对应文档。

3.4 跳过去之后​

  • 点开结果后，目标页面会把你搜的关键词高亮出来，直接就能看到相关内容在哪一段。
  • 如果结果太多，回到搜索框加长关键词或加上设备型号继续缩小范围。

💡 一句话总结：按 Ctrl/Cmd + K → 输入关键词 → 回车，基本都能直接找到。

四、怎么下载软件 / 资料​

  • 本地软件安装包：进「本地软件」栏目，最上方是「软件下载」，提供 64 位 / 32 位管理端与收费端的安装包。
  • 硬件工具 / 固件 / 资料：进「下载空间」栏目，按「工具下载 / 固件下载 / 资料下载」分类获取；其中「施工相关」里有布线图，每张图都能下载原图。

不确定该下 64 位还是 32 位？在「软件下载」页内有「如何选择」说明，或联系管理员确认系统版本。

五、遇到问题去哪找​

优先看 「本地软件 → 常见问题」，已按功能（基础设置、收费、对账、开票等）整理了大量问答，大多数使用问题都能在那里找到答案。

找不到就回到搜索（见第三节），用关键词直接搜，往往比翻目录更快。

六、关注公告与更新​

「网站公告」栏目会持续发布：

  1. 网站使用方法（本页）—— 帮你用好资料站；
  2. 更新公告——软件版本、文档新增与重要变更通知（置顶在栏目顶部）。

建议定期查看，或在有新公告时留意站点提示。

如有内容错误、缺失或建议，欢迎反馈，谢谢！
