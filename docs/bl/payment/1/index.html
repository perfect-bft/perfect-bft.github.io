支付

一、进入方式​

备注

左上角-->支付
注：未提及单元为定制单元或者停用单元

二、我的账户​

特别注意
  • 这里可以看到当天的电子收入，以及支付开通等情况
  • 开通支付流程：支付开通-->未开通-->标准支付（未开通）-->填入进件信息进行进件-->审核-->审核完成「如果未通过原路返回查看原因」
  • 进件完成后，后面有个微信未认证，支付宝审核失败，千万不要管，不要去点

三、商户信息​

提示

一般身份证过期的时候，去更新证件的时候需要查商户号，就在这里查

四、交易订单​

提示

查询车辆交易的订单信息和退款

五、车主发票（车主电子发票）​

提示

查询可开票的车辆以及已经开票车辆

六、手续费发票​

注意

支付开票注意事项：

  1. 乐刷每月10号之后可以申请上月手续费发票，如果遇到节假日，发票数据会延迟至15号之前出来
  2. 申请后乐刷会在1-2个工作日审核，如果审核通过后，等待乐刷开票即可
  3. 开票时间：审核通过后7个工作日内
  4. 后台只能看到最近一年的手续费发票记录，一年前的，请走线下申请

差额开票注意事项：

  1. 开票抬头为：深圳泊链软件有限公司
  2. 仅支持开普票

七、退款明细​

提示

记录退款订单

八、车场日报​

提示

记录每天收支的详细统计

九、提现管理​

注意
  • 提现账单：查询提现的账单
  • 提现明细：可以查到实际上否到卡里，或者打款失败以及失败的原因

十、账户明细​

提示

平台流水的相关信息

十一、账号管理​

提示
  • 账号角色：左上角注册角色，如前台/财务等，添加完毕后，可以点击权限设置对此角色的权限进行授权
  • 注：新添加的角色没有任何权限
  • 账号列表：前面的账号角色是为了控制角色的权限的，这里是就是为了给对应的人添加账号的，例如前面添加了前台的角色，但车场有两个前台，那么我们可以建两个前台的账号，但是角色都可以选择前台这个角色
  • 注：如果添加过程选项不上角色，刷新网页/重新打开这个页面/重新登录
  • 消息通知：这个操作员可以在公众号上面接收电子支付日报

十二、车场上报​

提示

对应的城市对接以及数据上报，下方有支持的接口明细【密码 BL66】

车场上报明细

十三、操作日志​

提示

记录操作员登录后的一些操作记录

十四、支付设置​

提示
  • 退款设置：可以设置退款是否需要审核
  • 提现设置：可以设置提现的方式及周期（标准D+1还是自定义/每月固定某天/多少天提现一次）
