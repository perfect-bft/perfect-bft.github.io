## 三、账号管理
### 1.账号角色
:::tip
- 系统有一个默认创建的角色（**不要删除**）
- 我们常见的情况是需要给岗亭的**保安或者财务**等添加一个只有**部分权限**的角色
- 右上角添加角色，如保安/财务等，添加完毕后，可以点击**角色权限**对此角色的权限进行授权
- **注：新添加的角色没有任何权限**
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/905a98003b_peJ1NIf.png)
</div>
### 2.账号列表
:::tip
- 前面的账号角色是为了控制角色的权限的，这里是就是为了给对应的人添加账号的，例如前面添加了保安的角色，但车场有两个保安，那么我们可以建两个保安的账号，但是角色都可以选择保安这个角色
- **如果添加过程选项不上角色，刷新网页/重新打开这个页面/重新登录**
- 选择消息：这个操作员可以在公众号上面接收到哪些消息通知
- 车场通道：这个操作员可以管理哪些车道，一般是对应云岗亭使用
:::

## 四、平台服务
:::tip
**车场的一些增值服务**
- 纯云服务：授权给服务商，可以设置对应金额，然后服务商可以自行添加纯云车场（**没有这个权限加的车场无法添加相机和无法授权相机**）
- 云值守服务：给值守端通道授权和查询相关情况
- 短信服务：为出入目标车场的车主提供短信服务
- 数据大屏：为集团客户提供数据大屏服务，集车场，车流，财务，时间等各方面数据，便于集中管控和可视化管理
- 商户公众号：商户登录web后台生成固定码，可以设置车主关注公众号之后才可扫描固定码领券
- 小程序收费：为客户定制开发专属小程序，并开通面向车主的收费功能，并包含加手动抬杆和抓拍功能，实现远程操控
- 车场公众号：车场可以自行设置私有公众号的消息推送模板，详情见增值服务配置页面
- 语音购买：车场前端车主需要远程呼叫的时候，己方提供云坐席语音服务，并设置接听人员管理
- 视频VIP服务：主相机播放在线视频、每台相机均在线视频等权限，由相机厂家定义
- 手动车牌识别：车场前端车牌识别有误并发生故障时，提供后台手动车牌识别，确保无人值守的完全闭环。用于车场小程序和app中手动出入场时拍照识别车牌;过期后剩余次数自动失效,不支持续期及退款
- 订单图片存储：车场的进出场订单图片和起落杆图片默认存储1个月，如存储更长时间需购买该增值服务
:::
