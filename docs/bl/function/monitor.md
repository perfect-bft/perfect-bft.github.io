# 车道监控
:::note[作用]
车道监控，可以对指定车道进行抓拍图片或者播放实时视频查看现场情况，也可以操作抬杆、落杆。同时该界面还可以对车主端扫码呼叫进行接听。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/23364bedeb_2024-12-10_185545_7572690.361038214620355.png)
</div>
:::tip
高峰模式
- 默认关闭:识别车辆并判断可进场或可出场时抬杆放行，车辆经过后自动落杆;
- 开启高峰模式:该通道闸杆升起，过车不回落，车辆直接通行;如果触发拦截限制,车辆通行但无法生成入场订单或无法结算在场订单;未支付离场车辆暂不支持追缴功能。
:::
