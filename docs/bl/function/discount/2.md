## 二、参数介绍
### 1. 新增
:::tip
新增商户信息功能说明
一、基础商户信息
- 商户名称（必填）：填写商户名称（海底捞/某某酒店）
- 联系人（必填）：填写商户对接人的姓名。
- 手机号：填写商户联系人的手机号码
- 地址信息：填写商户的实际经营地址。

二、优惠券与费用配置
- 手输额度：是否允许商户手动输入优惠券减免额度，可选「支持 / 不支持」（当前为不支持）。
- 全免券：是否允许商户发放全免类优惠券，可选「支持 / 不支持」（当前为支持）。
- 全免券使用限制：设置全免券的使用规则，如「单次有效 / 多次有效」等（一张全免券可在指定时段内用于同一个车牌的几个订单（车场软件自行判断））。
- 叠加限制：设置商户优惠券与其他优惠的叠加规则，可选「无限制 / 不可叠加」等（一个订单可使用该商户的几张优惠券；以车场“商户设置”的叠加限制优先）。
- 固定码使用：是否允许商户使用固定二维码发券，可选「支持 / 不支持」（当前为不支持）。
- 承担费用：设置优惠券成本的承担方，可选「商户 / 车主或商户」（当前为商户）。
- 商户折扣（必填）：设置商户结算折扣比例，「自定义」模式下可填写具体数值（商户向车场购买券时付费的优惠百分比，可选已设置的固定折扣类型）。

三、其他配置
- 默认备注信息：自定义商户优惠券的使用提示，如「请及时扫码领取优惠，出口无效」。
- 商户自助续费：是否允许商户在平台自助续费充值，可选「支持 / 不支持」（**商户自助续费的额度不支持在线退款**商户登录web后台在“充值明细”页面自助扫码续费；车场可提现该费用）。
- 本地商户号：配置自助续费的支付商户信息
- 无订单发券：是否允许车辆在订单时直接发券，可选「支持 / 不支持」（当前为不支持）。

四、操作按钮
- 确定：保存当前商户信息并创建商户。
- 取消：关闭新增窗口，放弃本次操作。
:::

### 2.续费折扣设置
:::tip
- 折扣类型：对这个折扣规则命名（酒店折扣/商超折扣）
- 折扣区间：某个金额区间对应折扣比例，可以多配置（100-200折扣9折）
注：充值金额精确到0.01，相同额度只对应一种折扣力度;打七五折请输入7.5，支持一位小数
:::

### 3.商户设置
:::caution[注意]
**此为优惠券全局设置功能说明**

一、叠加与时段限制
- 单次停车叠加用券：相同车牌单次停车可用场内各商户的优惠券总量，可选「限制一张」「不限制」等（当前为限制一张），且折扣券不支持叠加。
- 固定时间用券：相同车牌在指定时间段内多次停车可使用场内各商户的优惠券总量，可选「不限制」或自定义数量（当前为不限制）。

二、支付与校验配置
- 券后跳转支付：是否在使用优惠券后直接跳转至支付页面，可选「支持 / 不支持」（当前为支持）。

离场校验：控制出场时对未用券订单的校验规则：
- 无需校验：不校验用券状态（当前选中）。
- 必须用券：未用券的临停订单禁止出场。
- 券后免费离场时间：设置用券后应付金额为 0 元时，可免费离场的时长（单位：分钟，当前为 0 分钟），超时将重新计费。

三、操作按钮
- 确定：保存当前优惠券全局配置并生效。
- 取消：放弃本次修改，关闭设置窗口。
:::

### 4.操作
:::tip
- 编辑：修改商户信息和相关设置
- 账号列表：商户的登录账号列表，可以在内新增多个登录账号【默认会创建一个账号，第一次使用要修改密码】
- 销户：删除商户【**慎用**】
- 发券：给商户充值对应的券类型/数量/有效期/自动发券等
- 退款：充多或者充错，进行退款
- 券明细：券库存明细
:::
