## 二、参数介绍
:::tip
**注：只能看30天一个周期进行查询**

- 流水类型：全部/商户续费/车场续费/回收充值/退款/作废
- 商户类型：储值商户/买券商户
- 商户名称：对应的商户名称
- 操作人：操作员名称
- 操作时间：对应的操作时间
:::
