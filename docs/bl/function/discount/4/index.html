优惠券管理

一、进入方式​

进入方式

点击停车云-->优惠管理-->优惠券管理（如下图）

二、参数介绍​

提示

优惠券管理可以查看默认当天内的使用记录，状态为未使用并且没有绑定车牌号的是没有用券的，这种券会按商户设置回收或者过期后作废。

  • 商户名称：全部商户或者对应的商户名
  • 车牌号：使用优惠券的车牌号
  • 状态：全部状态/未使用/已使用/回收/作废
  • 创建时间：就是发券的时间
  • 编号：订单编号
  • 失效状态：已失效/未失效
    前面的三角点开就可以看到券的详情
