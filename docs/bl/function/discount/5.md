## 二、商户管理
:::tip
**左上角是券的类型和名称**
- 购买：商户配置了可以买券，且**用券方式为储值方式**，商户即可自主购买
- 扫码减免：将券生成一张二维码给车主自行扫码，且**用券方式为储值方式**可以手动输入额度
- 勾选**自动更新**。每次扫完后二维码会变动，等于动态券，但是需要有电脑或者平板
- 车辆减免：电脑直接输入车主车牌进行减免，且**用券方式为储值方式**可以手动输入额度
- 导出打印：可以打印多张纸质优惠券
:::

## 二、固定码管理（宴会模式）
### 1.添加固定码
:::tip
- 固定码名称（必填）：自定义固定码的名称，用于标识该优惠活动，比如「商场免费 2 小时券」「门店专属停车券」。
- 券名称（必填）：从已创建的优惠券列表中，选择该固定码绑定的优惠券类型，可选时长定额减免、金额定额减免、全免券等。
- 单张额度（必填）：选择单张固定码对应的减免额度，和绑定的券类型对应，比如 2 小时、10 元等。
- 支付公司限制：定制功能，选无即可
- 总张数（必填）：设置该固定码可被领取、使用的总次数上限。
- 当日限制：设置单个车牌在一个自然日内，可扫码用券的张数限制，默认无限制。
- 起始日期：设置固定码的生效起始日期时间。
- 结束日期：设置固定码的失效结束日期时间。
- 扫码时段：设置每日可扫码领券的时间范围，比如仅工作日 10:00-20:00 可扫码。
- 生效时段：设置优惠券领取后的使用时间范围，比如领券后 24 小时内有效。
- **费用承担：选择优惠成本的承担方，可选商户或者车主，（如果选择车主，车主就要花钱购买此券）**
:::

## 七、账号管理
:::tip
- 账号角色：右上角注册角色，如前台/财务等，添加完毕后，可以点击**权限设置**对此角色的权限进行授权
- **注：新添加的角色没有任何权限**
- 账号列表：前面的账号角色是为了控制角色的权限的，这里是就是为了给对应的人添加账号的，例如前面添加了前台的角色，但车场有两个前台，那么我们可以建两个前台的账号，但是角色都可以选择前台这个角色
- **注：如果添加过程选项不上角色，刷新网页/重新打开这个页面/重新登录**
:::
