## 二、参数介绍
:::tip
- 车主姓名：储值卡绑定的车主姓名，用于查询车主信息。（张三）
- 储值卡编号：储值卡的唯一标识编号，用于精准定位储值卡。（100002210）
- 有效状态：储值卡当前的有效性状态，用于筛选可用 / 不可用卡片。（有效 / 所有 / 已删除）
- 注册时间：储值卡的注册时间范围，用于按时间维度查询。（2026-01-01 至 2026-03-14）
- 车牌号：绑定储值卡的车辆车牌号，至少输入部分字符即可查询。（京 A12345）
- 储值车车位组：储值卡车辆所属的车位分组，**同一组共用储值额度**（A 区 / 商业住宅组）
- 备注：补充说明信息，用于记录特殊备注或标记。（企业客户储值卡）
- 卡类型：增加储值车的类型
:::
