## 二、参数介绍
:::tip
- 扣费时间：储值车扣费的周期选择
- 车牌号：储值车的车牌号。
- 姓名：储值车的车主姓名
- 扣费来源：车场储值卡/集团储值卡/车位组储值卡
:::

## 三、导出
:::tip
- 导出，点击导出，导出所有储值余额使用记录（如果有筛选就导出筛选之后的记录）
:::
