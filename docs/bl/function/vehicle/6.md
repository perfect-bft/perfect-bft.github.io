## 二、参数介绍
:::tip
- 续费时间：续费的时间段筛查
- 车牌号：对应续费的车牌号
- 姓名：续费的车主姓名
- 操作员：给车辆续费的操作员名
- 流水类型：收入和支出，收入就是车主缴费，支出就是退款
:::

## 三、导出
:::tip
- 导出，点击导出，导出所有储值余额变更记录（如果有筛选就导出筛选之后的记录）
:::
