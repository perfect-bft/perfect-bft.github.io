## 二、参数介绍
:::tip
- 创建时间：套餐创建的时间
- 月卡描述：套餐备注
- 编号：套餐对应的编号

### 新增
**基础配置**
- 名称：月卡套餐的名称，必填项。（商业区月卡 / 住宅区月卡）
- 价格：月卡套餐的收费金额，必填项。（100 元 / 200 元）
- 缴费周期：月卡的缴费时长周期单位，必填项。（日/月/年/次）
- 车辆类型：该月卡适用的车辆类型，必填项。（小型车 / 新能源车 / 大型车）
- 生效区域：月卡可使用的停车场区域，必填项。（全选 / A 区 / B 区）
- 生效类型：月卡的生效时段类型。（全天生效 / 分时段生效）
- 区分节假日：是否区分工作日与节假日的生效规则。（不区分 / 区分）
- 月卡描述：对月卡套餐的补充说明。（含专属车位 / 不限次进出）
- 上架日期：月卡套餐开始可购买的日期，必填项。（2026-03-14）
- 下架日期：月卡套餐停止可购买的日期。（长期 / 2026-12-31） 

**移动配置【配置小程序申请月卡车的相关配置】**
- APP上架：小程序上架月卡供自主申请（上架 / 下架）
- 是否审核：直接通过或者审核通过（是 / 否）
- 上传资料：上传相关资料（身份证 / 行驶证 / 驾驶证 / 住房租赁合同）
- 用户协议：上传月卡申请的用户协议
:::

**折扣设置**

- 月卡套餐：需要做折扣的套餐
- 续费周期：折扣的周期（1~60）
- 优惠方式：（折扣 / 赠送周期 / 自定义金额）
- 折扣：多少折就输入多少数字（打七五折请输入7.5，支持一位小数）
