:::tip[小结]
**内部车不同于月租车，它可以设置成不同的收费类型的固定车，也可以设置成不同类型的免费车，模式相对多元化一些，是为了一些特殊的车场环境使用的车辆类型**
:::

## 二、参数介绍
:::tip
- 姓名：内部车辆车主的姓名，用于精准查询车主信息。例如（李四）
- 手机号：车主绑定的手机号码，用于联系车主或接收通知。例如（138****1234）
- 车牌号：内部车辆的车牌号，可输入部分字符进行模糊查询。例如（京 A12345）
- 有效状态：内部车辆当前的有效性状态，用于筛选可用 / 不可用车辆。例如（所有 / 已失效 / 生效中 / 已删除）
- 车主类别：内部车辆所属的车主分类，用于按类别管理筛选。例如（员工车 / 公务车 / 临时内部车）
- 临期天数：内部车距离到期的剩余天数。例如（30）
- 备注：补充说明信息，用于记录特殊标记或备注。例如（高管专属车辆 / 维修中）
:::
:::caution[特别注意]
车主类别
- 名称：类别的名称。（员工车 / 公务车 / 临时内部车）
- 生效区域：生效的车场 （全选 / 车场 / 地库）
- 是否收费：是/否  **如果选择是，则在计费规则管理里面可以针对这个车型单独匹配一个收费类型**
:::

## 三、新增
:::tip
**若相同时间内车牌同时生效了月卡，内部车多身份时，系统默认以月卡车优先**

- 车牌号：必填项，输入车辆号牌，支持 1-8 个多牌共享时效。例如（京 A12345）
- 车主类别：选填项，为新增车辆归类。例如（员工车 / 公务车 / 临时内部车）
- 有效类型：选择车辆生效的时间类型，包含：  
指定时间：必填，指定一个开始生效时间  
指定天：必填，在已选的指定某一天中生效内部车（可选多个）  
指定周：必填，在已选的每个周的指定日生效内部车（可选多个）  
指定月：必填，仅在已选的指定月份中生效内部车（可选多个） 
- 开始时间：必填项，指定车辆开始生效的日期。例如（2026-03-15）
- 结束时间：必填项，指定车辆失效的日期，可勾选「长期」表示永久有效。例如（2026-12-31）
- **时效：指定时间内的生效规则，默认「不限」，到期后自动转为临时车（长期选项除外）**
- 姓名：选填项，记录车主姓名。例如（张三）
- 电话：选填项，记录车主手机号码，用于通知联系。例如（138****1234）
- 车位：选填项，自定义备注车辆所属车位信息。例如（A 区 008 号）
- 备注：选填项，补充其他说明信息。例如（临时公务车，仅限工作日使用）
:::
