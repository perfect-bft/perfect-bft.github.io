## 二、参数介绍
:::tip
**点击高级搜索**
- 车主姓名：车主的姓名。例如（张三）
- 月卡编号：月卡的唯一编号。例如（300150195）
- 套餐名称：月卡对应的套餐名称。例如（地面月卡 / 地库月卡 / 年费月卡）
- 月卡部门：月卡所属的部门。例如（行政部 / 技术部）
- 车辆类型：车辆的具体类型。例如（新能源车 / 小型车）
- 有效状态：月卡的有效状态。例如（所有 / 有效 / 已删除）
- 注册时间：月卡的注册时间范围。例如（2026-01-01 至 2026-03-13）
- 车位号：车辆对应的车位编号。例如（A012）
- 车辆类别：车辆的类别。例如（A区月租 / B区月租）
- 月卡状态：月卡当前状态。例如（使用中 / 未使用 / 已过期）
- 车牌号：车辆的车牌号，至少输入三位。例如（蒙 B52045）
- 月卡临期天数：月卡距离到期的剩余天数。例如（30）
- 备注：补充说明信息。例如（车主为公司高管）

**右上角标识**
- 申请码/续费/缴费码：下载对应的二维码（申请月租，续费月租，缴费月租）
- 下发到设备：正常情况下，添加月租车会自动下发到相机，但是如果出现网络波动或者离线的情况，可能会导致不能同步
所以，为了保险起见，可以点击下这个按钮
- 批量操作：导入 / 导出 / 删除 / 续费   点击导入会显示模板下载（下方也附了模板下载）
