## 二、参数介绍
:::danger[特别注意]
以下所有设置必须点击底部**确定**才能生效！！！
:::
:::tip
**车场通用设置**
1. 车牌是否可以重复：控制同一车牌能否重复登记。（可以 / 不可以）
2. 月卡过期进场：月卡过期后车辆进场的放行规则。（自动进场 / 人工进场 / 禁止进场）
3. 月卡过期出场：月卡过期后车辆出场的收费与放行规则。（收取临停部分费用 / 按月卡 0 元放行 / 禁止出场）
4. 集团月卡是否互通：集团下属多车场之间月卡是否通用。（互通 / 不互通）
5. 场内新办月卡：在停车场内新办月卡的生效时间。（立即生效 / 下次可用）
6. 场内过期续费：月卡过期后在停车场内续费的生效时间。（立即生效 / 下次可用）
7. 封顶期限：月卡可办理的最长有效期限制。（不限制 / 年底 / 最大月数）
8. 新办 / 续费月卡：办理新卡或续费时是否校验车辆在场状态。（不校验 / 校验）
:::

:::tip
**公众号和月卡续费**
1. 公众号和预付页面续费：控制车主能否在公众号 / 预付页面自助续费。（允许 / 不允许）
2. 续费时修改套餐：续费时是否允许更换月卡套餐。（不允许 / 允许）
3. 过期月卡续费开始时间：过期月卡续费后新有效期的起始时间。（结束时间下一秒 / 当前时间）
4. 月卡续费结束时间：月卡续费后到期时间的计算规则。（准时结束 / 顺延至 24 点）
5. 公众号内修改月卡：是否允许车主在公众号内修改月卡信息。（不允许 / 允许）
6. 私有公众号新建月卡：是否允许在私有公众号内新建月卡。（不允许 / 允许）
7. 公众号内新建月卡是否需要审核：公众号提交新建月卡申请后是否需后台审核。（否 / 是）
8. 新建月卡开始时间：新建月卡的生效时间。（当前时间 / 自定义时间）
9. 新建 / 续费月卡可选周期：新建或续费时可选择的月卡时长范围。（1 个月～60 个月可自定义）
10. 过期后禁止车主操作续费 (天)：月卡过期后多少天内禁止车主自助续费。（不限制 / 0-7 天自定义）
11. 允许月卡续费日期：限制车主可续费的日期范围。（自定义：1 日至 31 日 / 不限制）
:::

## 三、其他设置
:::tip
- 车辆类别：新增月卡车的对应类别，导入的时候可以根据编号导入（主要作用是区分月卡车，以及**月卡车过期后对应的收费规则**）
- 短信/公众号设置：月卡到期短信提醒设置
- 部门设置：新增月卡车的对应部门，导入的时候可以根据编号导入
- **车位组：多位多车用一个车位组（例如一个单位20台车，物业只有10个车位，就把车辆录入到车位组来）**
- 注册选项：公众号注册月卡的时候需要填写的资料，可以自定义
:::
