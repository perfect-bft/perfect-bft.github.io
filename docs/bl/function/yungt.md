# 云岗亭
:::tip
云岗亭是**网页版岗亭收费界面**  
车场员工登录云平台，点击 **“云岗亭”** 可直接进入到岗亭管理页面。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/c0f089600c_2024-12-10_185227_9629510.09430645290614403.png)
</div>
:::danger[特别注意]
1. ZS相机要到 高级设置-->音视频-->编码参数 把**认证**的勾选**去掉**  
2. 登录网站要是 http://m.yima.world/login 切记开头是http,不是https

```text title="平台网址【右侧按钮点击复制】"
http://m.yima.world/login
```

3. 如果浏览器强制https，可以更换360极速浏览器

<DownloadButton href="https://browser.360.cn/ee/">360极速浏览器下载</DownloadButton>

4. 也可以更换火狐浏览器

<DownloadButton href="https://www.firefox.com/zh-CN/">火狐浏览器下载</DownloadButton>
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/c0753ed7b7_ad4fa723-8ef9-4139-9749-4b45c1b3d53c.png)
</div>

:::tip
登录后需**选择**自己要操作的进出口通道，选择播放**本地视频**，设置完成点击弹窗右下角确定即可开始工作。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/d12e694944_2024-12-11_182608_4115130.9928786216848668.png)
</div>
:::tip
- 正常情况下，当前页面无需特殊操作，当有车入场时，会推送进场订单到当前页面，刷新订单列表。当出口识别到车辆并匹配到订单时，会推送出场订单到当前页面，一般车主会选择电子支付，此时无需操作；
- 如果需要收取现金，需操作员点击【收费放行】按钮进行放行。
- 如果需要免费放行，操作员点击【免费放行】按钮进行放行。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/08a1b2b545_2024-12-13_103027_9605620.34232100315408476.png)
</div>
:::tip
异常情况下，车辆入场识别出故障，可点击该车道的【手动出场】按钮，手动操作输车牌生成入场订单来辅助。
:::

:::tip
点击【设置】按钮，选择要管理的车道、全屏显示、或者更改皮肤。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/c25882be04_2024-12-10_185254_7991580.13999421073300444.png)

:::tip
点击【交换班】按钮，操作自己或选择别人换班或下班
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/14c674228e_2024-12-11_182843_3881080.949978531392453.png)

:::warning
如果有特殊情况，员工未正常下班，车场管理员可登录云平台，在统计分析模块下的“上下班记录”页面找到对应上班记录，点击“已签到”，强制签退本班次。每个班次的收费情况在该页面也可以查询。
:::
