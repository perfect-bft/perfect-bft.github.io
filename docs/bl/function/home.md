# 首页
点击顶部的**停车云**按钮就会自动跳转到停车平台的首页（**数据大屏**）。

该页面显示的功能：

- **总收入**（车场总收入，单位：元）
- **空车位**（车场空余车位，单位：个）
- **月卡会员**（车场月卡会员数量，单位：人）
- **优惠券发放**（车场优惠券发出数量，单位：张）
- **访客未处理**（车场访客数量，单位：人）
- **今日收费汇总**（电子支付，现金支付，优惠券减免）
- **在线设备**（相机的在线情况）
- **今日收费排行**（收费员收费排行）
- **进出车辆统计**（今日入场车辆的数量、今日离场车辆的数量、今日在场车辆的数量）
- **入场车辆信息和出场车辆信息**（进出场的通道、时间、车牌号）
- **泊位使用率**（停车位每个小时使用的占比）
- **异常抬杆**（异常抬杆清的通道、时间，收费员、原因）
