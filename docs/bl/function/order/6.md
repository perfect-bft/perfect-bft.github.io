## 二、参数介绍
:::tip
- 事件编号：异常订单编号。
- 事件时间：异常订单出现时间。
- 事件类型：异常订单事件类型。
- 确认类型：确认异常订单车辆要缴费。
- 车牌号码：异常订单车辆号码。
- 关联订单号：异常订单关联的订单编号。
- 进场区域：异常订单车辆进场区域。
- 入场车道：异常订单车辆进入停车场的通道信息。
- 进场时间:异常订单车辆进入停车场的时间。
- 出场区域：异常订单车辆出场区域。
- 出场车道：异常订单车辆出停车场的通道信息。
- 出场时间：异常订单处理出停车场的时间。
- 应收金额(元)：异常订单车辆该缴费金额。
- 已收金额(元)：异常订单车辆实金额。
- 减免金额(元)：异常订单车辆使用优惠券减免的金额。
- 待缴费金额(元)：需要缴费的金额。
- 确认人：异常订单车辆确认人员。
:::

## 三、搜索条件
:::tip
- 事件时间：选择时间范围，查询该时间范围使用的异常订单信息。
- 事件来源：（异常订单来源）选择通道，查询经过该通道的异常订单信息。
- 事件类型：选择事件类型，查询该事件类型的异常订单信息。
- 收费员：选择收费员，查询该收费员处理的异常订单信息。
- 确认人：选择确认人，查询该确认人处理的异常订单信息。
- 车牌号：选择车牌号，查询该车牌号的异常订单信息。
:::
