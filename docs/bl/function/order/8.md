## 二、参数介绍
:::tip
- 订单号：欠费订单的订单号。
- 欠费渠道：平台/第三方
- 订单类型：欠费订单类型。
- 车牌：欠费车辆，车牌号。
- 入场：欠费车辆入场通道名称、时间以及图片。
- 离场：欠费车辆离场通道名称、时间以及图片。
- 停车时长：欠费车辆停车时长。
- 停车费：欠费车辆需要缴纳的停车费用金额。
- 订单状态：欠费车辆订单状态。例如：待支付、已支付等。
- 备注：欠费订单原因备注。
:::

## 三、搜索条件
:::tip
- 更新时间：选择时间段，查询该时间段的欠费详情信息。
- 车牌号：选择车牌号，查询该车牌号的欠费详情信息。
- 状态：选择欠费状态，查询该欠费状态的订单信息。
:::
