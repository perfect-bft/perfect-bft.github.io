## 一、进入方式
:::note
停车云-->订单管理-->减免记录
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/9cf23c3cbf_2024-12-10_190111_1542030.30714970819790377.png)
</div>

## 二、参数介绍
:::tip
- 优惠券编号：使用优惠券的编号。
- 商户名称：发放优惠券的商户名称。
- 车牌号：使用优惠券的车牌号。
- 订单号：使用优惠券的订单号。
- 使用时间：优惠券的使用时间。
- 抵扣额度：优惠券的抵扣额度。
- 停车费总额：使用抵扣额度之后的停车费总额。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/bf01c70cd5_2024-12-10_185944_1147790.8137468715240384.png)
</div>

## 三、搜索条件
:::tip
- 商户名称：选择商户，查询该商户发放的优惠券。
- 车牌号：选择车牌号，查询该车牌号使用的优惠券。
- 使用时间：选择时间范围，查询该时间范围使用的优惠券的订单信息。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/73282fe023_2024-12-10_190327_8765310.6094810887493285.png)
</div>

## 四、导出
:::tip
点击导出，导出查询到所有使用优惠券的订单信息，（如果有筛选就导出筛选之后所有使用优惠券的订单信息）。
:::
