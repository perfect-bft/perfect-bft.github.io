## 一、进入方式
:::caution[进入方式]
点击停车云-->订单管理-->抵扣记录（如下图）
- **充电折扣：主要是用来查询汽车充电桩充电优惠的相关情况**  
- 商超折扣：主要是用来查询商超购物优惠的相关情况 
:::

![Docs Version Dropdown](/img/remote/974c7bdc1d_peFjUUJ.png)

## 二、参数介绍
:::tip
1.车牌号码：抵扣车辆车牌号。例如（蒙B52045）  
2.使用时间：车辆使用抵扣的时间。  
3.订单状态：在场或者离场   
4.订单号：车辆产生订单的订单号
:::

## 三、导出
:::tip
- 导出，点击导出，导出所有的折扣记录（如果有筛选就导出筛选之后的折扣记录）。  
:::
