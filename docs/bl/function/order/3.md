## 二、参数介绍
:::tip
1.时间:抬杆或落杆时间  
2.通道:抬杆或落杆通道  
3.操作原因:抬杆或落杆原因，例如：出场无订单/非机动车  
4.操作类型:抬杆或落杆  
5.备注:备注信息  
6.图片:点击查看可以查看图片。  
:::

## 三、搜索条件
:::tip
**普通搜索**
- 时间范围：选择时间范围，搜索该时间范围内的起落杆记录。
- 收费员：选择收费员，搜索该收费员操作的起落杆记录。  

**高级搜索**  
- 通道：选择通道，搜索该通道的起落杆记录。
- 操作原因：选择操作原因，搜索该操作原因的起落杆记录。
- 操作类型：选择操作类型：搜索该操作类型的起落杆记录。
:::

## 四、导出
:::tip
- 导出（不导出图片），点击导出，导出所有的起落杆记录（如果有筛选就导出筛选之后的起落杆记录）。  
- 导出（包含图片），勾选导出图片再点击导出，导出使用的起落杆记录包含图片（如果有筛选就导出筛选之后的起落杆记录）。
:::
