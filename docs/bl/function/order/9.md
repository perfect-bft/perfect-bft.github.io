## 二、参数介绍
:::tip
- 订单号：欠费订单的订单号。
- 欠费总额：欠费订单，欠费总额度。
- 车牌号码：欠费订单车牌号。
- 车牌颜色：欠费订单车牌号颜色。
- 欠费状态：欠费订单状态。
- 欠费渠道：平台/第三方
- 支付时间：欠费订单支付时间点。
- 备注：欠费订单支付备注。
:::

## 三、搜索条件
:::tip
- 车牌号：选择车牌号搜索该车牌号的欠费订单信息。
- 欠费渠道：选择欠费渠道，搜索该欠费渠道下的欠费订单信息。
- 支付时间：选择时间段，查询该时间段的欠费订单支付详情信息。
:::
