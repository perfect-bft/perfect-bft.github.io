## 二、参数介绍
:::tip
1.车牌号码：在场车辆车牌号。例如（蒙B52045）  
2.车辆种类：车辆种类。例如（月卡车/内部车/临时车）  
3.车辆类型：车辆类型。例如（新能源车/小型车）  
4.入场通道：车辆通过那个通道进入停车场。  
5.入场时间：车辆进入停车场时间。  
6.出场通道：车辆通过那个通道出停车场。  
7.出场时间：车辆出停车场时间。  
8.出场方式：车辆出停车场的方式。例如（人工放行/识别通行）  
9.停车时长：车辆进入停车场之后的时长。  
10.应收金额：未减去减免券的金额。  
11.实收金额：实际收取的金额。  
12.减免金额：使用减免券的金额减免的金额。  
13.结算方式：出场的付费方式（例如：电子预付/现金预付/电子结算等）如下图

## 三、搜索条件
:::tip
高级搜索
- 实收大于：例如：输入1元，点击搜索，搜索实收金额大于1元的订单信息。
- 车辆种类：选择车辆种类搜索车辆订单信息。
- 能源类型：选择车辆能源类型搜索车辆订单信息。
- 结算方式：选择结算方式搜索车辆订单信息。
- 入场通道：选择入场通道搜索车辆订单信息。
- 出场通道：选择出场通道搜索车辆订单信息。
:::
