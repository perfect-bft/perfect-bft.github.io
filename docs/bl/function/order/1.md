## 二、参数介绍
:::tip
1.车牌号码：在场车辆车牌号。例如（蒙B52045）  
2.车辆种类：车辆种类。例如（月卡车/内部车/临时车）  
3.车辆类型：车辆类型。例如（新能源车/小型车）  
4.入场通道：车辆通过那个通道进入停车场。  
5.入场时间：车辆进入停车场时间。  
6.停车时长：车辆进入停车场之后的时长。  
7.入场方式：车辆进入停车场的方式。例如（人工放行/识别通行）如下图。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/775b68946a_2024-12-09_153030_2605000.7475510428738017.png)
</div>

:::tip
8.操作
- 详情：查询该车辆订单详情信息。（包括缴费订单信息/订单号/停车场名称/车辆类型和车辆抓拍照片）如下图
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/f257ed38e2_2024-12-09_153959_9290090.03171087581479981.png)
</div>
:::tip
8.操作
- 车牌矫正：相机识别车牌号出现错误，可以在该功能下修改为正确的车牌号
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/e3571c58bf_2024-12-09_154538_3306800.7671627448909907.png)
</div>
:::tip
9.搜索：  
9.1 输入车牌号搜索车辆。（精确搜索车辆信息）  
9.2 筛选通道，搜索从该通道入场的车辆订单信息。  
9.3 选择车辆类型搜索该车辆类型的车辆订单信息。  
9.4 选择车辆种类搜索该车辆种类的车辆订单信息。
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/5309e09a0a_2024-12-09_160241_2403200.8979411894911394.png)
</div>
:::tip
10.导出：导出在场所有车辆信息（如果有筛选就导出筛选之后在场车辆的订单信息）。  
11.导入：导入车辆信息，导入的请选择Excel文件必须是xls,xlsx等格式（导入模板可以导入界面下载。）
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/08a12d9f4d_2024-12-09_162419_5644990.0765235858734421.png)
</div>
:::tip
12.手动结算：勾选需要结算的订单，再点击手动结算可以人工结算订单，需要批量删除或结算时可以全选订单在点击人工结算。（如下图）
:::
<div class="img-hover-container">
