## 二、参数介绍
:::tip
1.订单编号：缴费订单编号。   
2.交易流水号：缴费订单付款流水号。  
3.退款流水号：缴费订单退款流水号。  
4.支付方式：缴费支付方式，例如现金/免密。  
5.支付通道：缴费支付通道，例如微信/支付宝/余额。  
6.财务类型：缴费收入类型，例如手续费/提现。  
7.交易时间：缴费时间。  
8.金额：缴费额度。  
9.说明：缴费说明。  
:::

## 三、搜索条件
:::tip
普通搜索  
1.支付时间：选择时间范围，查询该时间范围内的缴费记录。  
2.车牌号：选择车牌号，查询该车牌号的缴费记录。  
3.订单号：选择订单编号，查询该订单编号的缴费记录。  
高级搜索  
1.交易流水号：选择交易流水号，查询该交易流水号的缴费记录。  
2.退款流水号：选择退款流水号，查询该退款流水号的缴费记录。  
3.财务类型：选择财务类型，查询该错误类型的缴费记录。  
4.支付通道：选择支付通道，查询该支付通道的缴费记录。  
5.支付方式：选择支付方式，查询该支付方式的缴费记录。  
:::

点击导出，导出查询到的所有缴费记录，（如果有筛选就导出筛选之后的缴费记录）。
