## 收费员月报
:::tip
这里记录着车场岗位员工每月实收金额的情况，选择对应的日期及收费员，下拉菜单栏可以选择对应的日期（以月份为单位）以及员工进行查询；详细记录了当月收费员的工作情况，包括收费金额、收费笔数、收费方式（如现金、电子支付等）等关键数据。这些数据能够直观地反映出车场的收费情况。
:::

## 车场月报
:::tip
车场月报详细记录了车场在每个月内的总收入，包括现金收费、电子支付等不同方式的收费金额，这有助于分析客户的支付习惯，为优化支付方式提供依据。这有助于全面了解车场的经济收益情况。
:::
