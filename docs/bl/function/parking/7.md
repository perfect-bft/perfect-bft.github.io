## 二、参数介绍
:::tip
- 新增：添加通道的时候会自动创建对应的通道码，只有预支付码需要新增（特殊情况：不小心删除了之前的通道码）
- 一键下载：直接打包所有二维码（一键下载的码不对显示通道名称）
- 批量删除：批量删除无效的二维码
- 回收站：误删的一定时间可以找回
- 二维码配置：通用配置，背景颜色/车场名称/客服电话/通道名称
:::
