## 一、储值卡会员设置
:::tip
- 是否允许退款：控制储值卡余额是否可退，可选「不可以」「可以」（默认为不可以）。
- 余额不足时：设置储值卡余额不足时的使用规则：
- 清零再补交：余额扣至 0 后，不足部分另行补交。
- 全额收费：直接按订单全额收费
- 公众号新建：是否允许车主在公众号自助新建储值卡，可选「允许」「不允许」
- 提交：保存储值卡会员配置。
:::
## 二、公众号订单推送设置
:::tip
- 临停车进出场订单消息推送：是否向临停车车主公众号推送进出场通知，可选「允许」「不允许」
- 月卡车进出场订单消息推送：是否向月卡车车主公众号推送进出场通知，可选「允许」「不允许」
- 提交：保存订单推送配置。
:::
## 三、消息推送设置
:::tip
出场无订单：
- **勾选「优先沿用上次出场订单」时，无入场记录的出场将复用上次订单（需通道属性 “无在场订单” 不放行时生效）。**
- 处理方式：无在场订单不放行时的处理策略：
- 车主自助：由车主在小程序处理。
- 管理员处理：由管理员人工干预。
- 无：不做特殊处理（当前选中）。
- **收费：按规则计费放行。**
- 无牌车入场需确认：无牌车入场的确认方式：
- 自动入场：自动放行（当前选中）。
- 管理员确认：需管理员审核。
- **地感判断/ 相机判断：由设备识别判断。**
- 无牌车出场需确认：无牌车出场的确认方式：
- 平台判断：由平台自动判断（当前选中）。
- 地感判断/ 相机判断：由设备识别判断。
- 通道掉线通知：是否在通道掉线时发送告警通知，可选「是」「否」
- 应急呼叫通知：是否在收到应急呼叫时发送通知，可选「是」「否」
- 开 / 关闸通知：是否在道闸开 / 关时发送通知，可选「是」「否」
- 在场无牌车扫码（入场码）：
- 按无牌车入场处理：扫码后按无牌车流程处理
- 按预付查询价格处理：扫码后查询预付价格。
- 提交：保存消息推送配置。
:::
## 四、车场重置设置
:::tip
- 车场重置：可选择重置「访客管理」（来访人员 / 业主管理）数据，重置后不可恢复，需谨慎操作。
- 提交：执行选中项的重置操作。
:::
## 五、订单管理设置
:::tip
- 异常订单：可按更新时间筛选近一年异常订单，执行批量删除操作。
- 减免记录：可按使用时间筛选近一年减免订单，执行批量删除操作。
- 删除：删除选中的异常订单或减免记录。
:::
