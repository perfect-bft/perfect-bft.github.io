## 一、进入方式
:::danger[特别注意]
 如果打开平台没找到**相机管理**那就是车场没有添加**纯云车场**，到**纯云车场管理**里面添加下本车场即可！！
:::
:::note
停车云-->车场管理-->相机管理
:::

## 二、参数介绍
:::tip
- 编辑：可以修改一些参数，例如名称 波特率 485等 **切记，不能修改相机序列号和类型，改了无法上线** 如果确实要修改，就删掉重新加
- 添加辅助：把一台在线的相机转为辅助相机，只支持同类相机（推荐使用相机内部组网） 
- 远程：远程访问相机（部分相机不支持或者未加入对应的云端管理平台） 
- 识别记录：可以查到对应的相机识别记录及图片
- 下发记录：可以查到车牌是否下发了语音播报和开闸  
- 显示主题：MQTT订阅，当相机配置正确的时候不在线，可以点开看看，如果字体是淡黑色的，不是深色的，就要删除相机，重新添加  
:::
