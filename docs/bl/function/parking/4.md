## 二、参数介绍
### 1.新增
:::tip
- 名称：自定义通道名称，用于标识出入口。例如（入口 1、出口 A）
- **所属区域：选择通道归属的车场内部区域，默认车场是外场。例如（内场、A 区）**
- 通道类型：选择通道的业务类型。例如（入口 / 出口 / 车位相机）
- **无在场订单放行：临时车/月卡车/内部车/储值车 可选择 （是 / 否）**
- 出口发放优惠券：自动放行/需要再次识别
- 蓝牙通行：是否启用蓝牙支付放行功能。例如（启用 / 关闭）
- 相机：绑定该通道的识别相机，用于车牌识别。例如（HX / 芊熠 / VZ R 相机）
- LED 卡：绑定对应相机的 会自动选择对应的类型（需先选择相机）
- 监控：绑定通道的监控摄像头，用于视频留存与回溯
- ETC类型：万集/世纪恒通/蚂蚁
- ETC车道编码：ETC设备对应的车道编码
- 环境相机：绑定环境监控相机，用于记录通道周边环境
- 可视对讲：绑定可视对讲设备，用于岗亭与车主远程沟通
- 车尾相机：绑定车尾识别相机，辅助车牌识别与防跟车
- 关联通道开闸：选择关联的通道，实现联动开闸，进出道闸对开模式,指定颜色的车牌进出打开关联通道的道闸（如入口与出口联动）
- 折返自动落杆：车辆折返时的道闸控制规则。例如（落杆 / 不落杆，当前为落杆）
- 说明：补充通道的备注信息，用于记录特殊用途或配置说明  
:::

### 2.显示屏配置
:::tip

一、时段与基础参数设置
- 白天时间段：设置白天模式的起止时间，用于区分昼夜配置。例如（06:00:00 至 21:00:00）
- **音量：分别配置白天 / 夜间的语音播报音量（0~10 级）。例如（白天 5 级，夜间 0 级）**
- 显示屏亮度：分别配置白天 / 夜间的屏幕亮度（0~5 级）。例如（白天 5 级，夜间 5 级）
- 显示屏滚动速度：分别配置白天 / 夜间的文字滚动速度（0~5 级）。例如（白天 5 级，夜间 5 级）

二、语音与显示类型设置
- 语音卡类型：选择语音播报的卡片类型。例如（普通卡 / 万能卡）
- 【入】入场播报：选择车辆入场时的语音提示内容。例如（欢迎光临 / 欢迎回家 / 请通行）
- 【出】出场播报：选择车辆出场时的语音提示内容。例如（一路顺风 / 一路平安）
- 显示屏行数：选择当前通道使用的屏幕类型。例如（双行屏 / 四行屏）

三、闲时 / 过车显示配置
- 闲时 / 过车切换：可分别配置「闲时」和「过车」状态下的显示内容
- 【闲时】第一二三四行广告语信息：自定义屏幕显示文字。例如（欢迎光临、减速慢行）
- 【过车】**临时车/月租车/储值车/内部车**入场**成功/失败**每一行配置对应内容
- 【闲时】第一二三四行广告语信息：自定义屏幕显示文字。例如（一路顺风、减速慢行）
- 【过车】**临时车/月租车/储值车/内部车**出场**支付/成功/失败**每一行配置对应内容
- 字体颜色：设置对应行文字的颜色。例如（红 / 蓝 / 黄）
- 滚动方式：设置文字的滚动方向。例如（从右往左滚动 / 从左往右滚动）
- **【入】余位显示：选择车场余位信息显示的行数。例如（不显示 / 第一行）**
- **【入】是否显示二维码：无牌车入场显示二维码。（是 / 否）**
- 【入】二维码颜色：二维码显示的颜色。例如（红 / 蓝 / 黄）
- 【出】是否播报并显示停车时长：播报停车的时长，粤A12345停车5小时1分钟（是 / 否）
- **【出】是否显示二维码：显示出口支付二维码（是 / 否）**
说明提示：时间默认滚动在第一行，二维码默认显示在第一、二、三行；确定保存后配置生效
:::

### 3.通行限制
:::tip
一、基础范围配置
- 车辆类型标签：切换不同车辆类型进行配置，当前为「月卡车」，还可切换至临时车、无牌车、内部车、储值车、访客车、共享车。
- 可通行套餐：勾选对应的套餐名称即可表示此套餐可以通行此通道

二、可通行时段配置（按周设置）
- 星期选择：选择周一至周日，分别配置每日通行规则。
- 禁止通行：可以设置指定车型不能通行（小型车/大型车

通行限制：
- 限时通行：仅在自定义时段内允许通行
- 全天自动通行：全天允许自动抬杆通行
- **全天禁止通行：全天禁止该类型车辆通行**

通行方式：
- 入场自动抬杆：识别后自动抬杆放行
- 入场人工确认：需岗亭人工确认后抬杆
- 落杆才生成订单：道闸落下后才生成停车订单
- 健康码判断：需校验健康码后放行
- 第三方审核：需第三方系统审核后放行
- 分段时段配置：最多可配置 4 个自定义时段（第一～第四时段），设置起止时间与对应时段通行方式（默认 “不启用”）。
- 不开闸时段：设置指定时间段内道闸不自动抬杆，需人工干预。
:::

### 5.通道设置
:::tip

一、重复识别设置
- 车场识别：控制整个车场范围内同车牌重复识别的规则，可选（不限制/进出限制识别）选限制就填写指定时间间隔。
- 单独通道识别：控制单条通道内同车牌重复识别的规则，可选（不限制/限制识别）选限制就填写指定时间间隔。
- 同车牌重复识别自动开闸 (秒)：设置同车牌在指定时间内重复识别时，自动开闸放行的时间阈值（例如 30 秒）。

二、月卡临期提醒设置
- 月卡临期提醒：选择月卡临期提醒的触发时机，可选「出入」「入口」「出口」或「无提示」
- 临期阈值 (天)：设置提前多少天触发月卡临期提醒

三、相机接线
**此功能主要是配置临时车入场需确认功能的时候，使用遥控器代替鼠标点击**
- in1 口：配置相机输入 1 口的信号类型，可选「遥控器信号」「地感信号」「无」等，并可勾选：
- 忙时确认：车辆繁忙时需人工确认后开闸
- 闲时抬杆：车辆稀少时自动抬杆（当前未勾选）
- in2 口：配置相机输入 2 口的信号类型，可选「遥控器信号」「地感信号」「无」等。
