## 二、车场余位设置
:::tip
### 一、车位满进场设置（核心通行规则）
- 临时车：控制车位已满时临时车的入场权限。例如（可进入 / 拒绝入场 / 人工确认）
- 月卡车：控制车位已满时月卡车的入场权限。例如（可进入 / 拒绝入场 / 人工确认）
- 内部车：控制车位已满时内部车的入场权限。例如（可进入 / 拒绝入场 / 人工确认）
- 储值车：控制车位已满时储值车的入场权限。例如（可进入 / 拒绝入场 / 人工确认）
- 访客预约：控制访客预约车辆的入场审批状态。例如（可申请 / 拒绝申请）
### 二、车位占用属性设置
- 月卡订单：设置月卡车辆是否占用固定车位。例如（占车位 / 不占车位）
- 内部车订单：设置内部车是否占用固定车位。例如（占车位 / 不占车位）
- 预约访客：设置预约访客车辆是否占用固定车位。例如（占车位 / 不占车位）
- 被拦车辆有余位后:车辆在入口因车位满被拦截无法进场，在有余位后，如果车辆仍在入口等待，可选择以下方式放行  
1.需再次识别：车场有余位后，需重新识别车牌才可放行。  
2.自动放行：车场有余位后，自动放行此前因车位满被拦截的入口车辆。  
### 三、余位分配管理
- 是否分配余位：开启余位分配功能，将指定数量的车位分配给特定车型 / 角色。例如（否 / 是）
- 车场车位：当开启余位分配时，设置分配的总车位数量。例如（50）
- 车场余位：当开启余位分配时，设置剩余可用 / 预留的车位数量。例如（0）
### 四、车型车位进场设置
- 车型车位进场设置：控制是否限制特定车型进场。例如（不限制 / 选择车型）

## 三、通行限制
:::tip
### 一、基础通行判断设置
- 月卡通行判断：选择月卡通行权限的判断主体。例如（平台判断 / 相机判断）
- 拦截指定车牌：是否对特定车牌进行拦截（优先级最高，多用于风控场景）。例如（不拦截 / 拦截）
### 二、重复入场限制
- 重复入场限制：控制各类车辆重复入场时的订单处理规则，可选择是否允许进入及订单生成方式：
- 临时车 / 月卡车 / 无牌车 / 内部车 / 储值车：勾选「可进入」后，可选择「重新生成入场订单」或「沿用之前在场订单」
- 注：重复入场订单受「通道管理 — 入口 — 是否存在标记总入口」配置影响  
重新生成入场订单：删掉之前的在场记录，生成新的入场订单  
沿用之前在场订单：此次入场正常抬杆放行，不减余位，不更新之前在场订单的进场时间和图片、通道等信息
### 三、特殊车辆通行规则
- 军警车通行：是否允许军警车通行。例如（允许 / 不允许）
- 通行规则：军警车计费方式。例如（按临时车 / 不限制）
- 使馆领事馆车通行：是否允许使馆领事馆车辆通行。例如（允许 / 不允许）
- 通行规则：使馆领事馆车辆计费方式。例如（按临时车 / 不限制）
- 车型通行：允许通行的车牌类型。例如（蓝牌车 / 新能源 / 未匹配颜色车型）
- 能源车通行：允许通行的能源类型车辆（无牌车必须勾选才能通行）。例如（汽油车 / 新能源车 / 无牌车）
### 四、访客与月卡多位多车设置
访客申请：访客预约相关配置：  
- 提前预约 / 入口登记：是否支持及计费规则。例如（不支持 / 支持 / 正常计费 / 免费离场）
- 是否允许多次进出：访客车辆能否多次进出。例如（是 / 否）
- 计费自动放行：是否自动放行计费完成的访客车辆。例如（否 / 自动放行）  
 注：选择自动放行时，访客车将按照现金结算方式结算，费用计入现金  

 月卡多位多车：    
- 通行限制：是否允许一卡多车通行。例如（不允许 / 允许）
- 收费方式：多位多车的计费规则。例如（按月卡处理 / 全程计费 / 场内计费转月卡）
- 人工确认：是否需要人工审核放行。例如（需要 / 不需要）
- 免费时长：免费时长计算规则。例如（按临停时长 / 按停车全程）
### 五、车牌识别匹配规则
入场匹配车牌：  
- 相似字符匹配：识别结果相似字符的处理规则。例如（不处理 / 0/O 匹配 D/0/O 匹配 Q/8 匹配 B / 自定义）
- 模糊匹配：车牌模糊识别的匹配精度。例如（模糊省份 / 模糊省份和任意一位 / 模糊省份和任意两位）

出场匹配车牌：  
- 相似字符匹配：同入场规则
- 模糊匹配：出场模糊识别规则。例如（模糊省份 / 模糊省份和首字母）
### 六、放行与操作设置
- 免费放行：是否允许免费放行。例如（禁止 / 允许）
- 免费原因：是否必须选择免费原因。例如（必选 / 不可选）
- 手动放行原因：手动放行时是否必须选择原因。例如（不选择 / 必选）
- 岗亭现金快捷键：是否启用岗亭现金快捷键。例如（禁止 / 允许）
### 七、黑名单与超时限制
- 允许黑名单离场：允许黑名单车辆离场的车型。例如（蓝牌车 / 新能源）

停车超时禁止入场：
- 可选择临停车 / 月卡车 / 内部车 / 储值车，配置超时停车后禁止入场的规则
- 可新增规则：指定车辆种类、停车超时分钟数、禁止入场分钟数
- 提交：保存所有通行限制配置并生效

## 四、相机断网模式
:::tip

选择断网放行模式：配置相机断网离线时的车辆放行规则
- 默认（部分放行）：仅放行已同步的月卡车、内部车、储值车等固定车辆，其他车辆禁止入场 / 出场。  
当前支持相机：列出当前模式下兼容的相机型号，例如（HX、芊熠、VZ R 相机、宇视 HC121）  
- 先走后付：放行所有车辆，待平台恢复后对未支付订单进行通知追缴。  
当前支持相机：列出当前模式下兼容的相机型号，例如（VZ R 相机）
- 支付后放行（蓝牙）：功能待开放，需配合蓝牙设备实现支付后放行。  
 
注意：需确认车场相机在支持列表内，否则断网模式不生效。  
订单归集规则：断网模式下产生的放行订单，将自动归集至「订单管理 > 欠费订单」，后续按欠费订单逻辑完成支付与结算。  
保存：确认配置后点击保存，使断网模式生效。
:::

## 五、车场内部区域设置
:::tip
- 新增区域：用于添加场中场的小车场区域（大车场默认存在，无需手动添加）。
- 区域编号：内部区域的唯一标识编号，系统自动生成。例如（6545）
- 区域名：自定义区域名称，用于区分不同子车场。例如（内场、A 区、B 区）
- 总车位数：该区域内的总车位数量。例如（100）
- 区域余位：当前区域剩余可用车位数，实时更新。例如（0）
- 多位多车：该区域是否支持一卡多车通行。例如（支持 / 不支持）
- 过期车进场：该区域是否允许过期月卡 / 储值车等车辆进场。例如（不允许 / 允许）
- 集团月卡通行：该区域是否允许集团下属其他车场的月卡车辆通行。例如（不允许 / 允许）

操作：
- 修改：编辑当前区域的配置信息（车位数量、通行规则等）
- 删除：删除该内部区域（需确认无车辆在该区域内）
:::

## 八、车场补缴设置
:::tip

补缴模式选择：配置欠费订单的补缴范围
- 全网补缴：本车场欠费可在其他车场补缴，外场欠费也可在本车场补缴。
- 本车场追缴：本车场欠费仅在本场内补缴，外场欠费不在本场处理（当前选中模式）。
- 集团内车场追缴：仅在集团下属车场之间进行欠费订单追缴。
- 关闭补缴：停止所有欠费订单的补缴功能。

特殊补缴规则配置（可勾选启用）
- 本车场欠费订单强制补缴：强制要求本车场欠费车辆完成补缴后才能通行。
- 三方平台欠费订单强制补缴：强制要求三方平台产生的欠费订单完成补缴。
- 出场疑跟车事件自动补缴：出场时识别为跟车的异常订单自动触发补缴流程。
- 重复入场不产生异常订单：重复入场时不生成异常订单，避免额外计费。
- 重复出场不产生异常订单：重复出场时不生成异常订单。
- 车辆出场停车费未支付产生异常订单：未支付停车费出场时自动生成异常订单，便于后续追缴。
- 本车场欠费订单入口补缴费：允许车辆在入口处完成本车场欠费订单的补缴。

三方联盟助缴：当前已签署三方平台联盟助缴并生效，可借助第三方平台提升欠费订单的补缴率。

备注说明
- 全网补缴：本车场与外场欠费订单可跨场互相补缴。
- 本车场追缴：本车场欠费仅在本场补缴，外场欠费不在本场处理。
- 提交：保存当前补缴配置并生效。
:::

## 十、折返设置
:::tip
- 进口折返处理:取消场内订单,并产生异常订单 / 仅产生异常订单需要人工确认异常订单
- 出口折返处理:取消当前订单,并还原为场内订单 / 仅产生异常订单需要人工确认异常订单
:::
## 十一、车场隐私设置
:::tip
隐私打开后，无牌车入场、场内预付、出场口扫码支付，车场名称将用**替换;公众号与小程序中的停车缴费、月卡续费、储值车充值均需要认证车牌，否则将不展示车牌信息
:::
