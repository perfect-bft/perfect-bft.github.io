计费管理

一、进入方式​

备注

停车云-->车场管理-->计费管理

二、参数介绍​

1.新增-单段计费​

提示

一、基础规则信息

  • 规则名称：必填项，自定义计费规则的名称，用于标识区分。例如（临停车日间计费、内部车优惠计费）
  • 计费规则：必填项，选择单段计费
  • 车类选择：选择适用的车辆类型。例如（临停车 / 月卡车 / 内部车等）
  • 车型选择：必填项，选择适用的车型。例如（小型车 / 大型车 / 新能源等）
  • 所属区域：选择规则生效的车场区域。例如（车场 / A 区 / 内场等）
  • 区分工作日：设置是否区分工作日与非工作日计费，可点击「非工作日设置」配置节假日规则。例如（不区分 / 区分）

二、进阶收费限制

  • 一天多次进出收费限额：车牌每天多次进出场，只收取设置的最高费用，缴足费用后可免费进出场，不重复计费。设置0元表示该选项不生效
  • 免费时长累计限额：设置当日累计免费停车时长的上限。周期类型（无/自然日/24小时）

三、核心计费配置

  • 收费时段：设置规则生效的时间范围。例如（00:00:00 至 23:59:59，即全天生效） 单价：
  • 每 X 分钟收费 Y 元：基础计费单位，配置每 X 分钟收取 Y 元停车费。
  • 不足 X 分钟免费：设置最短计费时长，小于 X 分钟的部分不收费。 按时段优惠（可选）：
  • 勾选后可配置前 N 分钟内的优惠计费规则：前 N 分钟内，每 X 分钟收费 Y 元。 按时长收费（可选）：
  • 勾选后可配置固定时长收费：前 N 分钟统一收取 Y 元。

四、金额与封顶设置

  • 零头不足 X 元舍去：设置金额舍入规则，不足 X 元的零头部分直接舍去。例如（零头不足 0.5 元舍去）
  • 24 小时内 X 元封顶：设置单日最高收费上限，24 小时内累计费用不超过该金额。例如（24 小时内 30 元封顶）

2.新增-多段计费​

提示

一、基础规则信息

  • 规则名称：必填项，自定义计费规则名称，用于区分不同计费策略。例如（临停车日夜分段计费）
  • 计费规则：必填项，选择「多段计费」模式，支持分时段差异化计费。
  • 车类选择：选择适用车辆类型。例如（临停车 / 月卡车 / 内部车等）
  • 车型选择：必填项，选择适用车型。例如（小型车 / 大型车 / 新能源等）
  • 所属区域：选择规则生效的车场区域。例如（车场 / A 区 / 内场等）
  • 区分工作日：设置是否区分工作日与非工作日，可点击「非工作日设置」配置节假日独立规则。例如（不区分 / 区分）

二、进阶收费限制

  • 一天多次进出收费限额：车牌每天多次进出场，只收取设置的最高费用，缴足费用后可免费进出场，不重复计费。设置0元表示该选项不生效
  • 免费时长累计限额：设置当日累计免费停车时长的上限。周期类型（无/自然日/24小时）

三、多时段配置

  • 时段切换：可配置「时段一」「时段二」等多个收费时段，分别设置不同计费规则。
  • 收费时段：设置当前时段的生效时间范围。例如（00:00:00 至 23:59:59，即全天生效）

单价：

  • 每 X 分钟收费 Y 元：基础计费单位，配置当前时段的计时收费标准。
  • 不足 X 分钟免费：设置当前时段的最短计费时长，小于 X 分钟的部分不收费。

免费与优惠次数控制：

  • 入场只计算一次免费：勾选后，仅在第一个时段计算免费时长，跨时段不再重复计算免费时长（不勾选则第二时段也可享受免费）。
  • 入场只计算一次首优惠：勾选后，仅在第一个时段计算首段优惠，跨时段不再重复计算首段优惠（不勾选则第二时段也可享受首优惠）。

补全规则：

  • 不补全：跨时段时，不将上一时段剩余时长补入下一时段计费。
  • 向前补全：将上一时段剩余时长补入当前时段计费。
  • 向后补全：将当前时段剩余时长补入下一时段计费。

四、优惠与封顶设置 按时段优惠（可选）：

  • 勾选后可配置当前时段内前 N 分钟的优惠计费：前 N 分钟内，每 X 分钟收费 Y 元。

按时长收费（可选）：

  • 勾选后可配置当前时段内固定时长收费：前 N 分钟统一收取 Y 元。

零头与封顶：

  • 零头不足 X 元舍去：设置金额舍入规则，不足 X 元的零头部分直接舍去。
  • 单段 X 元封顶：设置单个计费时段的最高收费上限。
  • 双段 / 多段 X 元封顶：设置多时段组合下的最高收费上限（可选择双段 / 多段模式）。
  • 单次 X 元封顶：设置单次停车的最高收费上限。

3.新增-24小时计费​

提示

一、基础规则信息

  • 规则名称：必填项，自定义计费规则名称，用于区分不同计费策略。例如（临停车日夜分段计费）
  • 计费规则：必填项，选择「24 小时计费」模式，按 24 小时为周期阶梯收费。
  • 车类选择：选择适用车辆类型。例如（临停车 / 月卡车 / 内部车等）
  • 车型选择：必填项，选择适用车型。例如（小型车 / 大型车 / 新能源等）
  • 所属区域：选择规则生效的车场区域。例如（车场 / A 区 / 内场等）
  • 区分工作日：设置是否区分工作日与非工作日，可点击「非工作日设置」配置节假日独立规则。例如（不区分 / 区分）

二、进阶收费限制

  • 一天多次进出收费限额：车牌每天多次进出场，只收取设置的最高费用，缴足费用后可免费进出场，不重复计费。设置0元表示该选项不生效
  • 免费时长累计限额：设置当日累计免费停车时长的上限。周期类型（无/自然日/24小时）

三、24 小时阶梯收费配置

  • 以 1 小时为单位，配置 1~24 小时累计时长对应的累计收费金额。
  • 例如：停车 1 小时收费 0 元，停车 6 小时收费 5 元，停车 24 小时收费 20 元等，可自定义每小时阶梯价格。
  • 不足 X 分钟免费：设置最短计费时长，小于 X 分钟的部分不收费。
  • 零头不足 X 元舍去：设置金额舍入规则，不足 X 元的零头部分直接舍去。

四、超 24 小时计费规则

  • 超过 24 小时：配置停车时长超过 24 小时后的计费方式：
  • 重复以上计费规则 (不计免费时长)：超过 24 小时后，重复套用当前 24 小时阶梯规则，且不再享受免费时长。
  • 每小时收费 X 元：超过 24 小时后，按固定每小时 X 元计费。
  • 每 24 小时收费 X 元：超过 24 小时后，每完整 24 小时周期固定收取 X 元。

提示

5.设置​

提示

车场计费特殊设置功能说明 一、特殊车辆收费设置

  • 特殊车：配置特殊车辆（如军警车、应急车等）的计费规则，可选「收费」或「免费」（当前为收费）。章节6配置
  • 使馆领事馆车：配置使馆领事馆车辆的计费规则，可选「收费」或「免费」（当前为收费）。
  • 新能源车：配置新能源车辆的计费规则，可选「收费」或「免费」（当前为收费）。

二、离场与预付配置

  • 离场时间 (分钟)：设置付费后允许离场的最长时间，超过该时间未离场将重新计费（当前为 15 分钟）。
  • 入场预付 (元)：临时车，入场预付固定金额

三、优惠与抵扣配置

  • 优惠减免金额：选择优惠减免的计算逻辑，可选「不记累积收费金额」或「记累积收费金额」。

仅对多进多出累积计费标准生效

  • 不记累积收费金额：以限额时段内实付金额为累计限额金额
  • 记累积收费金额：以限额时段内应付金额为累计限额金额
  • 场内预付：勾选后允许车主在场内提前支付停车费（当前已勾选）。
  • 外部抵扣：勾选后允许使用外部优惠券、充电减免等方式抵扣停车费（当前未勾选）。
  • 区域车场进出完整记录才计费：勾选后仅在车辆完成区域内完整进出记录时才计费，避免跨区域异常计费，如果不勾选区域订单与其他出口共用。

四、外部抵扣叠加规则 外部抵扣叠加：

  • 充电叠加：勾选后允许充电减免与其他优惠叠加使用（当前未勾选）。
  • 优惠叠加：勾选后允许多张优惠券或多种优惠方式叠加使用（当前已勾选）。

五、备注说明

  • 车主场内预付或使用外部优惠、充电减免等完全抵扣停车费后，在离场时间内不再计费。
  • 使用车场优惠券后的免费离场时间需在商户页面单独设置。
