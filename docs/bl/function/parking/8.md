## 二、参数介绍
:::tip
- 名称：对应车型的名称（大型车/小型车/新能源）
- 匹配颜色：无/黄/蓝/黑/白/纯电绿牌/混动绿牌/纯电黄绿牌/混动黄绿牌/黄牌+学
- 计费折扣：此类型车牌收费折扣 注:打七五折请输入7.5,支持一位小数
- 分配车位：不限制/分配车位数
:::
