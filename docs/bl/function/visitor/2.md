## 二、参数介绍
### 1.新增

:::tip
车场可添加或导入业主信息（手机号唯一），状态“正常”和“禁用”对应来访人员中的“认证”和“非认证”
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/f1f5fc520c_peKX5vD.png)
</div>
### 2. 部门管理

:::tip
部门管理：如果访客来访申请的指定部门，可以给该部门绑定指定的审核人员，审核人员在车场配置的私有公众号里进行审核
:::
