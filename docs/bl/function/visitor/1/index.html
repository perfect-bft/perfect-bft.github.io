来访人员

一、进入方式​

备注

停车云-->访客管理-->来访人员

二、参数说明​

1.生成访客二维码​

提示
  • 提前预约码：适用于来访人员提前预约到某限制进入的车场或小区，扫码提交车牌和预计进出 场时间等信息，平台会将该来访信息调用接口 3.19 下发给车场，车场保存该车牌信息，在指定时段内识别该车牌后开闸放行；
  • 入口登记码：适用于景区等外来车辆需单独登记方可进入的车场，车主到达通道入口，扫码输 入车牌和预计进出场时间等信息，平台会将该来访信息调用接口 3.19 下发给车场指定通道，车场使用该车牌信息生成订单，并将对应通道开闸放行；

车场管理员登录云平台，在“访客管理”模块的“来访人员”页面，可生成访客二维码。可以下载打印该二维码贴在来访人员需要扫码的位置，也可以将该二维码地址链接置于私有公众号内，供车主点击后访问。
注意：入口登记码需要填写访客入口通道编号（通道编号在通道管理中查看）

2.访客设置​

提示
  1. 访客分为认证业主和非认证业主
  • 认证业主：对应“业主管理”中状态为“正常”的业主;
  • 非认证业主：对应“业主管理”中状态为“禁用”的业主;
  1. 审核方式分为平台审核、公众号审核和自动审核
  • 平台审核：访客提交访客申请后，申请状态为“待审批”，同时下发给车场对应状态信息。待管理员到处理后，会再次向车场下发访客申请的状态；
  • 公众号审核:访客在申请来访时，可选择指定的部门，如果该部门绑定了审核人员，则审核人员可以收到到指定公众号（车场私有公众号）的消息推送，对该申请进行审核，审核状态会下发给车场；
  • 自动审核:提交访客申请后，自动审核则状态为“已通过”，同时下发给车场对应状态信息;

3.访客申请​

提示
  • 车场来访人员手机扫描访客二维码（微信、支付宝），输入来访车辆的车牌信息、来访的起止时间等信息，提交即可；
  • 微信可查看访客申请的历史记录；
    注意：验证码功能，需购买短信后才可使用！

三、平台录入访客车辆​

提示

车场也可以手动录入访客车，代替车主录入车辆信息
