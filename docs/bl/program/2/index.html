一码App 车主端使用指南

使用对象

一码App（微信/支付宝小程序同名，也称「一码YiMa」）是面向车主的 C 端小程序/APP，支持停车缴费、去充电、社区服务等功能，实现「一码在手，通行天下」。

一、进入方式​

打开微信或支付宝，搜索小程序【一码App】或【一码YiMa】进入使用。也支持在各大应用市场下载独立 APP。

提示

首次使用建议绑定车牌号；绑定后进出车场、开具发票、查找充电站会更便捷。

二、首页与「我的」页面​

登录后，底部导航为「首页 / 扫码 / 我的」。在「我的」页面可快速进入停车记录、充电记录、开发票、我的桩、社区服务等功能。

功能入口用途
停车记录查询历史停车订单
预约记录查看停车/充电预约
充电记录查看充电订单与明细
开发票申请停车/充电电子发票
我的桩管理家用/蓝牙充电桩
社区服务访客码、成员管理、出入提醒

三、停车缴费​

流程速览

绑定车牌 → 入口扫码进场 → 停车 → 离场选车场 → 在线支付 → 扫码出场

3.1 使用流程​

  1. 进入一码App 首页，确认已绑定车牌（如未绑定，在「我的」→「车辆管理」中添加）。
  2. 到达车场入口，将一码App 生成的二维码对准入口扫码设备，闸机自动开启。
  3. 离场时再次打开一码App，选择对应停车场。
  4. 系统根据停车时长计算费用，在线支付后生成离场二维码。
  5. 在出口扫码设备上扫码，闸机开启离场。
信息

若车场支持「无感支付/先离后付」，绑定车牌并开通免密支付后，出场无需额外操作，自动扣费。

3.2 停车记录与电子发票​

进入「我的」→「停车记录」可查看历史停车记录；进入「我的」→「开发票」可申请电子发票（停车服务 / 汽车充电 / 单车充电 均可开票）。

停车电子发票（一码App 小程序真实界面）​

路径：我的 → 开发票 → 停车服务，找到对应车场后按以下步骤开票。

第一步：选择业务类型与停车场

进入「我的 → 开发票」，选择业务类型（停车服务 / 汽车充电 / 单车充电），在列表中找到需要开票的停车场。

第二步：选择订单并开票

在订单列表中勾选要开票的停车订单，点击「开发票」，查看订单开票状态并确认。

第三步：填写开票信息

选择「企业」或「个人」，填写发票抬头后提交，页面会提示提交结果。

第四步：开票成功并查收邮箱

提交后页面提示开票成功；电子发票会发送到填写的邮箱，前往邮箱即可下载电子发票文件。

警告

目前小程序开票仅支持发送到邮箱，不支持直接保存到微信卡包（开发中）。如长时间未收到，可返回订单页重新输入邮箱获取。

充电电子发票（一码YiMa 小程序真实界面）​

第一步：找到开票订单

进入「我的 → 开发票 → 汽车充电」，在「待开票」列表中选择待开票的充电订单，点击「去开票」。

第二步：填写开票信息

选择「企业」或「个人」，填写名称后点击「提交开票」。

第三步：查看开票历史

开票成功后，在「开票历史」中可看到已开票记录。

第四步：复制发票链接

点击记录进入「发票详情」，复制发票链接到浏览器打开即可下载电子发票文件。

警告

充电业务同样在小程序内开票；与停车发票的区别仅在于「开发票」时选择「汽车充电」业务类型，其余步骤一致。

四、去充电（蓝牙充电）​

蓝牙充电主要用于家桩等无需联网的设备，用户仅需手机开启蓝牙，即可在一码App 小程序上启动/停止充电。

4.1 蓝牙充电完整流程​

4.2 操作步骤​

  1. 打开手机蓝牙：系统会提示「请在您的手机打开蓝牙!」。

  1. 进入「我的桩」：微信扫描充电桩二维码，或在一码App「我的」页面点击「我的桩」。

  1. 添加/搜索设备：点击「添加设备」，小程序会搜索附近的蓝牙充电桩。

  1. 启动/结束充电：设备连接成功后，进入充电主页，点击「启动充电」开始充电；充满后自动停止，也可随时点击「结束充电」手动停止。

  1. 分享给家人朋友：点击「分享充电」，输入对方手机号，即可把充电桩使用权限分享给家人或朋友。

提示

首次使用蓝牙充电桩时，平台会自动绑定设备与当前登录账号；非首次连接可直接启动充电。

五、社区服务（访客码）​

用于给熟人便捷分享门禁或电梯通行权限：

  1. 微信搜索「一码App」进入小程序。
  2. 首页点击「社区」。
  3. 点击「访客码」。
  4. 选择有效期（根据实际情况设置访客可访问时长）。
  5. 点击「分享」发给微信好友，或点击「保存图片」发送给访客。

访客凭该二维码在有效期内即可通行对应门禁/电梯。

只有代理免认证的车场才支持第三方小程序直接跳转一码小程序的停车/充电页面。

七、常见问题速查​

问题处理方法
停车后未生成订单确认车牌已绑定，且车场已接入一码平台；如仍无订单，联系车场管理方核对。
蓝牙充电桩搜索不到检查手机蓝牙是否开启、充电桩是否通电并处于可配对状态。
充电后找不到发票进入「我的 → 开发票 → 汽车充电 → 开票历史」查看，可复制链接下载。
访客码无效确认访客码在有效期内，且访客使用的是正确的二维码。
