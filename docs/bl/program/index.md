# 智慧通行小程序总览

智慧通行场景下主要使用两个小程序：**运营小管家**（面向车场运营方/商户）和 **一码App / 一码YiMa**（面向车主/住户/访客）。

根据你的身份和要处理的事情，直接看对应的说明文档：

| 维度 | 运营小管家 | 一码App |
|------|-----------|---------|
| **使用对象** | 车场管理员、商户、收费员 | 车主、住户、访客 |
| **核心用途** | 车场管理、优惠券发放、设备监控、充电/社区管理 | 停车缴费、去充电、社区服务、访客码 |
| **登录方式** | 云平台创建的员工账号 + 密码 | 微信/支付宝授权登录，需绑定车牌 |
| **典型场景** | 给某辆车发减免券、查看车场当日收入、远程操作抬杆、管理领券屏 | 扫码进出车场、蓝牙充电、开具充电发票、分享访客码 |

## 一句话区分

- **运营小管家 = 车场/商户端**：用来「管理」车场、给车「发券」、看数据。
- **一码App = 车主端**：用来「使用」停车/充电/社区服务，自己缴费、自己充电、分享访客码。

两个小程序账号体系不互通：员工用车场管理员分配的员工账号登录运营小管家；车主用微信/支付宝账号登录一码App。
