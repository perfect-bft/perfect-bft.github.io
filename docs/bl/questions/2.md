:::danger[注意]
- 一. 在平台添加辅助相机，这种方式比较直观，可以直接从平台看到相机的状态和直接远程管理
- 二. 在相机内部联动管理里面组网，这种方式比较方便快捷，缺点就是平台无法看到相机的状态，添加到平台上面会显示离线
- 三. <span style={{ color: "#f44336" }}><b>辅助相机不用接开闸线和485线</b></span>
:::

## 方法二
:::tip
这种方式比较方便快捷，相机离线了也不影响   
这里先介绍VZ相机，后面再介绍HX相机的方式
:::
<span style={{ color: "#f44336", fontSize: '20px' }}><b>VZ相机本地组网</b></span>
1. 打开浏览器，输入主和辅助的相机ip地址，登录后依次打开 高级设置-->联动管理-->**主辅都开启联动模式**-->开启后相机会重启
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/91b7e78970_d99f7b31-0336-441a-93a2-085259c3d805.png)
</div>
2. 重启完成后，在**主相机**的界面操作--><span style={{ color: "#f44336" }}><b>添加相机</b></span>
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/10337bf65b_6d65a07e-58aa-4279-a57b-13748de0f4ee.png)
</div>
3. 搜索相机，然后选择辅助相机的IP，点击**绑定**
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/f3ba8dedad_17104312-abe5-4ceb-9880-42d3887a9881.png)
</div>
4. 绑定后如图所示，会显示辅助相机的ip，但是切记要选择<span style={{ color: "#f44336" }}><b>延迟等待模式</b></span>，然后点确定，如果要解绑，点击Ip后面的❌即可
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/8438535656_d2e3f00a-562e-4e9e-b5f9-325392fc2cd9.png)
</div>

<span style={{ color: "#f44336", fontSize: '20px' }}><b>HX相机本地组网</b></span>   
打开HX相机调试工具，然后对照图片操作
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/86ae2b0478_4fe536e8-fb33-44e0-9396-bf0155139a75.png)
