# 停车Boss

停车Boss 是停车Boss推出的停车场云端管理与运营平台，涵盖 **上云配置、平台功能、微信小程序、常见问题** 四大板块，帮助运维与运营人员快速完成车场上云、日常管理与车主服务。

## 本分组包含

- **1. 上云**：快速创建车场、平台/VZ MQ 上线、公共配置、余位屏上线、系统上线说明。
- **2. 功能说明**：PC 端使用、车辆管理、预约车辆、优惠券、停车Boss无人值守系统，以及常用操作的图文说明（见「4. 常见问题」）。
- **3. 小程序**：微信小程序使用说明（车主端与运营端）。
- **4. 常见问题**：逃费追缴等高频问题处理办法。

## 使用建议

- 首次部署请先阅读「1. 上云」下的各上线说明，按步骤完成车场创建与设备接入。
- 日常管理操作见「2. 功能说明」，遇到界面操作不确定时可对照「4. 常见问题」中的图文说明。
- 车主侧功能请参考「3. 小程序」。
