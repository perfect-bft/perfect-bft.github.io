# 4.5 储值车使用说明

本页介绍储值车的定义、与普通车辆的区别、核心优势、充值方式以及管理员查询储值车信息的流程。

## 什么是储值车

储值车是指在停车Boss系统中预先存入停车费用的车辆。车辆进出停车场时，系统自动从账户余额中扣除停车费，无需每次单独支付。

## 储值车与其他类型车的区别

| 车辆类型 | 计费方式 | 适用场景 |
|---|---|---|
| 储值车 | 账户余额自动抵扣 | 长期停车、企业车辆 |
| 月租车 | 按月缴纳固定费用 | 固定车位租赁 |
| 临时车 | 按次/按时缴费 | 临时访客 |

## 核心优势与充值流程

储值车具有通行高效、减少人工干预、便于统一管理等优势。管理员可在后台为储值车充值，车主也可通过小程序完成自助充值。具体流程可参考下方说明图。
