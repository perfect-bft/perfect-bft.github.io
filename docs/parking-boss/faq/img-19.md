# 4.20 余位相关问题答疑

本页介绍停车场余位计算逻辑、余位显示不准的常见原因，以及通过平台后台、小程序、岗亭端调整余位数量的方法。

## 余位计算逻辑

系统通过入口识别车辆数与离场车辆数之差计算在场车辆数，再用总车位数减去在场车辆数得到剩余车位数。

## 余位显示不准的常见原因

1. 相机漏识别或误识别。
2. 手动开闸、跟车出场等未产生识别记录。
3. 多车场数据未合并计算。
4. 总车位数设置与实际不符。

## 调整余位的方法

- **平台后台**：进入 **车场配置 → 车位配置**，修改总车位数或校准当前在场车辆数。
- **小程序**：管理员可通过小程序实时查看并手动校准余位。
- **岗亭端**：岗亭人员可在收费端进行临时余位调整，确保现场显示屏数据准确。
