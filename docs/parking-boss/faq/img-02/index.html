4.3 小程序添加月卡车

本页介绍如何通过微信小程序端快速为车主新增月卡车，并完成月卡信息绑定。

操作步骤​

  1. 打开小程序，进入 项目管理 → 月卡车管理。
  2. 点击「车主管理」，再点击「添加月卡车」。
  3. 填写用户名称、手机号码、车牌号码、部门、车辆类型、开始/结束时间等信息。
  4. 选择对应的车辆类型与结束时间，点击「保存」完成新增。
