# 4.17 无牌车月租办理方案

本页介绍无牌车辆如何办理月租、绑定二维码以及进出停车场的完整流程。

## 适用车辆

- 未上牌新车
- 两轮/三轮电动车
- 老年代步车等无牌车辆

## 办理流程

1. **新增车辆**：在后台录入车主信息，选择无牌车类型。
2. **绑定车牌/二维码**：为车辆生成专属二维码并绑定。
3. **扫码绑定**：车主通过微信扫描二维码完成绑定。
4. **绑定成功**：系统显示绑定成功提示。
5. **正常停车**：车辆进出时通过扫码识别，按无牌车月租规则通行。
