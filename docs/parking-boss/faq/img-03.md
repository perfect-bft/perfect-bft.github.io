# 4.4 多次进出结算点说明

本页解释车辆多次进出停车场时，计费周期与结算点的计算逻辑及变化原因。

## 为什么要设置结算点

针对车辆在同一天内多次进出的场景，系统需要一个明确的计费周期。通常以 24 小时作为一个结算周期，便于准确计算停车费用。

## 结算点来源依据

- **自然天**：以每日 0 点到次日 0 点为一个结算周期，结算点固定为 0 点。
- **停车 24 小时**：以车辆首次入场时间为起点，到次日同一时间点为一个 24 小时结算周期。

## 结算点变化的逻辑

由于车辆入场时间不固定，如果一直沿用首次入场时间作为结算点，会导致车主的实际结算周期被拉长或缩短。系统会根据新的入场时间动态调整结算点，确保计费公平。
