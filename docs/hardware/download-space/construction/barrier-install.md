# 道闸设备安装

> 来源：《道闸设备安装说明书》V1.0（2024 年 1 月）

## 1. 通道选择和位置定位

首先要确定道闸的安装位置，这会直接影响道闸设备阻拦车辆的效果，需根据每个进出口的现场环境和条件来决定。一般一个车道安装一个道闸，尽量将道闸设备安装在车牌识别设备的后方，这样可增加车道的长度使车头尽量摆正，便于识别相机获得最佳识别效果。

## 2. 道闸安装距离和角度

1. 现场建议制作设备安全岛或者水泥基座（尺寸大小要比道闸底部外形尺寸大小多出约 **100–150 mm**，标准为方形），道闸设备尽量安装在其上，这样可以防止车辆剐蹭箱体，另可防止下雨积水后水蒸气反复侵蚀内部电路和金属部件造成闸机故障。
2. 道闸横向中轴线须与车道边界线垂直，纵向中轴线与车道边界线平行。若车道边界线为非直线，则分别与方形安全岛或基座垂直。
3. 道闸一般在出厂前弹簧拉伸已经调好，安装标准出厂杆子不会有问题，但如果现场杆子锯短后，必须调整弹簧（减少伸缩行程或者拆卸一根），调整后要使杆子起杆和落杆流畅。若起杆杆子发生抖动说明弹簧拉力过大；起杆非常慢甚至不能正常起来则弹簧拉力偏小。

## 3. 车辆检测器和地感线圈的安装

1. 首先察看现场地形、地面材质、车辆动向、被侦测的车辆种类、被侦测的目的、现场是否积水，以及确定甲方的需求。
2. 再依车道宽度、车道限制措施、地下钢筋的干扰、路面铺设的材质、旁边铁门的干扰等，来决定地感线圈的位置、面积、适当的圈数、与闸机机箱引线出孔的位置。
3. 地感线应用横截面大于等于 **0.75 mm²** 的耐高温耐腐蚀的铁氟龙绝缘线，开挖感应线圈的槽孔，至少为线圈外线径之三倍宽。检查地下钢筋的状况（水泥地面），决定埋线之深浅或再加减圈数。
4. 建议典型线圈圈数一览表：

| 线圈周长 | 线圈圈数 |
| --- | --- |
| 3–4 米 | 6 圈 |
| 4–6 米 | 5 圈 |
| 6–10 米 | 4 圈 |
| 10–20 米 | 3 圈 |
| 20 米以上 | 2 圈 |

5. 埋线前，要预留引线长度。埋线时，每一环线要上下紧贴。在环线开始要将两条引线出去时，即要开始缠绕（双绞）越密越好，然后从槽孔进入闸机机箱接入车辆检测器。
6. 封胶时，要充满槽孔内，确保导线不会晃动。同时导线与槽壁以胶隔离，使水不会渗入接触导线。封胶至引线出孔箱的位置为止，并与地面齐平。
7. 车辆检测器接线方法详见其包装内说明书。

## 4. 雷达地感器的安装

1. **确认雷达安装孔位**：根据现场实际情况（是否有安全岛/水泥基座、闸机类型、现场过车情况等）来定位雷达安装位置。水平方向位于侧箱中轴线上，垂直方向据情况而定，距车道地面 **65–85 cm**，雷达中心点水平面离道闸杆下平面 **5–10 cm**。
2. **安装开孔**：使用电钻在闸机侧箱钻一个适用于 M16 的固定孔位，推荐开孔钻头直径为 16 mm。
3. 开孔处做打胶防水处理。雷达接线方法详见其包装内说明书。

## 5. 施工时要点

### 5.1 道闸设备

1. 膨胀螺丝数量正确无漏装，螺母牢固无滑丝现象，底座与地面紧贴，手摇无明显晃动。
2. 道闸与水平面成 90 度垂直，与通道基准线成 90 度角；若地面不平必须用铁片或铁质物品垫平闸机基座，禁用石头、混凝土块或其它，垫平的东西隐藏不能超出闸机底座。
3. 安全岛（若有）必须提前沟通甲方是否贴瓷砖，若贴瓷砖闸机安装位置必须做增高处理，角铁或者水泥垫高，防止积水导致蒸发水蒸气造成电路故障。
4. 内部接线正确牢固，线缆布局整齐整洁规范，捆扎合理，接线子螺丝紧固手拽无脱落。
5. 箱门打开、关闭正常，无障碍物遮挡造成箱门打开角度过小无法检修的情况。
6. 杆体与闸机固定牢固，螺母牢固无滑丝现象，杆体、盖板、闸机紧贴，手摇无明显晃动。
7. 伸缩直杆拉伸接头位置螺丝固定牢固，栅栏杆、广告道闸杆下拉杆拐臂受力正常。
8. 通电后闸机杆体起落平稳，无卡顿无异响，灯带杆灯带亮度正常，栅栏杆折叠正常撑腿落地无异响，广告道闸叶片旋转正常撑腿落地无异响。
9. 闸机自带遥控器使用正常，若遥控器无效立即更换电池或重新在道闸主板上学习。
10. 检查闸机内弹簧拉杆限位螺母和中间调节臂限位螺母是否拧紧。

### 5.2 车辆检测器

1. 接线标准牢固，工作正常，闸机内有卡槽的必须固定在卡槽上，严禁扔地上。
2. 接线完后进行测试，调整灵敏度至正常检测。

### 5.3 地感线圈

1. 切割机开槽横平竖直，开槽长度、宽度、深度标准，埋线绕 5 圈以上，进闸机必须双绞。
2. 开槽布线完毕需回填，必须用水泥回填或者封胶，不得用切槽产生的砂浆回填。

### 5.4 线路

1. 室外走线必须穿 PVC 管，走线横平竖直，管卡间隔均匀且牢固无脱落。
2. 隐蔽工程：线缆需开槽或开挖预埋时，预埋完后拍照片留存。
3. 线缆穿越车道必须用镀锌钢管（抗车碾压）穿线，埋设镀锌钢管后拍照片留存。
4. 取电位置接线标准规范，无乱拉乱接现象。

### 5.5 安全岛

1. 安全岛尺寸精确、横平竖直，外观漂亮，外表面不得有坑洼或裂纹。
2. 安全岛内部敷设线管必须用弯管器进行折弯，禁止用 PVC 弯头。
3. 支模布管后拍照片留存，灌注水泥或混凝土，不得填充渣土废渣。

### 5.6 设备箱

1. 设备箱内部交换机、空开等必须固定在设备板上（若有设备板）。
2. 设备箱内部网线打线标，标明进口、出口、外网等。
