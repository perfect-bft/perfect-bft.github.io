车牌识别设备安装

来源：《车牌识别设备安装说明书》V1.0（2024 年 1 月）

1. 通道选择和位置定位​

首先要确定车牌识别的安装位置，这会直接影响车牌识别效果（准确率），需根据每个进出口的现场环境和条件来决定。一般一个车道安装一台车牌识别一体机，尽量将车牌识别设备安装在道闸前方，这样识别相机无遮挡可获得最佳识别效果。

图 1-1　车牌识别一体机与道闸的典型相对位置——主机位于安全岛中轴线、识别进/出口两端，朝向车道来车方向安装。

2. 辅助相机的选择和安装​

如果车辆驶入车道时方向不固定，比如同时可以左转和右转进场的场景，如果只装一个车牌识别设备则肯定有一个方向角度太大影响识别设备正常识别，这种情况就要考虑安装辅助相机，以保证车头不管从哪边来都可以正常识别、保证准确率。

图 2-1　当车辆左转/右转进出场时，主机只能覆盖一个方向，另一方向须靠辅助相机补位，避免出现识别盲区。

3. 车牌识别相机最佳距离和角度​

识别相机距车头牌照识别最佳距离为 3–3.5 米。安装车牌识别设备时需让车牌识别设备的中轴线和车道边界垂直线有一定的夹角，大概 30–45 度，同时相机的镜头方向可以进行微调，这样可以使相机拍到清晰、完整的图片。

图 3-1　车牌识别相机与车道边界垂直线的夹角控制在 30–45°，到车头牌照的水平距离 3–3.5 米，是识别率与图像质量的常用折中点。

4. 车牌识别相机镜头调整​

  1. 参照第 3 条"车牌识别相机最佳距离和角度"安排调试车辆停在车牌识别前进行调试。
  2. 车牌识别相机镜头可以 360 度微调，在成像调试时确保在视频画面中的车牌保持水平。
  3. 车牌在被识别时，确保图片中车辆位于中间位置且车牌位于中间靠下位置。
  4. 车牌识别后宽度像素过小或者太大都会影响识别效果，车牌宽度在 200–300 像素之间为最佳。

图 4-1　镜头调试时，让车牌水平、整车居中、牌照位于画面中下方区域；图像中车牌宽度像素 200–300 px 为最佳识别区间。

5. 施工时要点​

5.1 车牌识别设备​

  1. 膨胀螺丝数量正确无漏装，螺母牢固无滑丝现象，底座与地面紧贴，手摇无明显晃动。
  2. 车牌识别设备与水平面成 90 度垂直，与通道方向角度合理，相机识别范围内无障碍物遮挡。
  3. 内部接线正确牢固，线缆布局整齐整洁规范，捆扎合理，接线子螺丝紧固、网线水晶头制作规范，手拽无脱落。
  4. 箱门打开、关闭正常，无障碍物遮挡造成箱门打开角度过小无法检修的情况。
  5. 外置相机（若有）和鸭嘴连接牢固、手摇无明显位移，与通道方向角度合理，相机识别范围内无障碍物遮挡，连接的波纹管无破损且长度合适，两端接头拧紧牢固。
  6. 鸭嘴（若有）安装牢固，固定螺丝齐全，手摇无明显位移。
  7. 外置补光灯（若有）安装牢固，手摇无明显晃动和位移，光敏元件朝下，光照角度合适。

5.2 线路​

  1. 室外走线必须穿 PVC 管，走线横平竖直，管卡间隔均匀且牢固无脱落。
  2. 隐蔽工程：线缆需开槽或开挖预埋时，预埋完后拍照片留存。
  3. 线缆穿越车道必须用镀锌钢管（抗车碾压）穿线，埋设镀锌钢管后拍照片留存。
  4. 取电位置接线标准规范，无乱拉乱接现象。

5.3 安全岛​

  1. 安全岛尺寸精确、横平竖直，外观漂亮，外表面不得有坑洼或裂纹。
  2. 安全岛内部敷设线管必须用弯管器进行折弯，禁止用 PVC 弯头。
  3. 支模布管后拍照片留存，灌注水泥或混凝土，不得填充渣土废渣。

5.4 设备箱​

  1. 设备箱内部交换机、空开等必须固定在设备板上（若有设备板）。
  2. 设备箱内部网线打线标，标明进口、出口、外网等。
