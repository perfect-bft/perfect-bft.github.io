# 施工规范与最佳实践

本页汇总车牌识别系统施工过程中常见的安装规范、尺寸要求和调试要点，结合现场图纸与网络资料整理，供工程实施参考。

## 1. 前期勘测与现场安装尺寸

施工前需确认车道宽度、车辆类型、光照条件、取电与网络点位，并依据设备型号确定安装方案。以下是现场安装位置的最低尺寸要求示意：

![现场安装位置最低要求尺寸](/img/sg/sg-dimension-min.webp)

</div>

### 1.1 车道长度与宽度

- 标准车道无弯角时，车牌识别区宜设置在 **4–5 米** 区间段内，保证车头能摆正。
- 路面单个宽度不宜超过 **4.5 米**，建议宽度为 **3–4 米**。
- 单车道（宽度 ≤ 4 米）设备居中安装；双车道需分设两侧，间距 ≥ 1.2 米。

### 1.2 相机安装高度与角度

- 常规场景：摄像头距离地面 **1.5–2.0 米**（小型车为主）。
- 若有大车出入，可提高至 **2.0–2.5 米**。
- 镜头俯角保持 **15°–30°**，与车道中线夹角 **15°–30°** 为佳，避免正对车头造成反光或畸变。
- 识别距离：**3–5 米** 最稳定；车牌在画面中的宽度像素建议在 **120–300 px** 之间。

## 2. 安全岛与基础施工

<div className="doc-img-single">

![车牌识别一进一出效果图](/img/sg/sg-effect-oneinout.jpg)

</div>

### 2.1 安全岛尺寸

- 宽度：若同时放置岗亭，一般为 **1200–1500 mm**；仅安装设备时约 **600–800 mm**。
- 长度：约 **5000–6000 mm**。
- 高度：一般高出地面 **150–200 mm**。
- 浇筑混凝土前必须按图纸固定好预埋管，埋管深度不小于 **0.1 m**；管道走弯处不得折断或变形。
- 支模布管后拍照片留存，灌注水泥或混凝土，不得填充渣土废渣。

### 2.2 基础施工

- 道闸基座建议采用 C25/C30 混凝土浇筑，基础尺寸一般比设备底部外形尺寸多出 **100–150 mm**。
- 养护时间不少于 **7 天**，水平度误差 ≤ 2 mm/m。
- 设备周边应设置防撞立柱，位于安全岛两端边缘延长线上。

## 3. 车牌识别一体机安装要点

1. **安装位置**：优先安装在车道左侧（驾驶员侧），距离道闸 **3–5 米**，确保车辆进入识别区域时车牌能正对摄像头。
2. **固定方式**：用膨胀螺栓或支架固定在混凝土墙体/金属立柱上，支架底部加橡胶垫减震。
3. **防水防护**：户外设备须使用防水机箱，防护等级建议 **IP54 以上**，多雨地区达到 **IP65**。
4. **补光灯**：与摄像头同侧，距离相机 **30–50 cm**，呈 **30°** 角斜射车牌，避免直射镜头过曝。

## 4. 道闸安装要点

1. **安装位置**：道闸应距离出入口边缘 **60–80 cm**，安装在车牌识别设备后方，增加车道长度使车头摆正。
2. **垂直度**：道闸横向中轴线与车道边界线垂直，与水平面成 90°；若地面不平需用铁片垫平，禁用石块。
3. **限位与弹簧**：出厂一般已调好；若现场锯短杆子，需相应减少弹簧行程或拆卸一根，保证起杆/落杆流畅。
4. **防砸配置**：推荐组合为 **地感 + 雷达 + 红外对射** 三重防砸。

## 5. 地感线圈施工规范

![地感线圈现场施工规范](/img/sg/sg-spec-loop.jpg)

</div>

### 5.1 线材与开槽

- 线圈线建议使用直径 **≥ 1.0 mm²** 的铁氟龙耐高温导线（部分规范建议 ≥ 1.5 mm²）。
- 切槽深度一般为 **30–50 mm**，宽度 **4–8 mm**；矩形框四角做 **45° 倒角**，防止尖角破坏线圈。
- 开槽需在坚实路基上进行，避开破损路面、混凝土拼缝、窨井盖、伸缩门导轨等金属干扰源。

### 5.2 绕制与匝数

| 线圈周长 | 推荐匝数 |
| --- | --- |
| 3 米以下 | 根据时间情况，保证电感量 100–200 μH |
| 3–6 米 | 5–6 匝 |
| 6–10 米 | 4–5 匝 |
| 10–25 米 | 3 匝 |
| 25 米以上 | 2 匝 |

- 线圈电感量宜保持在 **80–300 μH** 之间。
- 埋线时每一环线上下紧贴，引线从槽孔进入机箱前需双绞，密度越高越好。
- 封胶需充满槽孔，导线与槽壁以胶隔离，防止渗水。

## 6. 管线布线与接地防雷

![车牌识别一进一出管线敷设图](/img/sg/sg-pipeline-oneinout.jpg)

</div>

### 6.1 强弱电分离

- 强电（220V 电源线）与弱电（网线、信号线）必须分开穿管，间距不小于 **0.3 m**。
- 当电源线采用 PVC/PE 管时，与信号线管间距 ≥ **0.15 m**；采用镀锌钢管时可缩小至 **0.1 m**。

### 6.2 线材与穿线

- 相机至交换机：超五类/六类屏蔽网线（室外用防水线）。
- 相机至道闸开闸信号线：2×1.0 mm² 纯铜线。
- 设备供电线：3×1.5 mm² 电线。
- 室外走线必须穿 PVC 管或镀锌钢管保护；穿越车道须用镀锌钢管抗碾压。
- 线管转弯处弯曲半径不小于管径的 10 倍，避免损伤线缆。

### 6.3 接地与防雷

- 道闸机箱、相机及控制主机必须可靠接地，**接地电阻 ≤ 4 Ω**。
- 接地体可用 50×50 mm 角钢，埋深不低于 **1.5 m**。
- 雷雨多发区域建议安装防雷模块，所有线缆接头做防水绝缘处理。

## 7. 调试与验收

### 7.1 图像与角度校准

1. 登录相机 Web 管理界面或专用客户端。
2. 用测试车停在最佳识别位，微调万向节，使车牌在画面中水平居中、位于图像下 1/3 区域。
3. 车牌像素宽度控制在 120–300 px，车牌区域占画面比例约 1/5–1/4。
4. 开启智能补光，夜间以车牌不反光、不模糊为准。

### 7.2 触发与联动

- 划定识别区覆盖目标车道，避开相邻车道或停放车辆。
- 设置虚拟触发线，车辆车牌压线即触发抓拍。
- 可选“视频流触发”或“外部输入触发”（地感线圈/雷达）。
- 识别成功后道闸延迟 **0.5–1 秒** 开启；车辆通过地感线圈后延迟 **3 秒** 关闭。

### 7.3 实车测试

- 连续通过不少于 **100–200 辆次** 测试，识别率应 ≥ **98%**（部分场景要求 ≥ 99.5%）。
- 分别在晴天、阴天、夜间无光环境测试。
- 必做防砸测试：模拟车辆/物体位于闸杆下方，确认道闸停止下落或自动抬起。
- 测试脱机、断电手动抬杆、收费/语音/显示联动是否正常。

- 点位台账（位置、IP、维护联系人）。
- 隐蔽工程照片（预埋管线、地感线圈、接地装置等）。
- 设备参数配置档案与验收测试记录。
