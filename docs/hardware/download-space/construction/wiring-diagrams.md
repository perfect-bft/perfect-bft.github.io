# 系统布线图

本页汇总停车场/车牌识别系统常用的施工布线图，含一进一出、多进多出、出入口分离、同进同出等典型场景，可作为现场布线、管线预埋和设备定位参考。点击每张图下方的「下载原图」可获取完整分辨率原图。

## 一进一出布线图

最常见的单车道一进一出场景，含电源线、道闸控制线、网线、光纤及地感线圈走向示意。根据现场搭配的显示屏类型，接线方式相同，仅显示屏型号/接口不同。
