## 什么是红外对射防砸

:::tip
红外对射（也叫**红外光栅**）由**发射端**和**接收端**两部份组成，分别装在车道两侧。发射端持续发出红外光束，接收端接收。

当有车辆或行人从中间穿过、遮挡住光束时，接收端收不到光，立即输出一个开关量信号给道闸主板，主板判断"杆下有障碍物"，**停止落杆或立即抬杆**。
:::

## 为什么它比地感线圈更适合防人

| 对比项 | 地感线圈 | 红外对射 |
|--------|----------|----------|
| 检测汽车 | 优秀 | 优秀 |
| 检测行人 | **差**（人体金属量太少） | **优秀** |
| 检测电动车/自行车 | 差 | 优秀 |
| 是否需要破路 | 是 | **否** |
| 安装工期 | 半天以上 | 半小时 |

:::warning
地感线圈靠检测**金属涡流**工作，人体几乎不产生涡流，所以**行人、自行车、木板车从杆下走过，地感是检测不到的**。

任何有人车混行的通道（小区大门、学校、医院、商场地下车库入口），都必须在地感之外**加装红外对射**。
:::

## 类型选择

| 类型 | 结构 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| **对射式** | 发射 + 接收分离，装在两侧 | 检测距离远、稳定 | 两侧都要立柱布线 | 车道、大门 |
| **反射式（一体式）** | 收发一体 + 反光板 | 只需单侧布线 | 距离较短、反光板易脏 | 单侧无法布线的场合 |
| **多光束光栅** | 2~4 束红外 | 覆盖高度大、防钻越 | 成本略高 | 人车混行重点区域 |

## 技术参数

| 参数 | 常见取值 |
|------|----------|
| 工作电压 | DC12V / DC24V（部分支持 AC/DC 宽压） |
| 工作电流 | 发射 30~50mA，接收 20~40mA |
| 探测距离 | 3m / 5m / 10m 等规格，按车道宽度选 |
| 光束数量 | 1 束 / 2 束 / 3 束 / 4 束 |
| 响应时间 | 20~50ms |
| 输出方式 | 继电器干接点 NO/NC/COM，容量一般 1A/30VDC |
| 工作温度 | -25℃ ~ +70℃（户外型） |
| 防护等级 | IP65 及以上（户外必须） |

:::info
选型原则：**探测距离要留余量**。车道宽 4m 就别选标称 3m 的，选 5m 或 10m 的规格，防止余量不足导致边缘检测不稳定。
:::

## 安装规范

### 安装高度（最关键）

| 安装高度 | 效果 |
|----------|------|
| 离地 10~20cm | 容易被地面杂物、积水反射误触发，且扫不到行人腿部以上 |
| **离地 30~60cm** | **推荐区间**，能可靠覆盖行人躯干和车辆底盘 |
| 离地 80cm 以上 | 行人猫腰、儿童、宠物可能漏检 |

:::tip[双光束推荐做法]
人车混行重点通道，建议装**两对**对射：
- 低位：**离地 30cm** —— 防儿童、宠物、低矮物体
- 高位：**离地 60cm** —— 防行人躯干

两对信号**串联（逻辑或）**，任意一对被遮挡都触发防砸。
:::

### 安装位置

- 装在道闸杆**正下方**或稍偏前方（偏前 30~50cm），确保闸杆落下时覆盖的区域在检测范围内
- 两侧立柱要**牢固**，避免车辆刮碰后移位导致光束偏移
- 发射端与接收端必须**严格对准**，可用设备自带的对准指示灯或蜂鸣器判断
- 避免正对**阳光直射方向**（尤其是西晒位置），必要时加遮阳罩

:::danger
- 户外安装必须选 IP65 以上防护等级，进线口朝下并做防水弯
- 镜头表面要**定期清洁**，积灰、结霜、蜘蛛网都会导致误报或不报
- 不要装在空调外机、排风口正对位置，热气流会引起空气折射抖动
:::

## 接线方式

### 端子定义（典型）

| 端子 | 说明 |
|------|------|
| V+ / 12V | 电源正极（DC12V） |
| GND / V- | 电源负极 |
| NO | 继电器常开输出 |
| NC | 继电器常闭输出 |
| COM | 继电器公共端 |

### 与道闸主板连接

:::warning[推荐接常闭 NC]
与地感同理，红外对射的防砸信号建议接**NC + COM**：

- 正常无遮挡时：NC-COM 导通 → 主板认为"通道畅通"，可以落杆
- 有人/车遮挡：NC-COM 断开 → 主板立即停止落杆
- **线路被剪断、设备掉电**：回路断开 → 主板同样停止落杆（故障导向安全）

如果主板只接受常开信号，可以用一个**小继电器做反相转换**。
:::

### 供电注意事项

:::tip
- 红外对射可以和相机、车检器共用一组 DC12V 电源，但要核算总电流
- 距离超过 50m 时，线损会导致电压下降，建议在现场就近取电或提高线径
- 电源纹波大（劣质开关电源）会导致红外接收误判，务必使用正规电源
:::

## 优缺点总结

### 优点

:::tip
- 能检测**行人、非机动车**，这是地感线圈做不到的
- **不需要破路**，改造项目、租赁场地特别友好
- 投入低，性价比高
- 安装调试简单，一个人半小时搞定
- 输出是标准干接点，任何品牌道闸主板都能接
:::

### 缺点

:::warning
- **受天气影响大**：大雨、浓雾、大雪会严重衰减红外光，导致误报
- **强光干扰**：正对太阳、车灯直射可能致盲
- **需要定期维护**：镜头脏污、立柱位移都会失效
- **只能检测一条线**：光束是一条线，光束上方或下方的物体漏检（多光束可缓解）
- 小动物、飘落的树叶、大件垃圾可能误触发导致杆不落
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 一直报警（认为有障碍），杆不落 | 镜头脏污 / 光束没对准 / 阳光直射 | 清洁镜头、重新对准、加遮阳罩 |
| 有人经过不报警 | 高度装错 / 探测距离不够 / 输出线断 | 调整高度、换远距离型号、测通断 |
| 雨雾天频繁误报 | 环境恶劣导致光束衰减 | 调低接收灵敏度（如有）、改用雷达方案 |
| 时好时坏 | 立柱松动 / 接线端子氧化 / 电压不足 | 加固立柱、重新压端子、测末端电压 |
| 设备上电无反应 | 电源极性接反 / 电压不符 | 核对电压、调换极性 |

:::tip[快速验证方法]
用万用表蜂鸣档接在输出 NO-COM 上：

1. 用身体或纸板挡住光束 → 应听到蜂鸣（导通）
2. 移开遮挡 → 应停止蜂鸣（断开）

若遮挡时无任何反应，先确认电源指示灯亮不亮，再检查对准。
:::

## 与其他方案搭配

:::info
- **地感线圈 + 红外对射**：车场主流组合，车靠地感防、人靠红外防，互补性最好
- **红外 + 压力波**：人车混行高安全等级，红外提前防、压力波兜底防
- **不建议单独用红外**：雨雪天气误报率高，单独使用会让道闸经常不落杆，影响通行效率
:::
