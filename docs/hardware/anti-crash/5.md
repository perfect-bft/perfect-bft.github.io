## 什么是压力波防砸

:::tip
压力波防砸是**唯一直接装在闸杆上**的防砸方案，属于**接触式**防护——别的方案都是"提前发现杆下有东西"，压力波是"**砸到了才知道**"，但它知道得足够快，能在造成伤害前让闸杆停止并反弹。

它通常作为**最后一道兜底防线**，和地感、红外、雷达搭配使用。
:::

## 三种实现形式

| 形式 | 原理 | 触发时机 | 特点 |
|------|------|----------|------|
| **气压波（气囊胶条）** | 闸杆底部安装中空橡胶气囊，受压变形 → 管内气压升高 → 气压开关动作 | 接触到物体瞬间 | 最传统，对人和物都有效 |
| **机械压力波（微动开关）** | 胶条内嵌导电橡胶条/微动开关，受压导通 | 接触到物体瞬间 | 结构简单，成本低 |
| **遇阻反弹（数字防砸）** | 检测**电机电流**或**霍尔脉冲**突变判断闸杆受阻 | 落杆受阻、阻力增大瞬间 | **无额外硬件**，靠主板算法 |

## 一、气压波（气囊胶条）

### 结构

:::tip
- **气囊胶条**：中空橡胶管，贴在闸杆**下沿**，长度与闸杆匹配
- **气压传感器 / 气压开关**：装在闸杆端部或机箱内，感应管内气压变化
- **气管**：连接胶条与传感器
- **信号线**：传感器输出开关量给主板
:::

### 工作过程

1. 闸杆下落过程中，胶条碰到车辆或行人
2. 胶条被挤压，内部空气被压缩，气压瞬间升高
3. 气压开关检测到压力变化超过阈值
4. 输出信号给主板 → 主板**立即停止落杆并反向抬杆**

| 参数 | 常见取值 |
|------|----------|
| 触发力 | 3kg ~ 10kg（可调） |
| 响应时间 | 20ms ~ 100ms |
| 胶条材质 | EPDM 橡胶 / 硅胶，耐候 -40℃ ~ +80℃ |
| 胶条长度 | 按闸杆长度定制（3m / 4m / 6m） |
| 输出 | 常开/常闭干接点 |

:::warning[气压波的两个天生缺陷]
1. **滞后性**：必须真的碰到才触发。虽然响应只要几十毫秒，但对行人来说已经有接触感，不如非接触方案体验好。
2. **气压漂移**：气温变化、胶条轻微漏气会让管内基准气压漂移，导致**误触发**（大风、胶条老化时特别明显）。
:::

## 二、机械压力波

:::tip
在胶条内嵌**导电橡胶条**（两个电极，受压接触导通）或沿胶条布置**微动开关**。

- 优点：不受气温影响、不会漏气、成本极低
- 缺点：只有被压到的那一段能触发（点式检测，不像气压波整根联动），需要多布几个点
:::

## 三、遇阻反弹（数字防砸）

### 原理

:::info
道闸电机在**匀速落杆**时，工作电流和霍尔脉冲频率都是**稳定的**。

一旦闸杆受阻（砸到车、被人为托住、被异物卡住）：
- 电机负载突然增大 → **电流上升**
- 或者闸杆速度骤降 → **霍尔脉冲间隔变长**

主板持续采样这两个量，一旦变化超过设定阈值，判定为"遇阻"，立即停止并反向抬杆。
:::

### 优点

- **零硬件成本**：不需要胶条、气管、传感器，纯算法
- **无老化问题**：不像胶条会龟裂漏气
- **安装零工作量**：刷个支持该功能的固件/主板即可
- **可调节**：阻力阈值、反弹高度均可设置

### 缺点

:::warning
- 触发需要先有**一定阻力**，轻触柔软物体（如衣物、小孩）时可能不明显
- 闸杆机械阻力变化（冬天润滑脂变稠、轴承磨损）会被误判为遇阻 → **误反弹**
- 阈值设置不当会频繁反弹导致杆落不下来
- 对**电机和传动机构的一致性**要求高，老旧道闸效果差
:::

### 参数设置

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 遇阻灵敏度 / 电流阈值 | 电流超过多少判定为遇阻 | 先设中等，实测后微调 |
| 反弹高度 | 遇阻后抬起多少 | 抬到垂直位或抬起 30~50cm |
| 反弹次数限制 | 连续遇阻几次后停止并报警 | 3 次 |
| 学习功能 | 首次安装时学习正常运行电流曲线 | **必须执行一次** |

:::danger[新装道闸必做]
更换主板或新装道闸后，**必须先执行一次"电机电流学习"（自学习）**，让主板记住这台电机的正常运行电流和落杆时间。

没做自学习就启用遇阻反弹，几乎必然出现**频繁误反弹**。
:::

## 安装规范（气压波）

:::tip
1. **胶条安装位置**：闸杆**下沿**，用配套卡槽或胶粘固定，必须整根贴合无缝隙
2. **气管走向**：气管沿闸杆走线槽引到机箱，**不能打折、不能压扁**
3. **传感器安装**：装在机箱内干燥处，避免进水
4. **接头密封**：所有气管接头必须插到底并紧固，漏气是误报头号原因
5. **平衡调整**：装了胶条后闸杆重量变化，需要**重新调整道闸弹簧平衡**
:::

:::danger
- 装胶条后闸杆变重，如果不重新调平衡，会导致电机负载增大、落杆速度异常、遇阻反弹误触发
- 胶条不得遮挡闸杆上的反光条 / LED 灯带
- 气温骤降时（如冬季凌晨），管内气压下降，可能需要重新标定基准
:::

## 五种防砸方案定位总结

| 方案 | 检测方式 | 防护时机 | 定位 |
|------|----------|----------|------|
| 地感线圈 | 非接触（电磁） | 提前 | **主防砸**（防车） |
| 红外对射 | 非接触（光束） | 提前 | **主防砸**（防人） |
| 毫米波雷达 | 非接触（电磁波） | 提前 | **主防砸**（免破路场合） |
| 视频虚拟线圈 | 非接触（算法） | 提前 | **补充/冗余** |
| **压力波/遇阻反弹** | **接触** | **事后** | **兜底防线** |

:::tip[推荐的三层防护架构]
1. **第一层（提前预防）**：地感线圈 或 雷达 —— 检测到杆下有车，压根不落杆
2. **第二层（提前预防）**：红外对射 或 视频检测 —— 检测到行人/非机动车，不落杆
3. **第三层（兜底保护）**：压力波胶条 或 遇阻反弹 —— 万一前两层都失效，砸到东西立刻停止并反弹

学校、医院、小区人行通道、地下车库坡道等**高风险场所，三层必须配齐**。
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 落杆时频繁自动反弹 | 遇阻阈值太低 / 未做电流自学习 / 机械阻力大 | 执行自学习、调高阈值、给传动机构加润滑 |
| 胶条被压但不反弹 | 气压开关损坏 / 气管脱落 / 信号线断 | 检查气管、万用表测输出通断 |
| 无触碰也自动反弹 | 气管漏气 / 气温骤变 / 胶条老化微渗 | 重新标定基准气压、更换胶条 |
| 大风天气误反弹 | 风阻导致电机电流波动 | 调高遇阻阈值、缩短闸杆、改用栅栏杆（透风） |
| 冬天误反弹多 | 润滑脂变稠、机械阻力增大 | 更换低温润滑脂、重新自学习 |
| 反弹后不再落下 | 连续遇阻次数超限触发保护 | 断电重启、排查真实阻碍物 |
| 胶条脱落 | 卡槽老化 / 胶粘失效 / 被车刮蹭 | 更换卡槽、重新固定 |

:::tip[快速区分是"真遇阻"还是"误报"]
手动托住闸杆模拟受阻：
- 若主板立即停止并反弹 → 说明**检测功能正常**，问题在阈值设置或机械阻力
- 若毫无反应 → 说明**功能没启用**或传感器/接线故障

再观察反弹时的**落杆位置**是否固定：
- 每次都在同一位置反弹 → 该位置有机械卡滞（导轨、轴承、弹簧）
- 位置随机 → 风流、气流或电气干扰
:::

## 维护要点

:::info
- **每季度**：检查胶条是否龟裂、脱落、老化发硬
- **每季度**：测试一次防砸功能（用纸箱或泡沫板放在杆下，落杆应停止/反弹）
- **每半年**：给传动机构加润滑脂，重新做一次电机电流自学习
- **入冬前**：检查气管密封性，必要时重新标定气压基准
- **每次更换主板或电机后**：**必须重新自学习**
:::

:::danger[安全红线]
压力波和遇阻反弹属于**最后一道防线**，绝不能因为装了它就省略前置的地感/红外/雷达。

接触式防护在伤害发生后才起作用，对老人、儿童、宠物仍存在风险。**安全冗余不做减法**。
:::
