地感线圈防砸

什么是地感线圈防砸​

提示

地感线圈是目前使用量最大、最成熟的防砸方案。做法是在道闸下方的路面切槽埋入一圈漆包线，配合**车辆检测器（车检器）**使用。

当车辆（金属物体）压在线圈上方时，线圈的电感量发生变化，车检器检测到这个变化后输出一个开关量信号给道闸主板，主板据此判断"杆下有车"，拒绝落杆。

工作原理​

步骤说明
1车检器内部振荡电路让线圈产生一个高频交变磁场（频率通常 20~150kHz）
2车辆金属底盘进入磁场，产生涡流，吸收能量
3线圈电感量 L 下降，振荡频率升高
4车检器检测到频率/电流变化超过设定阈值
5输出继电器动作，给道闸主板一个干接点信号（常开变闭合）
信息

简单记忆：线圈是传感器，车检器是大脑，继电器输出是手。线圈本身不能直接接主板，中间必须经过车检器。

系统组成​

提示
  • 感应线圈：耐高温腊克线（BV 或 FVN 线），截面 0.751.5mm²，一般绕 46 圈
  • 馈线（引线）：线圈到车检器的双绞线，必须双绞，每米不少于 20 绞
  • 车辆检测器：单路 / 双路，按通道数选择，需与线圈电感量匹配
  • 输出信号：继电器无源干接点（NO/COM）或电平输出

双线圈方案（推荐）​

出入口标准做法是埋两个线圈，各司其职：

线圈位置作用
触发线圈车辆驶来方向，距道闸 4~6m检测到车辆 → 触发相机抓拍识别
防砸线圈正对道闸杆正下方地面杆下有车 → 禁止落杆
关键间距

触发线圈与防砸线圈的间距必须不小于 1.5m，否则两个线圈的磁场会互相串扰，导致误触发或不落杆。

如果车道实在太短，必须把两个车检器的频率档位调到不同值（一个调高、一个调低）。

施工规范​

切槽尺寸​

项目常规值说明
线圈形状矩形 或 菱形（平行四边形）菱形对摩托车、电动车检测更灵敏
线圈尺寸2.0m（宽） × 0.8m（长） 或 1.0m × 2.0m车道宽时按车道宽度走
切槽深度40~50mm太浅易被车轮碾压破损
切槽宽度4~6mm刚好能塞进线即可
绕线圈数4~6 圈周长 4~6m 时绕 4 圈；周长大于 6m 减到 3 圈
引出线双绞，长度尽量短，最长不超过 10m双绞抑制干扰

施工步骤​

  1. 放线定位：按图纸在路面弹线，四个角切 45° 斜角（避免直角处线被割伤）
  2. 切槽：用路面切割机切槽，深度 40~50mm
  3. 清槽：吹净灰尘碎石，槽内必须干燥
  4. 绕线：从槽的一端开始顺时针绕，圈数按周长确定，每圈都要压到底
  5. 引线双绞：两根引出线双绞，每米不少于 20 绞，一直到车检器接线端子
  6. 封槽：用沥青、环氧树脂或专用填缝胶灌满，必须完全填实不留空隙（否则线圈会松动导致电感漂移）
  7. 接线：引线接到车检器的线圈输入端子（通常标 LOOP / IN）
  8. 上电调试：调节灵敏度档位和频率档位
施工红线
  • 线圈绝对不能在槽内接头、打结，必须整根线连续绕完
  • 槽内不能积水、不能有线缆交叉
  • 封槽未干透前禁止车辆碾压
  • 线圈下方如果有钢筋（如楼板），检测灵敏度会明显下降，需要增加圈数或提高灵敏度档位

车检器参数与设置​

参数常见取值说明
工作电压AC220V 或 DC12V / DC24VDC 型常用于相机取电
线圈电感范围50300μH（部分 201500μH）超出范围车检器会报故障
灵敏度4~8 档可调档位越高越灵敏，也越容易误触发
频率高 / 中 / 低 三档 或 4 档拨码相邻线圈必须错开
存在时间常驻 / 延时（几秒到几分钟）防砸线圈建议设"常驻"
输出方式继电器常开 NO / 常闭 NC防砸建议接常闭 NC
为什么防砸要接常闭 NC

接常闭时，如果线路被老鼠咬断、接头松脱、车检器掉电，回路断开，主板立刻判断为"有车"并停止落杆——这是故障导向安全的接法。

如果接常开 NO，同样的断线故障会表现为"没车"，道闸照常落杆，砸车风险大大增加。

四种防砸方案横向对比​

方案原理防车防人/非机动车受天气影响是否需要破路成本
地感线圈电磁感应强弱（金属少检测不到）无是低
红外对射光束遮挡强强有（雨雾雪、强光）否低
雷达毫米波电磁波反射强强无否中
压力波闸杆胶条受压中（滞后）强无否中
视频虚拟线圈算法检测中强有（夜间、逆光）否低（需算法支持）
组合方案推荐
  • 标准安全型：地感线圈 + 红外对射（性价比最高，车场主流）
  • 高可靠智能型：地感线圈 + 雷达（免破路 + 全天候，改造项目首选）
  • 万无一失型：地感 + 红外 + 压力波三重保护（人车混行、学校医院等场所）

常见故障排查​

故障一：杆下有车仍然落杆（不防砸）​

注意
  • 防砸信号线没接：主板防砸端子和车检器输出之间断线，用万用表蜂鸣档测通断
  • 接成了常开：把 NO 接到了需要 NC 的端子，看主板说明书确认
  • 灵敏度太低：大型车底盘高时检测不到，把车检器灵敏度调高 1~2 档
  • 线圈电感漂移：封槽没填实、线圈松动，需要重做线圈
  • 主板防砸功能被关：进主板菜单确认防砸输入使能是否打开

故障二：杆下没车却一直不落杆​

注意
  • 灵敏度太高：旁边过车、井盖、钢筋都被检测到，调低灵敏度
  • 车检器死机：断电重启，若频繁死机更换车检器
  • 输出继电器粘连：继电器触点烧粘，更换车检器
  • 线圈短路：槽内有水或线皮破损，测量线圈电感值判断

故障三：两个线圈互相干扰​

注意

现象：过一辆车，两个车检器同时动作，或者一个动作另一个不动。

处理：

  1. 确认两个线圈间距不小于 1.5m
  2. 把两个车检器的频率档位调至不同（一个高、一个低）
  3. 检查引线是否双绞、是否与强电电缆平行走线（间距应大于 30cm）

万用表快速判断法​

提示

把万用表打到蜂鸣档 / 通断档：

测量点正常状态（无车）有车时
车检器输出 NO-COM断开（蜂鸣器不响）导通（蜂鸣器响）
车检器输出 NC-COM导通（蜂鸣器响）断开（蜂鸣器不响）

如果无车/有车状态信号都不变化，问题在车检器或线圈；如果信号变化正常但道闸行为不对，问题在主板接线或参数设置。
