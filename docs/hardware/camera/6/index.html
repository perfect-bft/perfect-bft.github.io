通用双目相机

什么是双目相机​

提示

双目相机装有两个镜头（两套图像传感器），两个镜头之间有一定间距（称为基线），模仿人眼的工作原理。

两个镜头从不同角度同时拍摄同一场景，算法通过比对两幅图像中同一个点的位置差异（视差），结合镜头间距和焦距，用三角测量原理计算出每个像素点到相机的实际距离，从而得到场景的深度信息（3D 点云）。

立体视觉原理​

概念说明
基线（Baseline）两个镜头光心之间的距离，一般 30~120mm。基线越长，远距离精度越高
视差（Disparity）同一物体在左右两幅图像中的水平像素位置差
深度计算深度 = （焦距 × 基线） ÷ 视差。视差越大，物体越近
立体匹配算法在左右图中寻找对应像素点的过程，是双目视觉的核心难点
标定参数焦距、主点、畸变系数、双镜头相对姿态，出厂标定并写入相机
信息

人眼判断距离靠的也是这套机制：把手指放在眼前，左右眼交替看，手指相对背景的移动量就是视差。手指越近，移动量越大。

双目相机能做什么单目做不到的事​

能力单目相机双目相机
平面图像支持支持
深度/距离信息只能靠目标尺寸估算，误差大直接测量，精度厘米级
立体建模不支持支持（3D 点云、目标体积）
逆光/强光表现依赖 WDR 算法双路曝光合成，效果更好
区分真实车辆 vs 图片/屏幕困难容易（平面没有深度）
车辆长宽高测量估算实测
无牌车特征识别弱强（车型、颜色、轮廓 3D）
人与物体区分靠 2D 特征靠 3D 形状，准确率高
目标轨迹追踪2D 追踪3D 空间追踪，抗遮挡

技术参数（典型）​

参数常见取值
传感器双 200 万 / 双 400 万 / 双 500 万像素
单路分辨率1920×1080 / 2560×1440 / 2592×1944
基线长度40mm ~ 120mm
视场角 FOV水平可达 150°（广角型号）
有效深度距离0.5m ~ 20m（按型号）
深度精度厘米级（近距离 12cm，远距离 510cm）
帧率25fps / 30fps
宽动态不小于 120dB，双路曝光合成
处理单元内置 VPU / NPU，实时立体匹配 + AI 推理
接口RJ45 网口、RS485、IO 输入/输出、TF 卡
防护等级IP66 / IP67
供电DC12V 或 POE
提示

VPU（视觉处理单元）是双目相机的核心。立体匹配计算量极大，早期双目需要外接工控机，现在靠内置 VPU 就能实时建模，这是双目相机能普及的关键。

典型应用场景​

一、出入口车牌识别（高端型号）​

信息

高端双目车牌识别相机（如"双 200 万传感器"方案）主打：

  • 识别率可达 99.99%
  • 双路曝光合成，逆光、强光、隧道出入口表现远超单目
  • 3D 建模辅助判断车型、无牌车
  • 有效抑制跟车、旁车干扰

二、路内停车 / 高位视频​

提示

路内停车（路边停车位）是双目相机最典型的应用：

  • 装在路侧立杆 6m 高，俯拍泊位
  • 单台 500 万双目可覆盖 6~8 个泊位
  • 通过 3D 建模判断车位占用状态，不受光影变化影响
  • 自动识别停放车辆车牌、停车时长，生成订单
  • 有效解决"斜停、跨位、遮挡"识别难题

三、车位引导​

  • 双目视频车位相机替代传统超声波探测器
  • 一个相机管 2~3 个车位，减少布线
  • 同时输出车位状态 + 车牌，支持反向寻车

四、客流统计 / 安防​

  • 3D 立体检测，能区分成人、儿童、行李
  • 不受影子、灯光倒影干扰（单目常被倒影坑）
  • 支持双向计数、区域人数统计

双目 vs 单目 选型建议​

场景推荐理由
标准车场出入口（预算敏感）单目足够环境可控，单目识别率已够用
出入口逆光/强光严重双目双路曝光合成优势明显
隧道、地下车库坡道出入口双目明暗反差极端
路内停车、高位视频必须双目斜拍角度大，需要 3D 信息
车位引导（视频方案）双目优先抗光影干扰
需要车型/无牌车识别双目3D 特征是关键
客流统计双目抗倒影、抗影子
简单门禁、人脸通行单目/专用相机双目无必要
双目不是万能的

双目相机也有短板：

  • 投入更高，同分辨率下硬件成本明显高于单目方案
  • 算力消耗大，需要更强的处理单元，功耗和发热更高
  • 标定会漂移：剧烈震动、温差变化后需要重新标定，否则深度不准
  • 弱纹理区域失效：纯白墙、纯色地面没有特征点，立体匹配会失败
  • 镜头脏污影响更大：两个镜头脏污程度不一致会导致深度计算错误
  • 基线限制：小体积相机基线短，远距离精度受限

安装规范​

通用要求​

提示
  • 两个镜头都不能被遮挡：这是最容易犯的错，遮住一个镜头双目就退化成单目
  • 避免剧烈振动：装在可晃动的横杆、薄钢板上会导致标定漂移
  • 避免强光直射任一镜头：两路进光量差异大会破坏曝光合成
  • 镜头要定期清洁：两路脏污程度不一致比都脏更糟糕
  • 避免正对纯色墙面/地面：弱纹理区域立体匹配失败

高位视频（路内停车）安装​

项目要求
安装高度6m（范围 5.5~6.5m）
立杆位置路侧，距泊位边缘 0.5~1m
覆盖范围单台覆盖 6~8 个泊位（500 万型号）
俯角按覆盖泊位数量计算，一般 30° ~ 55°
相邻相机重叠边界泊位保留 0.5 个车位重叠，避免漏检
供电POE 或 太阳能 + 电池（无市电场景）
网络4G 路由器 或 光纤
危险

高位相机装好后必须做一次现场标定：在泊位上放置标定物（或用标准车辆），让相机学习实际安装角度。跳过这一步，识别率会大幅下降。

调试要点​

提示
  1. 检查双路图像：进后台确认左右两路画面都正常、亮度一致
  2. 检查标定参数：确认出厂标定参数存在且未丢失
  3. 现场标定：按说明书用标定板或标准车位做现场标定
  4. 设置检测区域：在画面上框定泊位/车道区域
  5. 设置深度阈值：过滤过远/过近的无效目标
  6. 验证深度图：多数后台能显示深度伪彩图，务必看一眼，深度图是否正确直接决定效果
  7. 实测：不同车型、不同光照、不同停放角度各测几轮
深度图自检

深度伪彩图（越近越红、越远越蓝）是判断双目是否工作正常的最直观工具：

  • 深度图层次清晰、与实物的远近关系一致 → 标定正常
  • 深度图一片噪点、黑白斑驳 → 标定失败或弱纹理区域
  • 深度图整体偏移 → 需要重新标定
  • 只有一半画面有深度 → 有一个镜头被遮挡或故障

深度图不对，后面所有识别结果都不可信。

常见故障排查​

现象可能原因处理方法
深度图全是噪点未标定 / 标定参数丢失 / 镜头脏重新标定、清洁两个镜头
深度图只有一半一个镜头被遮挡或损坏检查遮挡、检查镜头连接
安装震动后识别变差标定漂移重新做现场标定
白墙/纯色地面前深度丢失弱纹理，立体匹配失败调整角度避开、增加环境纹理
逆光下表现仍不好双路曝光参数未优化调整双路曝光时间差、开启 WDR
两个镜头亮度不一致一个被部分遮挡 / 脏污清洁、去除遮挡
功耗高、相机发烫算力满载降低帧率/分辨率、改善散热
识别速度和单目差不多未开启深度辅助确认算法版本支持双目增强
夜间深度图质量差补光不足增加补光灯、调高增益
