## 系列概述

:::tip
**人脸识别相机 A 系列**

主打通道、门禁、工地实名制场景。常见机型有 **7 寸单目人脸识别门禁一体机**、**红外热成像测温人脸识别门禁机**，以及基于 **Hi3516EV300** 方案的高性价比门禁模组。
:::

## 核心功能

:::tip
- **脱机识别**：无需电脑及云端，本机人脸库直接比对
- **活体检测**：双目版本可防手机照片、彩打照片、黑白照片攻击
- **智能曝光补偿**：自动校正逆光、背光、阴阳脸
- **输出方式**：韦根协议输出 + 开关量输出，可直接控制闸机、门禁、广告门
- **黑白名单 + 报警输出**：支持临时名单管控（按时间点自动失效）
- **测温（测温双目机型）**：1 秒非接触体表温度检测，误差 ±0.4℃，超温现场语音报警并推送短信
- **住建平台对接**：支持对接全国大部分住建 / 实名制平台（如济公网、宁图平台等）
:::

## 人脸录入方式

:::tip
1. **相机本地采集**：直接在相机上采集人脸，无需采集器；也可用手机照片或寸照
2. **刷卡录入**：选配刷卡器后，设置任意 IC / ID 卡为管理卡，刷管理卡后抓拍镜头前人脸并注册到人脸库
3. **WIFI 热点录入**：通电后相机默认生成以 **EV300** 开头的 WIFI 热点，手机连接后通过微信小程序添加人脸（需特定固件，人脸数 8000）
4. **批量上传**：支持所有人脸批量导入，支持局域网考勤与报表导出
:::

## 安装与调试要点

:::warning[安装位置]
- **安装高度**：以 1.4~1.6m 为宜（镜头对准成人面部高度），配合立柱或壁挂安装
- **识别距离**：0.5~2.0m，行人需在此范围内短暂停留
- **避免逆光**：不要正对玻璃幕墙或强光源，否则易出现阴阳脸、识别失败
- **户外机型**：做好防雨防晒，避免阳光直射镜头
:::

:::tip
- 相机角度可调，配合智能补光灯，太阳直射与无光环境也能识别
- 一台电脑最多可接入 16 台人脸相机（配套管理软件）
- 支持视频叠加、全景图与局部特写图输出（比对成功 / 未比对 / 失败 / 合成图）
:::

## 常见问题排查

:::warning[识别慢或识别不出]
- 检查识别距离是否超出 0.5~2m 范围
- 检查是否有强逆光 / 阴阳脸，调整安装角度或开启曝光补偿
- 检查人脸库是否已满（7 寸单目机型为 10000，EV300 方案仅 4000）
- 检查镜头是否脏污、起雾
:::

:::warning[刷脸不开门 / 不抬杆]
- 检查韦根或开关量输出线是否接对（韦根 D0 / D1，注意正负极）
- 检查门锁 / 闸机端的信号类型是否与相机输出匹配
- 用万用表或短接法测试闸机端是否能被触发，排除后端设备故障
:::

:::warning[无法对接住建平台]
- 确认设备固件版本支持目标平台
- 确认网络可达、设备序列号已在平台注册
- 联系技术支持获取对应平台的对接文档
:::
