# 人脸识别上云使用说明书

:::tip
本文说明人脸门禁一体机（设备类型 **DA-L001**）接入社区云平台的完整配置流程，共七步：设备联网 → 平台参数 → 开通账号 → 建项目 → 建基本数据 → 添加设备 → 填序列号。
:::

## 准备信息

| 项目 | 内容 |
|------|------|
| 人脸机后台 | 浏览器输入人脸机 **IP** |
| 后台账号 | `admin` |
| 后台密码 | `123456` |
| 平台地址 | `https://f.bolink.club/camera/device` |
| 设备类型 | DA-L001 |

:::warning[前提条件]
人脸机必须**联网并保证外网通讯**，否则设备无法与平台建立连接。
:::

## 第一步：人脸机联网并登录后台

人脸机联网，保证设备外网通讯，用人脸机的 IP 登录浏览器，输入账号密码（账号 `admin`、密码 `123456`）。

## 第二步：配置平台接入参数

登录成功后，打开 **平台配置 → 系统参数**，勾选**平台开启**，填入平台 URL：

```
https://f.bolink.club/camera/device
```

## 第六步：建立基本数据

进入 **基本数据**，按 **区域管理 → 楼宇管理 → 房屋管理** 的顺序依次添加。

### 区域管理

<div className="doc-img-wide">

![区域管理](/img/camera/da-face/da-step05.png)

</div>

### 楼宇管理

区域选择上一步创建的区域名称，**楼栋名称自定义**，楼层自定义随便填个数字都可以，电梯选择有或者无。带星号必填，没有强制性内容，自定义即可。

<div className="doc-img-wide">

![楼宇管理](/img/camera/da-face/da-step06.png)

</div>

### 房屋管理

带星号必填，内容自定义填写，默认填 1 都可以。

<div className="doc-img-wide">

![房屋管理](/img/camera/da-face/da-step07.png)

## 第七步：添加门禁设备

进入 **设备管理 → 门禁设备 → 新增**。

<div className="doc-img-wide">

![设备管理-门禁设备-新增](/img/camera/da-face/da-step08.png)

</div>

按下表填写设备信息（**带星号的为必填项**）：

| 字段 | 填写内容 |
|------|----------|
| 设备名称 | 自定义 |
| 设备类别 | 人脸门禁 |
| 设备类型 | **DA-L001** |
| 联网类型 | 以太网 |
| 序列号 | 人脸机的 **MAC 地址**（见下方获取方式） |
| 设备方向 | 进 或 出 |
| 设备位置 | 平台手选 |
| 安装位置 | 自定义填写 |

### 序列号（MAC 地址）获取方式

登录人脸机后台，进入 **设备信息 → 系统参数**，里面的 **MAC 地址** 即为序列号，填写到平台。

<div className="doc-img-wide">

![人脸机后台查看 MAC 地址](/img/camera/da-face/da-step09.png)

</div>

<div className="doc-img-wide">

![序列号填写到平台](/img/camera/da-face/da-step10.png)

:::danger[最容易填错的一项]
**序列号必须填人脸机后台查到的 MAC 地址**，填错设备无法上线。所有带星号字段必填，其余内容可自定义。
:::

## 上线自检

:::tip
1. 人脸机能否 ping 通外网
2. 平台配置里"平台开启"是否已勾选、URL 是否正确
3. 平台侧设备是否显示**在线**
4. 序列号（MAC）与设备机身是否一致
5. 设备方向（进/出）是否符合实际安装位置
:::
