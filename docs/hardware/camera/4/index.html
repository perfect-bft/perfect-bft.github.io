人脸识别相机（B 系列）

系列概述​

提示

人脸识别相机 B 系列

面向端侧 AI 人脸识别应用的高性能套料方案，基于主流 AI 芯片（如 RV1109、AX620Q 等）开发，提供核心模组与整机形态，支持二次开发。

主力方案：高性能 AI 人脸识别套料​

项目规格
主芯片RV1109，2 核 1.5GHz
AI 算力1.2 TFLOPS
系统Linux
内存 / 存储RAM 512MB，Flash 8GB
摄像头500W 双目宽动态活体摄像头
分辨率2048(H) × 1536(V)
宽动态支持
识别距离0.5 ~ 2m（最远 2m）
识别时间小于 300ms（方案级可达 10ms 级响应）
识别准确率99.7%
人脸库容量1:N，N ≤ 60000
屏幕竖屏，7 寸（600×1024）/ 8 寸（800×1280）
供电DC 12V

核心功能​

提示
  • 活体检测：RGB / IR 双目，有效防止照片、视频、面具攻击
  • 脱机识别：可单机直接录入人脸信息，免后台及云端；本地人脸库最大 60000 人
  • 多种认证方式：1:N 刷脸识别、1:1 人证比对、ID / IC 卡识别
  • 人证比对：支持读取二代身份证、港澳台居住证进行人证比对，支持刷身份证开门
    • 兼容 USB 通用协议身份证阅读器：IDM30 / IDM40、ID100、CVR-100M
  • 输出接口：支持门禁控制、韦根输出，可直接联动闸机
  • 二次开发：支持局域网 / 云端协议对接，提供标准化接口与 SDK
刷卡模块为选配

IC / ID 卡识别需选配 USB 刷卡模块或串口刷卡模块（支持超级卡功能），下单时需确认是否带刷卡。

接口说明​

功能说明
电源DC 12V 输入
网络RJ45，10/100Mbps 自适应（部分方案支持 WIFI）
韦根韦根输出（Wiegand 26 / 34），接门禁控制器或闸机
开关量开门信号输出，直接驱动电锁 / 闸机
USB接身份证阅读器、刷卡模块
串口RS485 / TTL，用于外设扩展与二次开发
音频语音播报输出

应用场景​

提示
  • 门禁：小区单元门、写字楼大堂、工地实名制通道
  • 通道闸：翼闸、摆闸、三辊闸、广告门，比对成功后直接输出开闸信号
  • 人证核验：需实名制比对场景（工地、考场、政务大厅）

安装与调试要点​

安装位置
  • 安装高度：镜头中心距地 1.4~1.6m，对准成人面部
  • 识别距离：0.5~2m，提醒行人在此范围内摘口罩、正对镜头
  • 避免正对强光 / 玻璃幕墙；户外需加遮阳罩
  • 竖屏机型注意屏幕安装方向，横竖屏切换需在配置中同步设置
提示
  • 人脸库越大，比对耗时越长；60000 人满库场景建议评估响应速度
  • 支持人脸名单扩容，需向厂家确认授权上限
  • 二次开发前先索取 SDK 与协议文档，确认 HTTP 推送格式

常见问题排查​

识别准确率下降
  • 检查镜头是否脏污、起雾
  • 检查是否有强逆光或阴阳脸
  • 确认人脸注册照是否为正面清晰照（避免侧脸、戴墨镜、过度美颜）
  • 确认固件与算法版本为最新
人证比对失败
  • 确认身份证阅读器型号在兼容列表中（IDM30 / IDM40 / ID100 / CVR-100M）
  • 确认阅读器 USB 连接正常、驱动已加载
  • 部分场景需在配置中开启"人证比对"开关
刷脸后闸机不开
  • 检查韦根 D0 / D1 接线是否接反、接虚
  • 检查闸机端韦根输入是否与相机输出位数一致（26 / 34）
  • 直接用开关量输出短接测试，排除闸机自身故障
