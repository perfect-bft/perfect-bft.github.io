# 道闸控制板（D8）

:::tip
D8 直流无刷道闸控制器（V3.81）是直流无刷道闸的核心控制板，支持 24V 直流供电、起/落杆速度独立调节、多重保护、蓝牙调试与多种继电器输出模式。
:::

![D8 直流无刷道闸控制器封面](/img/barrier/d8-p01-cover.png)

## 规格参数

| 项目 | 参数 |
|------|------|
| 供电电源 | DC 24V ±10% / 10A |
| 电机功率 | 最大 250W |
| 静态功率 | 小于 2W |
| 起杆/落杆速度 | 1% ~ 100% 可调 |
| 工作温度 | -40℃ ~ +75℃ |
| 工作湿度 | 30% ~ 80%（无凝露） |
| 工作噪音 | 小于 50dB |
| 主板尺寸 | 约 170 × 61.85mm（含安装耳），安装孔距 4.24mm |

## 产品特点

- **安全**：24V 直流电源供电，保障人身安全。
- **节能**：静态功率小于 2W，可接最大功率 250W 的电机。
- **速度可调**：起杆、落杆速度独立调节。
- **工作平稳**：多段速度设计，运行平稳。
- **多重保护**：电机过流、过载、短路保护，电机故障保护，电源反接保护。
- **遥控输入**：支持外接遥控器输入。
- **参数可设**：支持 P-00 ~ P-90 功能参数设置。
- **光感控制**：支持光敏开启广告闸灯光。
- **环境适应**：支持防风、防冻、防锈等功能。
- **继电器模式**：支持多种继电器输出模式。

## 按键与显示

控制器面板有 4 个按键，从左到右分别是：**开/+**、**关/-**、**菜单**、**停止/取消**，配合四位 LED 显示屏完成参数查看与设置。

![D8 按键说明与 P 码功能目录](/img/barrier/d8-p05-buttons.png)

### 按键说明

| 按键 | 功能 |
|------|------|
| 开/+ | 正常状态起杆；设置状态增加菜单项或增大设定值 |
| 关/- | 正常状态落杆；设置状态减少菜单项或减小设定值 |
| 菜单 | 长按 3 秒进入菜单；短按进入参数设置；设置完成后短按保存退出 |
| 停止/取消 | 正常状态停止；设置状态返回上一级或取消设置 |

### 显示说明

- 上电后 LED 以低功耗模式运行，亮度较暗。
- 按任意键进入正常工作模式，LED 高亮。
- 60 秒无操作进入低功耗模式；2 分钟无操作关闭 LED 显示。
- 菜单选择状态显示 `P-XX`，参数设置状态显示对应数值。

## P 码参数表

## 继电器输出模式（P-44）

P-44 用于设置继电器 1、继电器 2 在不同道闸状态下的通断逻辑，可实现广告灯、红绿灯、地感联动等功能。

![D8 继电器模式输出表](/img/barrier/d8-p11-relay.png)

### P-44 模式速查

| 模式 | 名称 | 说明 |
|------|------|------|
| 0 | 通行灯模式 | 继电器 1 开到位断开/关到位闭合；继电器 2 开到位闭合/关到位断开 |
| 1 | 广告灯模式 | 根据外接光感开启/关闭广告道闸灯光 |
| 2 | 地感模式 | 开始抬杆时闭合，关到位断开 |
| 3 ~ 9 | 红绿灯模式 | 多种红绿灯联动逻辑 |
| 10 ~ 19 | 道闸状态/脉冲/透传等扩展模式 | 详见上图完整表 |

## 错误代码与 LED 状态

控制器检测到异常时，会通过错误代码显示错误类型；LED 状态灯用于指示当前工作状态。

![D8 错误代码与数码管显示说明](/img/barrier/d8-p17-error.png)

### 错误代码表

| 代码 | 含义 |
|------|------|
| Err0 | 清除遥控器和恢复出厂设置时确认值不正确 |
| Err1 | 保留 |
| Err2 | 刹车反冲电压过高告警，一般因弹簧匹配不好或速度过快 |
| Err3 | 起杆堵转，可能弹簧断、速度过小、结束速度过小 |
| Err4 | 落杆堵转，可能弹簧太紧、未挂闸杆、结束速度过小 |
| Err5 | 起杆超时，起杆时间超过 15 秒 |
| Err6 | 落杆超时，落杆时间超过 15 秒 |
| Err7 | 电机类型选择错误，可通过 P-10 改正 |
| Err8 | 保留 |
| Err9 | 起杆过程中弹簧断等导致电机反转 |

### LED 状态含义

| 显示 | 含义 |
|------|------|
| IDLE | 未接电机或电机霍尔故障，可能接线松动 |
| STOP | 停止状态 |
| CLOS | 正在关闸 |
| OPEN | 正在开闸 |
| HOLD | 保持状态 |
| LOCK | 锁闸状态 |
| FLET | fleet 车队模式 |

D8 内置蓝牙调试功能，可扫描控制板上的二维码，或在微信小程序搜索「D8 调试小助手」进行连接与参数调试。

## 注意事项

- 请在允许的湿度和温度范围内运输、使用和存储设备。
- 请勿将任何液体流入设备。
- 请将设备安装在通风良好的场所，切勿堵塞通风口。
- 请勿重压、剧烈振动或浸泡设备。
- 建议将设备接地孔接地，提高可靠性。
- 请勿私自拆卸本设备。
- 配套的杆子不允许加长、截断或私自加重。
