FK控制板（FK 主控板 A 型）

产品定位​

提示

FK控制板 = FK 主控板 A 型（车牌识别一体机常用语音 + 显示驱动板）

车牌识别一体机里最常用的语音 + 显示驱动主板之一。主打国产替代与高性价比，广泛用于老旧小区改造和中小型物业项目，成本可控、安装简单、兼容性强。

选型时可参考一句话口诀：预算有限选 A 型，管理复杂选进阶协议板，注重显示效果选显示一体板。

FK 控制卡系列概览​

提示

本站实际使用 12V 供电系列，分为两类：

  • 12V 双色控制卡：红色 / 绿色 两种 PCB
  • 12V 全彩控制卡

均采用最新 ARM Cortex-M 系列 RISC core 内核芯片，超高性能，显示效果完美。

12V 双色控制卡（绿色）

12V 全彩控制卡

主要功能​

提示

  • LED 屏驱动：把相机 / 平台通过 485 下发的指令，转换成可直接驱动 LED 屏幕板显示的信号

    • 双色卡：1 路 08 接口，支持 16 扫、4 行 4 字
    • 全彩卡：1 路 75 接口，支持 16/32 扫、4 行 4 字

  • 语音播报：板载行业常用语音，自带功放直接推喇叭；支持 TTS 万能语音接口，即插即用

  • 红绿灯输出：两路红绿灯信号，驱动能力 1A

  • 二维码显示：自带二维码生成引擎，可显示缴费二维码；显示二维码时扫描频率自动倍频至 800Hz 以上

典型规格​

项目规格
主控芯片ARM Cortex-M 系列 RISC core 内核芯片

波特率设置方法​

提示

控制卡波特率必须与相机 485 波特率一致，否则屏幕不显示、喇叭不播报。

  1. 通电后屏幕第一行会显示控制卡当前的固件版本和波特率
  2. 短按左边第一个 SET /「设置」 按钮，进入设置模式
  3. 进入后短按第二个方向按钮切换配置值
  4. 继续短按 SET 按钮切换配置项
  5. 切换到波特率界面，修改波特率
  6. 等待几秒钟，自动保存生效
注意

若屏幕完全无显示或显示乱码，优先检查：485 线 A / B 是否接反（A 对 A、B 对 B）、波特率是否一致、控制卡供电是否到位（5V / 12V）。

一体机主板接口（通用参考）​

以常见的 12V 集成电源型主板为例，接口通常包括：

接口说明
电源输入12V / 5A（集成电源设计，切勿接入 220V）
相机电源12V 输出，供抓拍相机
补光灯电源12V 输出，注意正负极性
模组电源5V 输出，供显示屏模组
道闸控制输出继电器常开输出，接道闸【公共】+【起】
485 接口A / B，连接相机与显示屏
喇叭接口语音功放信号输出，配 4Ω10W 4 寸喇叭
红绿灯接口3pin 2.54 端子，配 12V 共阴 LED 灯板
网络接口联机时接交换机，与电脑组成局域网
接线安全
  • 该主板采用集成电源设计，严禁将 220V 接入主板
  • 补光灯接线注意正负极与输入电压参数；使用自带 220V 电源的补光灯可不接此接口
  • 相机电源同理，使用自带 220V 转 12V 适配器的相机可不接主板供电
