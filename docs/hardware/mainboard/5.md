## 作用

:::tip
继电器扩展主板是**弱电控制强电**、**一路信号扩展成多路**的中间环节。

典型用途：
- 把车牌识别相机的开关量输出转成可驱动大功率设备的触点信号
- 一路开闸信号同时联动道闸、补光灯、红绿灯、摄像头抓拍
- 强弱电隔离，保护相机 IO 口不被外部电路烧毁
:::

## 基本原理

:::tip
继电器本质是一个**用电磁铁控制的开关**，分两部分：

- **线圈侧（输入）**：接控制信号，常见 DC 5V / 12V / 24V
- **触点侧（输出）**：相当于一个机械开关，有三个端子
  - **COM**：公共端
  - **NO**（常开）：线圈未通电时断开，通电后闭合
  - **NC**（常闭）：线圈未通电时闭合，通电后断开
:::

:::warning
道闸开闸一般使用 **COM + NO** 这一组——识别成功瞬间触点闭合，相当于按了一次开闸按钮，随后自动断开。
:::

## 常见参数

| 项目 | 常见规格 |
|------|----------|
| 线圈电压 | DC 5V / 12V / 24V（需与前端控制板一致） |
| 触点容量 | 10A 250VAC / 10A 30VDC（常见） |
| 路数 | 1 / 2 / 4 / 8 路 |
| 触发方式 | 高电平触发 / 低电平触发（可跳线选择） |
| 隔离 | 光耦隔离，输入输出不共地 |
| 指示 | 每路带 LED 状态灯，吸合时点亮 |

## 典型接线示例

### 场景：相机开闸信号驱动道闸

:::tip
1. **线圈侧**：相机开闸输出（如相机 ALARM-OUT1 与 COM）接到继电器模块输入端 IN，模块供电接 12V / GND
2. **触点侧**：继电器 **COM** 与 **NO** 两端，串联到道闸主板的【公共】与【开】端子
3. 识别成功 → 相机输出 → 继电器吸合 → COM-NO 导通 → 道闸收到开闸信号
:::

### 场景：一路信号联动多路设备

:::tip
把多个继电器的线圈并联接到同一路控制信号，各继电器触点分别接不同设备（道闸、补光灯、红绿灯、抓拍触发），实现一进多出。
:::

## 选型与安装要点

:::warning
- **触点容量要留余量**：驱动道闸主板通常电流很小，但若直接驱动 220V 补光灯或电机，需确认容量并加中间继电器或交流接触器
- **感性负载要保护**：驱动电机、电磁阀等感性负载时，建议加续流二极管（直流）或 RC 吸收回路（交流），延长触点寿命
- **强弱电分离走线**：220V 强电与信号线分开走，避免干扰导致误触发
- **触发电平要确认**：高电平触发 / 低电平触发接反会导致继电器不动作或一直吸合
- **切勿把 220V 直接接到相机 IO 输出端**，会烧毁相机
:::

## 常见故障排查

:::warning[继电器不吸合]
- 线圈电压是否与模块要求一致（5V / 12V / 24V）
- 触发电平跳线是否正确（高 / 低电平）
- 输入信号是否真的有输出（用万用表测前端）
- 供电电流是否足够（多路同时吸合时电流叠加）
:::

:::warning[继电器吸合但后端设备不动作]
- 触点接线是否接在 COM 与 NO 上（接成 COM 与 NC 会反逻辑）
- 触点是否烧蚀（长时间大电流导致），可换一路或换模块
- 后端设备是否本身故障（直接短接测试）
:::

:::warning[继电器误动作 / 抖动]
- 信号线过长或靠近强电，引入干扰 → 用屏蔽线、缩短距离
- 电源功率不足 → 更换更大电流电源
- 输出端未加吸收回路，感性负载反峰干扰
:::
