液晶屏驱动板（S400）

产品定位​

提示

LCD 显示屏驱动主板

本类板卡专为「显示 + 控制一体化」设计，自带高清屏驱功能，可直接驱动道闸旁的 LCD / LED 信息屏，实时显示车牌号、进出时间、停车时长、收费金额、剩余车位等信息，同时驱动喇叭播报。

与 LED 点阵屏相比，LCD 屏可显示多行彩色内容、字体更小更细腻，观感更高端，适合追求可视化体验的项目。

S400 规格参数​

提示

S400 是DT（OLM 系列）液晶屏驱动板，内置车场显示业务与 TTS 语音合成，用于车牌识别一体机的 LCD 屏驱动，对应本站的「液晶屏驱动板」。

产品特点​

  • 内置车场显示业务：空闲视频 / 图片轮播，过车图文显示，扫码支付显示
  • 内置 TTS 语音合成算法
  • 支持 RS485 / TCP / UDP / MQTT 通信方式
  • 支持芊熠、HX、VZ 相机脱机工作
  • 内置停车场常用语音库
  • 支持 TTS 语音模块扩展接口
  • 预留可视对讲接口、扫码接口、扫码识别算法（暂未开放）

接口与性能​

项目规格
显示接口一路 LVDS 单 8 接口，最高分辨率 1366×768@60Hz
网络一路 100M 以太网接口
通信一路 RS485 通信接口，最高波特率 115200bps
功放一路 D 类功放输出，最大输出功率 4 欧姆 5 瓦特
USB一路 USB 主机通用接口，支持外部摄像头 / 扫码头接入
摄像头一路 MIPI 摄像头专用接口，最大像素 5MP；一路模拟咪头输入接口
按键一路外部触发按键输入接口

提示

对应到相机侧：B 系列 88D 支持 LCD 高清控屏（多色显示、丰富 UI），E5 支持 LED 控屏。选型时相机与屏型要匹配。

控制板接口详解​

以典型显示屏控制板为例，通常有 5 个端口：

端口标识说明
电源5V / GND直流 5V 供电，正极接 5V、负极接 GND，切勿接反
红绿灯输出红灯 / 绿灯 / 地线红灯 + 地线一组，绿灯 + 地线一组，接 LED 灯板
喇叭SPK+ / SPK-语音播报输出，分正负，接反喇叭不响
485 信号A+ / B-接收相机识别结果，A 对 A、B 对 B
屏驱输出排线 / 端子输出显示内容到屏幕
注意
  • 喇叭接线分正负，接反不会响
  • 5V 电源正负极接反会烧板（部分板卡自带防反接，但不可依赖）
  • 485 线 A / B 接反是最常见的"不显示"原因

与相机联动的配置步骤​

提示
  1. 接线：相机与显示屏正常通电；板卡 485A 接相机 A1，485B 接相机 B1
  2. 进入相机网页端：高级设置 → 屏显语音 → 屏显协议
  3. 选择协议类型：按控制卡型号选择对应协议（A / D / E 等，不同厂家命名不同）
  4. 核对波特率：控制卡默认波特率需与相机一致（常见 9600，部分板卡为 19200）
    • 若不一致，先到串口配置把相机波特率改成与板卡一致
  5. 串口号：默认多为 2，需按现场改为 1
  6. 启用状态：一般设为"脱机启用"
  7. 输出配置：勾选 RS485 输出接口（A 系列相机在「高级设置 → 外观设置 → 输出配置」）
  8. 显示与语音内容：设置入口空闲 / 忙碌状态显示方式，配置入口语音
  9. 保存后实际过车测试显示与播报
波特率是最常见的坑

屏显控制卡背面 / 屏幕第一行通常会显示当前固件版本与波特率。控制卡波特率与相机 485 波特率必须一致，否则屏幕完全不显示、喇叭不播报。

常见默认波特率：

  • 多数 LED 控制卡：9600
  • 部分 LCD 控制卡（如某些 P61 型号）：19200

常见故障排查​

屏幕不显示
  1. 485 线 A / B 是否接反
  2. 波特率是否与相机一致
  3. 相机端屏显协议类型是否选对
  4. 相机端 RS485 输出是否勾选、串口号是否正确
  5. 控制卡供电是否正常（5V / 12V）
显示正常但无语音
  1. 喇叭正负是否接反
  2. 喇叭阻抗 / 功率是否匹配（一般 48Ω、310W）
  3. 音量设置是否为 0（部分主板有硬件旋钮 + 软件音量两处）
  4. 语音条目是否在板载库中，自定义语句需使用万能语音功能
显示内容错乱 / 缺字
  1. 屏型与扫描方式配置是否匹配
  2. 排线是否松动、氧化
  3. 板卡固件版本与协议版本是否匹配，必要时升级
白天正常、晚上通信中断

485 长距离通信受温差与干扰影响，可尝试：

  • 使用屏蔽双绞线，远离强电
  • 降低波特率（如 19200 → 9600）
  • 检查线路阻抗与接头氧化情况
信息
