DT控制卡（OLM-M1F）

产品定位​

提示

主控板 B 型（车牌识别一体机主板 / 屏显控制卡）

本类型是车牌识别一体机主板的主流方案之一。B 型与其同源方案采用同一套通信协议，行业内常并称为该协议族，多款车牌识别相机内部集成的就是同一类 LED 屏显控制卡。

主打"显示 + 控制一体化"，自带高清 LED 屏驱动功能，可直接连接道闸旁的 LED 信息屏，实时显示车牌号、进出时间、剩余车位等。

屏显控制卡的作用​

提示

LED 屏显控制卡的核心作用：把服务器通过相机 485 下发的指令，转换成可以直接驱动 LED 屏幕板显示和喇叭发声的信号。

在平台车道设置中选择正确的屏显卡协议类型，车牌识别机才能正常显示字幕和播报语音。

OLM-M1F 规格参数​

提示

OLM-M1F v3.2 是DT（OLM 系列）屏显控制卡，用于车牌识别一体机的 LED 屏驱动与语音播报，对应本站的「DT控制卡」。

产品特点​

  • 一路 08 接口，支持单双色 8 扫、16 扫驱动
  • 一路 RS485 通信接口，最高波特率 115200bps
  • 一路 5V 稳压输出，可给模组供电
  • 一路 D 类功放输出，直接驱动喇叭，最大输出功率：4 欧姆 5 瓦特
  • 板载 RTC 时钟功能，掉电时钟可保存 2 年
  • 最大驱动点数为 64×64（RGB），刷新率高至 500Hz
  • 软件支持文字显示、语音播报、二维码显示（绘图模式）
  • 支持芊熠、HX、VZ 相机脱机工作
  • 支持横屏、竖屏多种显示模板
  • 内置停车场常用语音库
  • 支持按键调参数，一键恢复功能

基本电性规格​

项目规格
工作电压12V ±5%
静态电流≤ 40mA（无外部负载）
工作温度范围-20℃ ~ 80℃
音频功放输出功率4 欧姆 5 瓦特（喇叭阻抗不能小于 2 欧姆）
RS485 通信距离100 米 @ 115200bps
显示屏扫描频率30Hz ~ 500Hz

应用场合​

  • 车牌识别一体机
  • 余位显示屏
  • 车载条屏

主板尺寸​

  • 主板：长 98mm × 宽 68mm
  • 两孔位中心：长 92mm × 宽 62mm
  • 孔位直径 φ：3.5mm

控制卡外观识别与设置​

识别特征​

如何识别 B 型控制卡
  • 板卡印刷的版本号以 OLM- 为前缀
  • 板卡印有三角形图标
  • 只有单独一个手动控制按钮，一般为黑色

波特率设置（与 A 型不同，注意区分）​

提示
  1. 通电后屏幕第一行会显示控制卡当前的固件版本和波特率
  2. 长按控制卡上的黑色按钮，进入设置模式
  3. 进入后短按切换配置值，长按继续切换配置项
  4. 切换到通信速率界面，修改控制卡的波特率
  5. 改好后等待几秒钟，自动保存生效

控制卡波特率和相机的 485 波特率必须保持一致，才能正常接收屏显与语音指令。

注意

A 型是"短按 SET 进入"，B 型是"长按黑色按钮进入"，操作时不要混用，否则容易误入其他配置项。

常见故障排查​

屏幕不显示 / 只亮不显示内容
  • 485 线 A / B 是否接反（A 对 A、B 对 B）
  • 控制卡波特率与相机 485 波特率是否一致
  • 平台车道设置中的屏显协议类型是否选择正确（A 型 / B 型 / 进阶协议 / 通用型等）
  • 更换控制卡后是否重新设置了协议类型
显示乱码 / 缺笔画
  • 检查屏型与扫描方式配置（08 接口 / 75 接口）
  • 检查排线是否松动、接触不良
  • 部分批次控制卡横竖屏模式不匹配，可尝试恢复出厂设置
有显示但无语音
  • 检查喇叭接线与阻抗（一般 4~8Ω）
  • 检查音量设置（部分主板支持硬件旋钮 + 软件调节）
  • 确认语音条目是否存在于板载语音库，自定义语句需使用万能语音功能
