# 21B 道闸机芯规格书

:::tip
21B 系列是**直流无刷道闸机芯**，采用侧贴式安装 + 齿轮减速传动，DC24V 安全电压供电，配合控制器可实现速度任意调节、到位减速缓冲。共有 **21B-0.8S / 21B-1.5S / 21B-3.0S** 三个型号，对应不同杆长与起落速度。
:::

## 一、产品性能特点

1. **侧贴式安装**：机芯采用侧贴式安装，安装方便结构紧凑。
2. **铝合金压铸主体**：主体为铝合金材质，由压铸工艺制造，机械强度可靠，外形美观，尺寸精准，散热良好。
3. **齿轮减速传动**：传动效率高，对功率输出损耗小；齿轮材质 SCM421、渗碳热处理工艺、精密磨齿加工、抗磨损、抗冲击，使用寿命远超蜗轮传动结构。
4. **直流无刷电机**：输出扭矩大、体积小，通过控制器可实现速度任意调节，落杆与抬杆到位时实现减速缓冲，使闸杆平稳到位。
5. **DC24V 安全电压**：避免了漏电后造成的触电事故，对人身安全更有保障。

## 五、电机引出线定义

电机引出线共 8 根：**U、V、W、VCC、Hu、Hv、Hw、GND**。

<div className="doc-img-wide">

![21B 电机引出线定义](/img/barrier/21b/21b-wiring.png)

</div>

:::warning[接线前确认]
接线前务必对照上表核对线序，U/V/W 为电机相线，Hu/Hv/Hw 为霍尔信号线，VCC/GND 为霍尔电源。**相线接错会导致电机抖动或不转，霍尔线接错会烧霍尔。**
:::

## 七、工作环境

| 项目 | 要求 |
|------|------|
| 温度范围 | -30℃ 至 +60℃ |
| 湿度 | 90% 以内（无凝露） |
| 海拔 | 1000M 以下 |

## 八、存储环境

机芯应存放在干燥、通风的库房内，库内适宜温度应保持在 **5℃ ~ 35℃** 范围内，相对湿度不高于 **65%**，应防止有害气体、蒸汽以及尘土等侵入。

## 九、运行寿命

机芯在正常闸杆长度与速度范围内，工作运行寿命 **≥ 500 万次**。
