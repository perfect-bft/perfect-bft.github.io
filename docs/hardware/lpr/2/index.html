车辆进出完整流程

入场流程​

提示

第 1 步：车辆触发

车辆驶入入口，压到地感线圈（线圈电感量变化）或被雷达 / 视频虚拟线圈检测到，检测器把「有车」信号发给相机，触发抓拍。

第 2 步：抓拍与识别

相机连续抓拍 2~3 张图片，内置 AI 芯片完成车牌定位、字符分割、OCR 识别，输出车牌号、车牌颜色、车牌类型，同时记录车辆图片与进场时间。

第 3 步：逻辑判断

识别结果上传到服务器 / 云平台与数据库比对：

车辆类型比对结果处理方式
月卡 / 储值车在白名单且在有效期内直接开闸，记为「入场」
临时车未被禁止新建入场记录（车牌、时间、入口相机 ID），开闸并开始计时
黑名单车命中黑名单不输出开闸信号，需人工处理
无牌车算法无法识别系统不动，需扫码或人工取票

第 4 步：放行

道闸控制器收到开闸指令后驱动电机抬杆，闸杆到垂直位触发「开限位开关」，电机断电停止，车辆通行。

第 5 步：安全防砸

车辆在杆下时，地感持续输出「有车」信号，强制道闸保持抬起；红外对射或压力波被触发时立即反弹归位。

第 6 步：自动落杆

车辆完全驶离防砸线圈范围后「有车」信号消失，控制板延时（1~3 秒可调）后自动落杆，触发「关限位开关」后停止，系统复位等待下一辆车。

出场流程​

提示
  1. 车辆驶入出口识别区，地感 / 雷达触发抓拍
  2. 相机识别车牌，系统调取该车的入场记录
  3. 按收费标准计算停车时长与费用
  4. 判断放行条件：
    • 月卡车：有效期内直接开闸
    • 临时车：已缴费（现场扫码 / 无感支付 / ETC / 中央收费）→ 开闸
    • 未缴费临时车：显示缴费金额与二维码，缴费完成后开闸
    • 超时未缴 / 黑名单：拦截，人工处理
  5. 开闸 → 防砸 → 车辆驶离 → 自动落杆

特殊情况处理​

跟车（前车已识别、后车未识别）
  • 开启「双向」运动方向，倒车时可补识别
  • 增加辅助相机（主辅模式）
  • 合理设置识别区域，确保后车进入识别区
无牌车 / 车牌严重污损
  • 引导车主扫入口二维码取票或扫码入场
  • 部分系统支持车型 / 车标识别辅助匹配
  • 人工岗亭处理
车牌遮挡 / 套牌逃费
  • 开启车牌防伪功能（可选「告警」或「过滤」）
  • 防伪匹配度越高，拦截强度越强，但可能略微影响正常车通行
车辆折返

车辆识别后又倒回，系统会产生一条无效入场记录。主流相机（如 B 系列 87C）已支持车辆折返事件检测，可自动清理。

无人值守要点​

提示

要让车场真正做到无人值守，需要保证：

  • 识别率足够高（≥99%），减少异常拦截
  • 支付渠道完善（微信、支付宝、ETC、无感支付）
  • 配备可视对讲 / 云坐席，应对异常情况
  • 道闸防砸可靠（地感 + 雷达 / 红外双保险）
  • 断网脱机可用：相机本地白名单判断，网络恢复后数据自动补传

车位引导与反向寻车​

提示

车位引导：每个车位安装超声波探测器或视频车位相机，实时判断车位状态，通过 RS485 或网络上传到引导控制器，驱动区域引导屏与车位指示灯（绿灯空 / 红灯占）。

  • 相机数量 = 总车位数 ÷ 单相机覆盖车位数（200 万像素相机通常覆盖 2~3 个斜列式车位）
  • 引导屏数量 ≈ 主要岔路口数量 + 1

反向寻车：车主停车时，系统记录「车牌号 ↔ 车位编号」的对应关系；车主在查询机输入车牌或扫码小程序，即可看到停车位置与最优寻车路径。
