常见故障排查

排查思路​

提示

车牌识别系统出问题，按「前端识别 → 信号输出 → 道闸执行 → 平台联动」四段逐段排查，比盲目换件高效得多。

推荐工具：万用表（蜂鸣档）、网线测试仪、笔记本电脑、备用网线、备用电源。

一、相机不识别 / 识别率低​

现象可能原因处理
完全不识别未触发抓拍检查地感信号、虚拟线圈位置、触发模式配置
完全不识别相机时间偏差过大同步相机时间（平台指令会因时间差被拒绝）
白天好、夜晚差补光灯不亮或亮度不足检查补光灯供电与补光模式，夜间测试亮度
逆光识别差正对强光源调整安装角度，开启宽动态，加遮阳罩
个别车牌识别错车牌像素不在 160~200调焦距或调整识别距离
识别慢画面中运动物体多在识别区域绘制中排除干扰区
识别正确但车型判断错算法限制升级算法包 / 固件
注意

车牌防伪功能开启过强时，会误判部分正常车牌。若识别率明显下降，可先关闭防伪对比测试。

二、识别成功但道闸不抬杆​

按下面顺序排查：

提示

第 1 步：确认相机有没有输出

万用表蜂鸣档接相机 COM 与 OUT1：

  • 静态：不鸣叫（常态断开）
  • 识别瞬间：鸣叫、阻值接近 0，约 1 秒后断开 → 相机输出正常
  • 全程不鸣叫 → 相机无输出，检查输出联动配置

也可在相机网页后台「外设管理 → 输出联动 → 手动开闸」测试，听继电器是否有「咔哒」声。

第 2 步：确认线路

起闸线两端是否接牢，中间有无断点。可直接短接道闸主板【公共】+【起】测试。

第 3 步：确认道闸主板

  • 短接能抬杆 → 主板正常，问题在前端
  • 短接不抬杆 → 检查主板供电、遥控学习、限位、电机
四种典型结果
  1. 有继电器声、万用表导通、道闸不抬杆 → 线路断线或道闸主板故障
  2. 有继电器声、万用表不导通 → 继电器触点烧蚀
  3. 无继电器声、万用表无变化 → 继电器线圈坏或驱动电路坏
  4. 日志有「输出 IO 触发」但不抬杆 → 相机正常，查线路与道闸

三、道闸故障​

现象可能原因处理
通电无反应电源未接好、保险丝熔断测输入端电压，更换同规格保险丝
电机转但杆不动电机线接错 / 缺相、机械卡死检查 U/V/W 接线，检查机械传动
杆到位不停限位未学习好、霍尔线松动重新限位学习，检查 HU/HV/HW 接线
不落杆地感一直有信号、无地感落杆时间设置过长检查地感、调整 P-32 / P-33
落杆砸车防砸失效检查地感、红外、压力波、雷达
遥控失灵未学习 / 电池没电重新学习遥控器，更换电池
反复起落地感误触发调整线圈匝数与埋深，信号线远离强电

四、屏显与语音故障​

现象可能原因处理
屏幕完全不显示485 A / B 接反对调 A、B（A 对 A、B 对 B）
屏幕不显示波特率不一致控制卡与相机 485 波特率设为一致
屏幕不显示屏显协议类型选错在相机后台重新选择对应协议
屏幕不显示控制卡无供电检查 5V / 12V 供电
有显示无语音喇叭线接反喇叭分正负，对调
有显示无语音音量设置为 0检查硬件旋钮与软件音量
显示乱码 / 缺字屏型扫描方式不匹配、排线松动重设屏型参数，重新插拔排线
白天正常晚上断485 干扰用屏蔽双绞线，降低波特率
注意

不同品牌控制卡的默认波特率不同：多数 LED 控制卡为 9600，部分 LCD 控制卡为 19200。控制卡通电时屏幕第一行通常会显示当前固件版本与波特率，可据此核对。

五、网络与平台故障​

现象可能原因处理
网页打不开相机电脑与相机不同网段把电脑 IP 改到相机网段
网页打不开网线 / 水晶头问题看网口指示灯，重做水晶头
频繁掉线IP 冲突ping 检测，改用 IP 绑定
频繁掉线交换机故障更换交换机
客户端搜不到网段不对电脑设自动获取 IP 后搜索
平台上看不到设备MQTT / 服务器参数错误核对域名、端口、停车场 ID
名单下发不生效相机时间不同步配置 NTP 并校准时间
脱机后有声音、联机没声音屏显协议 / 串口号配置检查串口号与输出接口勾选
忘记 IP 或密码
  • 忘记 IP：电脑设为自动获取，用客户端搜索；或查看机身标签
  • 忘记密码：机身 / 内部标签有初始账号密码；修改过则需硬件复位
  • 复位方法：打开设备外盖，用工具通过圆孔长按电路板上复位键，待 LED 闪两下松开，重启后恢复出厂（一般长按 5~10 秒）
  • 常见默认账号密码：admin / admin

六、应急处理​

危险
  • 道闸突发故障无法抬杆：先断电，用摇把从闸箱后部小孔插入手动摇起闸杆（或停电后手动抬杆），恢复通行后再排查
  • 涉及 220V 强电排查必须断电操作，非专业人员请勿带电作业
  • 雷雨季节检查接地与防雷器，避免雷击损坏主板
信息

本文内容整理自行业公开维修与调试资料，具体故障请以现场实际检测为准，涉及设备拆修请联系供应商或厂家技术支持。
