现场安装规范

相机安装定位规范​

这是决定识别率的第一要素

设备再好，装歪了也白搭。下面每一条都是现场踩坑总结出来的。

关键尺寸​

项目推荐值说明
识别距离（车牌到镜头）36m，**推荐 44.5m**太近抬杆来不及、补光过曝；太远车牌像素不足
车道宽度≤ 4m超过 4m 需增加辅助相机
安装高度小车为主：1.4~1.7m
大货车为主（地磅）：1.6~2.0m		以车牌在画面中居中为准
俯角15°~40°配合三维万向节调节
侧角小于 30°相机正对来车方向，减少车牌形变
车牌像素宽度160~200调试时在相机后台查看，超出范围需调节焦距或距离
提示

调节时的正确顺序：先调距离与高度 → 再用三维万向节让车牌在画面中水平居中 → 最后调焦距使车牌像素宽度落在 160~200。

注意：相机装在道路一侧，为了车牌水平，相机本身看起来会有点歪，这是正常现象，不要为了相机"看起来正"而牺牲车牌水平。

场景化布局原则​

提示
  1. 长直通道：车牌识别一体机与道闸可就近布置，减少施工量
  2. 大角度转弯：一体机应布置在正对来车方向的位置，减少相机与车牌之间的角度
  3. T 型路口：若转弯半径不足让车辆在识别区前摆正车身，需在道路两侧各配一台识别机
  4. 强逆光环境：尽量避免正对西晒 / 强光源；无法避免时选用宽动态相机并合理补光
  5. 路边长期停车：识别区必须把该位置排除在外，避免误识别

虚拟线圈（识别区）设置​

提示
  • 虚拟线圈顶线设定在取景框下部 1/3 处，并保持水平
  • 识别区域应尽量扩大以提升识别速度，但要避开无效区域（道路过路车、常停车位）
  • 让车辆停在虚拟线圈顶线处，调节万向节使线圈与车牌水平、车牌居中

补光灯安装​

提示
  • 补光灯一般集成在一体机内，环境复杂时可外置
  • 补光灯基于图像分析算法控制，比传统光敏电阻更稳定
  • 常规设为「智能补光」；地下车库长期无光或强逆光可设「手动补光」
  • 补光参数按现场识别距离设定，相机会自动调节亮度
  • 补光灯可分时段控制开关，节省能耗

道闸安装​

注意
  • 装好闸杆后方可通电，否则可能造成安装困难、控制主板损坏，甚至人员受伤
  • 道闸应安装在水平坚实地面，用膨胀螺丝固定
  • 闸杆下方地面需预埋防砸地感线圈
  • 广告道闸需注意杆长与主板功率匹配（重型闸机选大功率主板）

地感线圈施工规范​

提示
  1. 用墨斗弹线，切割机切槽：槽宽约 2mm，槽深 3cm（馈线槽宽 4mm）
  2. 清理槽内尖锐水泥渣，避免刺破线圈
  3. 地感线绕 4~6 匝埋入槽中
  4. 预留的馈线部分需双绞，每米不少于 30 绞，放入馈线槽
  5. 馈线引入道闸后还需预留约 1m
  6. 槽底需平整，回填时注意保护线材
注意

线圈匝数与埋深直接影响灵敏度：匝数 46 匝，埋深 510cm。误触发或不落杆时优先检查这两项。

立柱与基础​

提示
  • 一体机常用高杆安装方式，离地 1.4m 以上
  • 立柱基础需预埋件或膨胀螺丝固定，浇筑混凝土
  • 所有室外线缆穿 PVC 管保护，管口做防水处理
  • 机箱做好接地，雷雨多发区加装防雷器

安装后自检清单​

#检查项合格标准
1车牌像素宽度160~200
2车牌在画面中水平、居中
3虚拟线圈位于取景框下 1/3，避开干扰区
4补光灯夜晚自动点亮，无过曝
5识别测试连续 20 车次，识别率 100%
6开闸测试识别后道闸正常抬起
7防砸测试杆下站人 / 放车，闸杆不落或反弹
8落杆测试车辆驶离后自动落杆
9屏显与语音车牌、费用、欢迎语显示播报正常
10断网测试断网后白名单车仍可通行，恢复后数据补传
11相机时间与北京时间一致（否则平台指令不生效）
信息
