## 常用线材

| 用途 | 线材规格 | 说明 |
|------|----------|------|
| 电源 | RVV 2×1.0 | 220V 供电，注意区分零火线 |
| 网络 | 超五类 / 六类 8 芯网线 | 相机、交换机、电脑组网 |
| 信号（起闸 / 屏显） | RVVP 2×0.5（可用网线代替） | 屏蔽线，抗干扰 |
| 地感线圈 | 防腐蚀地感线（50m/卷） | 专用线材，不可用普通线替代 |
| 喇叭 | RVV 2×0.5 | 注意正负 |

:::tip
其他辅材：水晶头、交换机、膨胀螺丝、PVC 套管、水泥和中砂（线槽回填）。

工具：电锤、切割机、电动螺丝刀、手磨机、网线钳、网线测试仪、万用表、墨斗、卷尺、剥线钳、活动扳手、内六角扳手、电笔、螺丝刀、水平尺。
:::

## 开槽布线

:::tip
1. 按规划设计尺寸用墨斗在地面弹线
2. 切割机沿墨线切割，**深度 3cm**，电锤去除槽内水泥，槽底尽量平整
3. 按现场长度与转角切割 PVC 线管，放入线槽
4. 将线材穿入线管，两端预留长度：
   - 值班室 → 道闸：电源线与网线，道闸端预留 **1m**
   - 道闸 → 车牌识别机：电源线、网线、信号线，道闸端预留 **1m**，相机端预留 **2m**
5. 地感线圈单独布线（见安装规范）
:::

## 电源接线

:::danger
**接线完成前不可通电**，避免强电伤人或损坏设备。
:::

:::tip
1. 从值班室过来的电源线接入道闸空开**进线端**
2. 从空开**出线端**分出各支线：
   - 道闸主板支线 → 主板 **L / N** 接线端
   - 车牌识别机支线 → **L / N**
   - 车检器支线 → **1 / 2** 接线端（不区分正反）
   - 交换机电源 → 220V 输入端
:::

## 网线接线

:::tip
- 值班室 → 道闸：值班室端插入交换机（不接外网时可直接插电脑网口），道闸端插入道闸内交换机
- 道闸 → 车牌识别机：两端分别插入道闸内交换机与相机网口
- 水晶头按 T568B 标准制作，做好后用网线测试仪验证
:::

## 起闸线接线

:::warning
起闸线两端分别接**车牌识别机的起闸接口**与**道闸主板的起闸接口**，**接线不分正反**。

| 设备端 | 端子标识 |
|--------|----------|
| 道闸主板 | **【公共】+【起】** |
| A 系列相机 | **ALARM-OUT1** |
| B 系列相机 | **O1+ / O1-** |
| C 系列相机 | **【公共】+【起闸】** |
:::

## 屏显线接线

:::warning
屏显线传输车牌识别相机的**语音和显示信号**。一体式车牌识别出厂已接好，分体式需现场接。

从相机到车牌识别控制卡：**A 对应 A，B 对应 B，绝对不能接反**。接反表现为屏幕完全无显示或乱码。
:::

## 地感车检器接线

| 端子 | 接法 |
|------|------|
| **1 / 2** | AC 220V 电源，不分正反 |
| **7 / 8** | 地感线圈馈线，不分正反 |
| **3 / 4** | 接道闸主板【公共】和【地感】端子，不分正反 |

## 标准一进一出布线要点

:::tip
- 入口与出口各一套：识别一体机 + 道闸 + 车检器
- 两端通过交换机组网，与管理电脑同一局域网
- 摄像机与道闸之间距离不宜过远，减少起闸线损耗与干扰
- 强弱电分离走线，信号线远离 220V 电源线，避免干扰
:::

## 验收测试

| # | 测试项 | 方法 | 合格标准 |
|---|--------|------|----------|
| 1 | 网线通断 | 网线测试仪 | 8 芯全通 |
| 2 | 电源电压 | 万用表 | 220V ±10% |
| 3 | 地感线圈 | 车检器指示灯 | 车辆压过有反应 |
| 4 | 起闸信号 | 万用表蜂鸣档测 COM 与 OUT1 | 识别瞬间导通 |
| 5 | 屏显通信 | 观察屏幕 | 车牌、费用正常显示 |
| 6 | 网络连通 | ping 相机 IP | 无丢包、无延时 |
| 7 | 全程联调 | 连续过车 20 次 | 识别、开闸、落杆全正常 |

:::warning[IP 冲突]
多台设备同时使用时，务必确保每台相机 IP 唯一。判断方法：先断开设备，在电脑上 ping 该 IP，能 ping 通说明该 IP 已被占用。建议采用 IP 绑定避免冲突。
:::
