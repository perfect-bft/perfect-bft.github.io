系统组成与工作原理

什么是车牌识别系统​

提示

车牌识别停车系统（业内简称 VLPR 系统）以计算机视觉、数字图像处理、模式识别技术为基础，通过高清摄像机采集车辆图像并自动识别车牌号码，实现车辆自动识别、计费和管理。

相比早期的刷卡、蓝牙识别，车牌识别属于被动识别——车主无需停车取卡、无需提前开蓝牙，车辆开进识别区即自动完成识别，这是它能成为主流方案的关键。

系统分层​

整个系统可以拆成四层，业内常用一个比喻：相机是眼睛，主板是大脑，道闸是手臂。

层级作用主要设备
触发感知层发现有车到了地感线圈、车辆检测器、微波 / 激光雷达、视频虚拟线圈
图像采集与识别层看清并认出车牌车牌识别一体机（相机 + 补光灯 + AI 算法）
控制与逻辑判断层比对名单、决定是否开闸相机主板、道闸控制主板、上位机 / 云平台软件
执行与安全防护层抬杆、防砸、落杆道闸机、地感线圈、红外对射、压力波、雷达

核心设备清单​

出入口必备设备​

提示
  • 车牌识别一体机：含相机、补光灯、AI 算法，部分集成显示屏与喇叭
  • 自动道闸：含闸杆、电机、控制器（控制主板）
  • 车辆检测器：地感线圈或雷达
  • 入口控制机（可选）：含显示屏、语音喇叭
  • 户外防水机箱、交换机、UPS（可选）

场内设备（车位引导 / 反向寻车）​

提示
  • 超声波探测器 或 视频车位相机（按车位安装）
  • 车位指示灯（绿灯空位 / 红灯占用）
  • RS485 总线或网络交换机
  • 车位引导控制器
  • 区域 / 总余位引导屏
  • 寻车查询终端（触摸屏）

识别算法流程​

相机抓拍到车辆图像后，算法按以下三步完成识别：

提示
  1. 车牌定位：从画面中框出车牌所在区域
  2. 字符分割：把车牌上的汉字、字母、数字逐个切分开
  3. 光学字符识别（OCR）：把切分出的图像字符转换成计算机文本

同时在抓拍前会对图像做预处理：噪声过滤、自动白平衡、曝光调整、宽动态合成，以应对逆光、夜间、雨雾等复杂环境。

识别率指标​

指标行业水平说明
综合识别率≥ 99%（主流 99.8%~99.9%）正确识别车牌数 / 总识别车牌数 × 100%
综合抓拍率≥ 99.9%车辆被成功抓拍的比例
白天识别率> 99%配合宽动态与智能补光
夜间识别率≥ 95%~98%取决于补光灯与环境光
识别速度几百毫秒含抓拍、识别、比对、下发开闸全过程
注意

识别率是场景相关的，不是设备固有指标。安装角度、车牌像素大小、补光、车道宽度都会显著影响实际识别率。现场调试到位比单纯堆参数更重要。

与道闸的联动关系​

提示

车牌识别相机与道闸主板之间只有一对开关量信号线（相机开闸输出 → 道闸【公共】+【起】），接线不分正负。

  • A 系列相机：端子标识 ALARM-OUT1
  • B 系列相机：端子标识 O1+ / O1-
  • C 系列相机：端子标识 【公共】+【起闸】

屏显与语音则通过 RS485（A 对 A、B 对 B）传输，且波特率必须与相机一致。
