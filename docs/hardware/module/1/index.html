4G免流控制模块

应用场景​

注意

主要应用于各类道闸设备，门禁设备的远程控制开关闸或者定时常开的功能，应用广泛

接线说明​

提示
  • 模块为宽压支持12V/24V电源，12/24V接电源正极，GND接负极
  • 开+公共为开门输出/常开输出
  • 关+公共为关门输出

使用方法​

提示

首先扫码机身小程序码进入小程序乐勤开关

提示

进入小程序后点击右下上角 ➕ ，然后注册账号，注册完成后 一键登录

提示

登录完成后再次点击右上角的➕，然后点击扫码 ，扫描模块背部的二维码绑定

提示

绑定完成后即可正常工作

  • 点击开门 开和公共会输出1秒继电器信号
  • 点击关门 关和公共会输出1秒继电器信号
  • 点击常开 开和公共会输出持续继电器信号，再次点击开门可以关闭继电器信号
  • 点击定时 可以设置定时常开继电器信号

状态说明​

提示
  • 在线：模块供电和网络稳定在线
  • 离线：模块离线
  • 门已开：点击过开门后
  • 门已关：点击过关门后

其他功能​

提示
  • 设备分享：可以把模块分享给其他用户，共同使用
  • 分享管理：可以管理分享的用户，取消分享
  • 手机开门记录：可以看到开关门的明细和时间
