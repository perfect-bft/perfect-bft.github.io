## 什么是继电器控制模块

:::tip
继电器是一个**用小电流控制大电流的电磁开关**。在停车场系统里，它的核心作用是：

1. **弱电控制强电**：用相机/主板的 12V 小信号，去控制 220V 的道闸电机、LED 屏、补光灯
2. **信号隔离**：把两套电路在电气上完全隔开，避免干扰和窜电烧毁
3. **触点扩展**：一个主板输出口通过继电器扩展成多路控制
4. **信号反相**：把常开信号转成常闭，或反之
:::

## 工作原理

:::info
继电器内部就是一个**电磁铁 + 机械触点**：

1. 线圈通电 → 产生磁场
2. 磁场吸合衔铁 → 带动触点动作
3. 常闭触点（NC）断开，常开触点（NO）闭合
4. 线圈断电 → 弹簧复位，触点回到初始状态

**关键特性：线圈和触点之间没有电气连接，只有机械联动**——这就是"隔离"的来源。
:::

## 三个核心触点

| 触点 | 全称 | 常态（线圈未通电） | 线圈通电后 |
|------|------|------------------|-----------|
| **COM** | Common 公共端 | — | — |
| **NO** | Normally Open 常开 | **断开** | **闭合导通** |
| **NC** | Normally Closed 常闭 | **导通** | **断开** |

:::tip
记忆口诀：**NO = 不通，通电才通；NC = 常通，通电才断。**

用万用表蜂鸣档测：线圈没电时，COM-NC 应该响（导通），COM-NO 不响（断开）。
:::

## 技术参数

### 线圈侧（控制端）

| 参数 | 常见取值 |
|------|----------|
| 线圈电压 | **DC5V / DC12V / DC24V**（直流）；AC220V（交流） |
| 线圈功率 | 0.2W ~ 0.9W |
| 吸合电流 | 12V 继电器约 30~75mA |
| 吸合电压 | 额定电压的 75% 以上 |
| 释放电压 | 额定电压的 10% ~ 30% |
| 线圈电阻 | 12V 一般 160Ω ~ 400Ω（可测量判断好坏） |

:::warning
**一个 12V 继电器的线圈电流约 30~75mA，相机/主板的单个 IO 口往往驱动不了**，需要通过三极管或光耦驱动，或者直接选**带驱动电路的继电器模块**。

直接把继电器线圈接到相机 IO 口上，很可能烧坏 IO 口。
:::

### 触点侧（负载端）

| 参数 | 常见取值 |
|------|----------|
| 触点容量（阻性） | 10A / 250VAC；10A / 30VDC |
| 触点容量（感性） | **约为阻性的 1/4 ~ 1/5**（如 2~3A / 250VAC） |
| 接触电阻 | 小于 100mΩ（新） |
| 机械寿命 | 1000 万次以上（空载） |
| 电气寿命 | **10 万次左右**（带额定负载） |
| 吸合时间 | 5 ~ 15ms |
| 释放时间 | 5 ~ 10ms |

:::danger[感性负载必须降额]
**道闸电机、电磁锁、电磁阀都是感性负载**，断开瞬间会产生**反向高压电弧**（可达几百伏），这会：
- 烧蚀触点，导致触点粘连
- 产生强烈电磁干扰，让相机/主板死机

**处理办法：**
1. 触点容量按 **额定值的 1/4** 选型（如电机 3A，选 10A 继电器）
2. 在**触点两端并联 RC 吸收回路**（典型 100Ω + 0.1μF）或**压敏电阻**
3. 交流负载用专用 RC 模块，直流负载用**续流二极管**
4. 大功率电机**必须通过交流接触器**中转，不要直接用继电器带
:::

## 继电器模块 vs 裸继电器

| 对比 | 裸继电器 | **继电器模块**（推荐） |
|------|----------|---------------------|
| 驱动 | 需要自己加三极管、续流二极管 | **自带光耦隔离 + 驱动电路** |
| 输入 | 必须匹配线圈电压 | 3.3V / 5V / 12V / 24V 多规格，部分宽压 |
| 保护 | 无 | **自带续流二极管、保险丝、光耦隔离** |
| 指示 | 无 | **带 LED 状态灯**（通电/吸合一眼可见） |
| 接线 | 要焊接 | **螺丝端子，免焊接** |
| 触发电平 | 固定 | 可跳线选择**高电平触发 / 低电平触发** |

:::tip
**现场施工一律用继电器模块，不要用裸继电器。**

多花十几块钱，换来光耦隔离、续流保护、状态指示、免焊接，还能避免烧主控 IO 口——这笔账非常划算。
:::

## 典型应用接线

### 应用一：相机开闸信号控制道闸

:::info
**场景**：相机识别成功后输出一个 12V 开闸信号，但道闸主板需要的信号形式不同（如需无源干接点）。

**接法**：
1. 相机开闸输出正 → 继电器模块 **IN+**
2. 相机 GND → 继电器模块 **IN-**（必须共地）
3. 继电器模块 **COM** → 道闸主板开闸端子 1
4. 继电器模块 **NO** → 道闸主板开闸端子 2

相机输出信号 → 继电器吸合 → COM-NO 导通 → 相当于把主板开闸端子短接 → 道闸抬杆。
:::

### 应用二：信号反相（NO 转 NC）

:::tip
**场景**：设备输出常开信号，但主板要求常闭输入（防砸信号常用）。

**接法**：把信号接到继电器线圈，然后从 **COM 和 NC** 取输出。

- 信号无效（无车）→ 继电器不吸合 → COM-NC 导通 → 主板收到"导通"
- 信号有效（有车）→ 继电器吸合 → COM-NC 断开 → 主板收到"断开"

这样就完成了反相。
:::

### 应用三：一路扩展多路

:::info
**场景**：一个开闸信号需要同时控制道闸、LED 屏、语音模块。

**接法**：把同一个信号并联到多个继电器模块的输入端，各模块的触点分别接不同设备的控制端。

注意：并联的模块数量受**信号源驱动能力**限制，超过 3~4 个建议加一级缓冲或用带缓冲的分配模块。
:::

### 应用四：控制 220V 设备（补光灯、LED 屏）

:::danger
**接法**：
1. 220V 火线 L → 继电器 **COM**
2. 继电器 **NO** → 设备火线输入端
3. 220V 零线 N → 设备零线输入端（**不经过继电器**）

**安全红线：**
- **必须断开火线（L），严禁断开零线（N）**——断零线会导致设备外壳带电
- 强电部分必须装在**独立的绝缘接线盒**内，加装**空开或保险丝**
- 接线盒贴**高压危险标识**
- 弱电（继电器线圈）和强电（220V 触点）的走线**严格分开**，不得同管
- 施工前**必须断电验电**
- 户外必须做好防水，接线盒防护等级不低于 IP65

:::warning
**不持有电工证的人员不得操作 220V 强电接线，必须由持证电工完成。**
:::

## 选型清单

:::tip
买继电器模块前先确认这 6 项：

1. **线圈/输入电压**：5V / 12V / 24V？要和你的控制信号一致
2. **触发方式**：高电平触发还是低电平触发（买可跳线的最保险）
3. **触点容量**：感性负载按 1/4 降额后仍要够用
4. **路数**：1 路 / 2 路 / 4 路 / 8 路 / 16 路
5. **隔离方式**：是否带光耦隔离（强烈建议要）
6. **输出形式**：是否同时引出 NO/NC/COM（必须三个都有才灵活）

**推荐配置**：12V 输入、8 路、带光耦隔离、高低电平可跳线、带 LED 指示的模块 —— 通用性最强。
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| **完全没有反应** | 输入电压不对 / 触发电平设错 / 未共地 | 测输入电压、调整触发跳线、接共地 |
| **LED 亮但触点不通** | 触点烧蚀 / 接线接错端子 | 换继电器、核对 COM/NO/NC |
| **继电器吸合后不断开**（粘连） | 感性负载电弧烧粘 / 超载 | 加 RC 吸收或续流二极管、加大容量、换新的 |
| **动作几次后失效** | 触点过载烧毁 | 换大容量继电器或加交流接触器 |
| **干扰导致相机/主板死机** | 感性负载无保护 | **加 RC 吸收回路/续流二极管**、强弱电分开走线 |
| **继电器发热严重** | 线圈电压偏高 / 频繁动作 / 触点过载 | 核对电压、降低动作频率、加大容量 |
| **吸合声音异常（嗡嗡响）** | 电压不足 / 铁芯有异物 | 提高电压至额定值、更换 |
| **多路互相影响** | 共地环路 / 电源功率不足 | 检查共地、加大电源功率 |
| 使用一段时间后接触不良 | 触点氧化 | 更换继电器，选用密封型 |

:::tip[用万用表快速判断继电器好坏]
1. **测线圈**：电阻档测线圈两端，应有几百欧姆阻值（12V 一般 160~400Ω）。**无穷大 = 线圈开路，0Ω = 短路，都是坏的**
2. **测触点（未通电）**：蜂鸣档测 COM-NC 应**响**；COM-NO 应**不响**
3. **测触点（通电）**：给线圈加额定电压，应听到"咔哒"一声；此时 COM-NC **不响**，COM-NO **响**

三步全过 = 继电器正常。任何一步不对就更换。
:::

## 维护建议

:::info
- **每年检查一次**触点是否有烧蚀发黑痕迹
- 频繁动作的继电器（如道闸开闸，每天几百次）建议 **2~3 年预防性更换**
- 保持接线盒干燥，潮湿会加速触点氧化
- 备用 1~2 个同型号模块在现场，故障时能立刻替换
- 记录每个继电器的**用途和编号**，贴在接线盒上，后期维护能省大量时间
:::
