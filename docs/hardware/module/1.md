## 应用场景
:::warning[注意]
主要应用于各类道闸设备，门禁设备的远程控制开关闸或者定时常开的功能，应用广泛
:::
## 接线说明
:::tip
- 模块为宽压支持12V/24V电源，12/24V接电源正极，GND接负极
- 开+公共为开门输出/常开输出
- 关+公共为关门输出
:::
## 使用方法
:::tip
首先扫码机身小程序码进入小程序<span style={{ color: "#f44336" }}><b>乐勤开关</b></span>
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/940a98b4d3_98cf147f2d9993a52c6f77ec5093e966.png)
</div>
:::tip
进入小程序后点击右下上角 **➕** ，然后注册账号，注册完成后 **一键登录**
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/2697f7f04b__E5_B9_B3_E6_B6_82.png)
</div>
:::tip
登录完成后再次点击右上角的➕，然后**点击扫码** ，<span style={{ color: "#f44336" }}><b>扫描模块背部的二维码绑定</b></span>
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/8daafc646c_deb27d72-c50f-4784-8390-65d96c644754.png)
</div>
:::tip
绑定完成后即可正常工作
- 点击**开门** 开和公共会输出1秒继电器信号
- 点击**关门** 关和公共会输出1秒继电器信号
- 点击**常开** 开和公共会输出持续继电器信号，再次点击**开门**可以关闭继电器信号
- 点击**定时** 可以设置定时常开继电器信号
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/93605bc0ab_1ff17f80-7e84-48a4-a9ce-90e8d669bb26.png)
</div>

## 状态说明
:::tip
- 在线：模块供电和网络稳定在线
- 离线：模块离线
- 门已开：点击过开门后
- 门已关：点击过关门后
:::
<div class="img-hover-container">
![Docs Version Dropdown](/img/remote/af0e210336_ed794520-03e3-466b-b8ff-8ac58c2640b3.png)
</div>

## 其他功能
:::tip
- 设备分享：可以把模块分享给其他用户，共同使用
- 分享管理：可以管理分享的用户，取消分享
- 手机开门记录：可以看到开关门的明细和时间
:::
