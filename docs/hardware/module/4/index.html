读卡感应模块

什么是读卡感应模块​

提示

读卡感应模块（读卡器 / 读头）通过射频信号读取ID 卡或 IC 卡的卡号，转换成**韦根（Wiegand）**或 RS485 信号送给控制主板，由主板比对权限后决定是否开闸。

在车牌识别普及之前，这是出入口的绝对主流方案。现在虽然车牌识别是主力，但读卡模块仍在以下场景大量使用：

  • 车牌识别失败的兜底通行手段
  • 内部车辆、月卡车刷卡进出
  • 人脸识别设备的人证比对辅助
  • 门禁、梯控、通道闸

ID 卡 vs IC 卡​

对比项ID 卡IC 卡
工作频率125kHz（低频）13.56MHz（高频）
卡片类型EM4100 / TK4100 等Mifare S50 / S70 / CPU 卡
存储容量只读卡号，不可写（64bit）可读写，S50 有 1KB 分区存储
安全性低，卡号明文，极易复制较高，可分扇区加密，CPU 卡更高
感应距离5 ~ 15cm0 ~ 5cm
卡片成本极低低
读卡器成本低略高
典型应用老小区门禁、简易停车场一卡通、消费、梯控、加密门禁
选型红线
  • ID 卡号可以被轻易复制（淘宝十几块钱的拷贝机），绝不能用于有安全要求的场合
  • 新建项目一律选 IC 卡（最好是 CPU 卡）
  • ID 卡读头和 IC 卡读头不通用，125kHz 读头读不了 13.56MHz 的卡，采购时务必确认频率

技术参数（典型）​

参数常见取值
支持卡型ID（EM4100/TK4100）或 IC（Mifare S50/S70），部分双频兼容
工作频率125kHz / 13.56MHz
读卡速度小于 0.2 秒
感应距离ID：5 ~ 15cm；IC：0 ~ 5cm
工作电压DC5V ~ DC15V（标准 DC12V）
工作电流30mA ~ 100mA
输出格式韦根 WG26 / WG34（默认多为 WG26）
通讯距离韦根 100m；RS232 10m；RS485 1000m
工作温度-25℃ ~ +75℃
防护等级室内 IP54；户外必须选 IP65 以上
信息

通讯距离差异是选型时最容易被忽略的点：

  • 韦根信号是 TTL 电平脉冲，传输距离极限约 100m（实际建议不超过 80m）
  • 如果读卡器离主板很远（超过 80m），必须选 RS485 输出的读头，或者中间加韦根转换器

韦根协议（Wiegand）​

是什么​

提示

韦根是门禁行业的事实标准接口，用两根数据线（D0 和 D1）传输卡号：

  • D0 线上出现一个低脉冲 → 输出一个二进制 0
  • D1 线上出现一个低脉冲 → 输出一个二进制 1

两根线平时都被上拉为高电平（一般上拉到 5V 或 12V），靠拉低来传输数据。

WG26 帧结构（26 位）​

位内容
第 1 位偶校验位（前 12 位）
第 2 ~ 9 位** facility code / 区号（8 位）**
第 10 ~ 25 位卡号（16 位）
第 26 位奇校验位（后 12 位）
信息

WG26 的卡号范围是 0 ~ 65535，区号 0 ~ 255。同一个区号下卡号只有 65536 个，对于大型项目可能不够，这时用 WG34。

WG34（34 位）把卡号扩展到 24 位（0 ~ 16777215），是现在新建项目的推荐格式。

韦根 26 与 34 的兼容​

注意
  • 读卡器侧：多数读头通过一根跳线/接线选择输出 WG26 还是 WG34
  • 主板侧：主板也要设置成对应的接收格式，两边必须一致
  • 常见故障：读头设成 WG34，主板设成 WG26 → 读到的卡号完全对不上，或者干脆读不到
  • 不确定时，两边都先设成 WG26（兼容性最好）

接线定义（标准线色）​

标准的韦根读卡器引出线颜色定义（绝大多数厂家通用）：

线色定义说明
红+12V电源正极（DC12V）
黑GND电源负极，必须与主板共地
绿D0韦根数据 0
白D1韦根数据 1
蓝LED指示灯控制（主板拉低 = 亮红灯/绿灯，按型号）
黄BEEP蜂鸣器控制（主板拉低 = 蜂鸣）
灰WG26/34 选择悬空或接 GND 切换格式，看说明书
危险
  • 不同厂家线色可能不同，接线前必须核读卡器标签或说明书，不要想当然
  • LED 和 BEEP 线必须接对极性，部分读头是低电平触发，接错会一直响或一直亮
  • 韦根线（D0/D1）严禁与强电同管走线，干扰会导致卡号错乱
  • 读卡器供电不要从电机电源取，电机启停的干扰会造成读卡器死机

安装规范​

提示
  1. 安装高度：距地面 1.2m ~ 1.4m（方便驾驶员伸手刷卡）
  2. 安装位置：车道右侧（驾驶员侧），距道闸 2~3m
  3. 避开金属：读卡器不能直接装在金属板上，金属会屏蔽射频场，导致感应距离骤降甚至完全读不到。必须装时在金属与读卡器之间垫 10mm 以上塑料/亚克力板
  4. 避开干扰源：远离变频器、电机、LED 屏驱动、对讲机天线
  5. 多台间距：两台读卡器间距不小于 50cm，否则射频场互相干扰
  6. 防水：户外必须选 IP65 防水读头，进线口朝下并打防水胶
  7. 走线：韦根线用屏蔽双绞线，屏蔽层单端接地
金属屏蔽是最常见的安装事故

遇到"读卡距离特别短"或"卡片要贴上去才读得到"，十有八九是背后有金属。

排查方法：把读卡器从安装位置拆下来，悬空拿在手里测试。如果悬空正常、装上去不行，就是金属屏蔽问题，加绝缘垫片解决。

与主板/相机对接​

接道闸控制主板​

信息
  1. 主板设置为韦根输入模式（部分主板需要在菜单里切换）
  2. 确认 WG26/WG34 与读头一致
  3. 接线：红→12V，黑→GND，绿→主板 WG D0，白→主板 WG D1
  4. 刷卡测试，主板应有蜂鸣/指示灯反馈
  5. 在主板或平台里登记卡号（授权）

接车牌识别相机​

部分相机提供韦根接口，用于：

  • 刷卡辅助识别（车牌识别失败时刷卡）
  • 人证比对（身份证阅读器 + 人脸相机）
提示

相机侧需要在后台开启韦根输入功能并配置匹配的格式，默认是关闭的。

接人脸相机​

人脸设备常接 身份证阅读器（也属于读卡感应类，但是 13.56MHz 的高频 RFID，输出多为 RS232/USB），用于人证核验。参见「1.3 人脸识别相机（A 系列）」「1.4 人脸识别相机（B 系列）」。

常见故障排查​

现象可能原因处理方法
完全读不到卡供电异常 / D0-D1 接反 / WG 格式不匹配 / 卡型不对测电压、对调 D0/D1、统一 WG 格式、确认 ID/IC
感应距离特别短背后有金属 / 电压不足 / 读头老化加绝缘垫、测末端电压、更换读头
读到的卡号不对WG26/34 不匹配 / 数据线受干扰统一格式、换屏蔽线、远离强电
读卡时好时坏接线松动 / 电源纹波 / 附近有干扰源重压端子、换电源、移开干扰源
蜂鸣器一直响BEEP 线极性/电平接错核对说明书接线定义
指示灯颜色不对LED 控制线接错核对接线
远距离读不到（超 80m）韦根传输距离超限改用 RS485 读头或加韦根转 485 模块
装了新读头老卡读不了ID/IC 制式买错更换对应频率的读头
户外读头进水失效防护等级不够更换 IP65 防水型、打防水胶
三步快速定位

  1. 看指示灯/蜂鸣：刷卡时读头本身有没有"嘀"一声或闪灯？

    • 没有 → 读头/卡片/供电问题
    • 有，但主板没反应 → 韦根线路或格式问题

  2. 换卡测试：换几张卡试，排除单张卡损坏

  3. 短路测试：把 D0 和 D1 分别对 GND 短接一下，主板若有反应说明线路通，问题在读头；无反应说明线路断或主板设置错

安全提示​

危险
  • ID 卡极易复制，任何涉及收费、权限的项目都应升级到 IC 卡或 CPU 卡
  • IC 卡默认密钥（如 Mifare 的 FFFFFFFFFFFF）必须修改，否则等同明文
  • 读卡器供电要独立，不要和电机、LED 屏共用开关电源
  • 户外读头要定期检查防水胶是否老化开裂
  • 卡片授权信息要定期清理，离职人员、过期月卡的卡片及时注销
