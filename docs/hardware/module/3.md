## 什么是语音播放模块

:::tip
语音播放模块负责把文字或预设内容变成**人声从喇叭里播出来**，是出入口设备与车主交互的关键部件。

典型播报内容：
- 「欢迎光临」
- 「车牌识别成功，请入场」
- 「临时车，请缴费」
- 「月卡车，有效期至 2026 年 12 月 31 日」
- 「一路平安」
- 「非机动车禁止通行」
:::

## 三种技术方案

| 方案 | 原理 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| **TTS 合成** | 文字实时合成语音 | **任意内容都能播**，无需预录 | 音质略机械、成本高一点 | 需要播报车牌号、金额、日期 |
| **预录语音（语音芯片）** | 播放烧录好的固定音频 | 音质好、成本极低 | **内容固定，改不了** | 只播固定提示语 |
| **串口 MP3 模块** | 从 TF 卡读取音频文件播放 | 可换文件、音质好 | 要提前准备音频文件 | 内容定期更新的场合 |

:::info
停车场**主流是 TTS**，因为车牌号、停车时长、缴费金额都是**动态内容**，预录语音根本存不完。

多数车牌识别一体机内部已集成 TTS 模块，只需通过串口/网络把文本发过去即可。
:::

## TTS 模块技术参数

以市面上常见的中文 TTS 模块为例：

| 参数 | 常见取值 |
|------|----------|
| 控制接口 | **UART TTL 串口**（最主流）／部分支持 RS485、I2C、SPI |
| 默认波特率 | **9600 bps**（可配置为 19200/38400/57600/115200） |
| 串口格式 | 1 起始位 + 8 数据位 + 无校验 + 1 停止位（8-N-1） |
| 电平 | 3.3V TTL ／ 5V TTL（**务必确认，接错会烧**） |
| 文本编码 | **GB2312 / GBK**（部分支持 UTF-8、UNICODE） |
| 单次合成文本量 | 2KB ~ 4KB（约 1000~2000 汉字） |
| 音量等级 | 4 级 / 10 级 / 31 级（按型号） |
| 语速等级 | 3 级 / 10 级 |
| 内置音效 | 5~15 种提示音、警示音、铃声 |
| 音频输出 | DAC 模拟输出（需外接功放）／内置功放直推喇叭 |
| 直推喇叭能力 | 典型 **4Ω 3W** ／ **8Ω 1.5W** ／ 16Ω 1W |
| 工作电压 | 3.6V ~ 5.5V（部分 2.6V ~ 5.5V 宽压） |
| 工作电流 | 合成时 80~120mA，休眠小于 20μA |
| 工作温度 | -40℃ ~ +85℃（工业级） |

:::warning[最关键的两个参数：波特率和编码]
现场 90% 的语音故障出在这两个参数上：
- **波特率不匹配** → 收不到指令，完全无声
- **编码不匹配**（模块要 GB2312，你发了 UTF-8）→ 播出来是**乱码或读不出字**

调试时先确认这两项。
:::

## 引脚与接线

### 典型引脚

| 引脚 | 功能 | 说明 |
|------|------|------|
| VCC / V | 电源正极 | 注意是 5V 还是 3.3V |
| GND / G | 电源负极 | 必须与主控**共地** |
| RX / R | 串口接收 | 接主控的 **TX** |
| TX / T | 串口发送 | 接主控的 **RX**（状态回传用，可省略） |
| SPK+ / SPK- | 喇叭输出 | 差分输出，不分正负也可响但建议按标识接 |
| BUSY | 忙状态指示 | 播放中为低电平，空闲为高电平（部分型号相反） |

:::danger
- **RX 接 TX、TX 接 RX**，交叉连接，接反了没声音
- **必须共地**：主控和语音模块的 GND 要连在一起，否则串口电平无参考，通信失败
- 5V 主控的 TX 接到 3.3V 模块的 RX，建议**串联 2kΩ 电阻**限流保护
- 喇叭线要**短而粗**，远离信号线，否则会引入干扰杂音
- 电源端并联 **100μF 电解电容**，避免播放瞬间电压跌落导致模块复位
:::

## 功放与喇叭选型

| 场景 | 推荐 | 说明 |
|------|------|------|
| 室内岗亭、桌面提示 | 模块直推 4Ω 3W 喇叭 | 无需额外功放 |
| 出入口户外一体机 | **外接功放 + 8Ω 10W 号角喇叭** | 环境噪声大，需要更大音量 |
| 大型车场、嘈杂路段 | 外接 15~20W 功放 + 号角喇叭 | 保证 5m 外能听清 |

:::tip
- **喇叭阻抗**：4Ω / 8Ω 最常见。阻抗越低，同电压下功率越大，但也越容易过载
- **功放功率要匹配喇叭**：功放功率过大容易烧喇叭，一般取喇叭额定功率的 1.2~1.5 倍
- 户外喇叭必须选**防水号角喇叭**，普通纸盆喇叭淋雨即坏
- 喇叭安装位置**朝向车内**，避免声音朝天空散射
:::

## 常见控制指令（通用模式）

不同厂家协议不同，但思路一致。以串口指令为例：

| 功能 | 实现方式 |
|------|----------|
| 播放文本 | 直接发送文本内容，发什么播什么 |
| 设置音量 | 发送特定指令帧，如 `[v5]` 表示 5 级音量 |
| 设置语速 | 发送特定指令帧，如 `[s3]` 表示 3 级语速 |
| 播放内置音效 | 发送音效编号，如发送 `0` 播放 0 号音效 |
| 停止播放 | 发送停止指令帧 |
| 查询状态 | 发送查询帧，模块回传忙/闲 |
| 多音字纠正 | 用标记语法，如 `空[=tiao2]调` |
| 数字读法 | 用标记语法，如 `[n2]100` 读作"一百" |

:::info
部分模块支持**上电提示音**，默认开启。如果觉得每次上电都"叮"一声很烦，可以发指令关闭。
:::

## 与车牌识别相机/主板对接

### 方式一：相机内置语音

:::tip
多数车牌识别一体机内置 TTS + 功放，只需要在相机 Web 后台：
1. 开启「语音播报」功能
2. 编辑播报模板（支持变量，如 `{车牌}` `{金额}` `{时长}`）
3. 设置音量、语速、播报次数
4. 测试播报
:::

### 方式二：外接语音模块（RS485）

:::info
接线：相机的 RS485 口（A/B）接语音模块的 485 接口。

注意点：
- 485 是**总线**，A 接 A、B 接 B，不能反
- 总线上所有设备的**波特率、校验位必须一致**
- 总线两端加 **120Ω 终端电阻**（距离超过 100m 时）
- 多台语音模块要注意**地址区分**（部分模块支持地址码）
:::

### 方式三：IO 触发固定语音

:::tip
某些简单场景只需要播固定内容（如「禁止通行」），可以用主板的一个**继电器输出**去触发语音模块的播放引脚。

优点：接线简单、不依赖通信协议；缺点：内容固定。
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| **完全无声** | 波特率不对 / TX-RX 接反 / 未共地 / 供电异常 | 逐项核对串口参数、交叉接线、共地、测电压 |
| **播报乱码或读不出字** | 文本编码不匹配 | 主控侧改为 **GB2312/GBK** 编码输出 |
| **声音很小** | 音量等级低 / 功放功率不足 / 喇叭阻抗不匹配 | 调高音量、换功放、核对阻抗 |
| **有杂音/电流声** | 电源纹波大 / 喇叭线太长 / 与强电平行走线 | 换优质电源、缩短喇叭线、远离强电 |
| **播放时模块重启** | 电源功率不足，播放瞬间电压跌落 | 加大电源功率、并联 100μF 电容 |
| **只播第一句，后面的不播** | 未等待上一条播完（BUSY 忙） | 读 BUSY 引脚，空闲后再发下一条；或开启队列 |
| **数字读法错误**（如 100 读"一零零"） | 未使用数字读法标记 | 用 `[n2]` 一类标记指定读法 |
| **多音字读错**（如"银行"读成 yin xing） | 未做多音字标记 | 用标记语法指定拼音 |
| 播报延迟大 | 文本太长 / 波特率太低 | 缩短文本、提高波特率到 115200 |
| 户外喇叭半年就坏 | 用了非防水喇叭 | 更换 IP65 防水号角喇叭 |

:::tip[三步定位法]
1. **测硬件**：模块单独接 USB 转串口，用电脑串口助手发一段中文文本。能响 → 模块和喇叭正常，问题在对接；不响 → 查波特率、接线、供电。
2. **测协议**：电脑发文本能响，但接相机不响 → 查相机侧串口参数、编码、485 地址。
3. **测内容**：能响但内容不对 → 查播报模板变量、编码、多音字标记。
:::
