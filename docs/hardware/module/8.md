## 什么是 WiFi 无线模块

:::tip
WiFi 无线模块在停车场设备里主要承担三类任务：

1. **调试通道**：设备自身生成一个 WiFi 热点，手机连上后用浏览器/小程序配置参数（最常见）
2. **无线组网**：两个设备之间、或设备到路由器之间用 WiFi 替代网线，解决无法布线的问题
3. **无线桥接**：跨越道路、广场把两端的网络打通

:::warning
**重要定位**：WiFi 模块适合**调试和临时替代**，不建议作为车场主干通信。车牌识别和道闸控制是实时业务，WiFi 的延迟抖动、掉线、干扰会直接影响通行效率。
:::

## 三种工作模式

| 模式 | 说明 | 典型应用 |
|------|------|----------|
| **AP 模式** | 模块自己作为热点，其他设备连它 | 相机/雷达上电后手机连热点调试 |
| **STA 模式** | 模块作为终端，去连已有的路由器 | 相机通过 WiFi 接入车场网络 |
| **AP + STA 共存** | 同时做热点又连路由器 | 既能调试又能联网，多数新款支持 |

:::info
判断方法：手机 WiFi 列表里能搜到设备热点 → 设备工作在 AP 模式；搜不到但设备能上网 → STA 模式。

很多设备默认是 AP 模式，配完 STA 参数后自动切换到 STA，此时热点消失。如果发现配完网热点没了，就是这个原因。
:::

## 技术参数

| 参数 | 常见取值 |
|------|----------|
| 频段 | 2.4GHz（绝大多数）／部分支持 5GHz |
| 协议 | 802.11 b/g/n（部分支持 ac） |
| 速率 | 150Mbps（2.4G 单流）／300Mbps（双流） |
| 发射功率 | 15~20dBm |
| 接收灵敏度 | -70dBm ~ -95dBm |
| 空旷传输距离 | 50m ~ 200m（2.4G） |
| 穿墙能力 | 一堵砖墙衰减约 10~15dB |
| 供电 | DC3.3V / DC5V / DC12V（按模块型号） |
| 接口 | UART / USB / SPI / SDIO / RJ45（网桥型） |
| 天线 | 板载 PCB 天线 / 外接 IPEX 天线 / 外置棒状天线 |
| 工作温度 | -20℃ ~ +70℃（工业级 -40℃ ~ +85℃） |

## 典型应用场景

### 一、设备调试热点（最常用）

:::tip
现在多数相机、雷达、控制主板都内置 WiFi 调试功能：

1. 设备上电，等待 20~40 秒
2. 手机搜索 WiFi，找到设备热点（命名规则通常是**品牌名或设备类型 + 序列号**）
3. 输入默认密码（常见如 `12345678`、`123456789`、`admin123`，以机身标签为准）
4. 手机浏览器访问管理地址（常见 `192.168.1.1` / `192.168.4.1` / `10.10.10.1`）
5. 在页面里配置参数
6. **保存后断电重启生效**

:::warning
调试完成后，如果设备支持关闭热点，**建议关闭**。长期开启热点会：
- 增加功耗和发热
- 占用无线信道，干扰车场其他 2.4G 设备
- 存在被他人连入修改参数的安全风险
:::

### 二、无线网桥（跨路传输）

:::info
**适用场景**：出入口在道路两侧、中间无法开挖布线；或者广场两端的设备需要联网。

做法：两端各装一台**室外无线网桥**（带定向天线），一对一对射，把网络从一端桥接到另一端。

选型要点：
- 必须选**室外型**，防护等级 IP65 以上
- 距离 100m 以内可用 2.4G 全向；超过 300m 或要求稳定，用 **5.8G 定向**
- **两点之间必须视距可见**，中间不能有树、广告牌、建筑物遮挡
- 网桥要可靠接地和**防雷**
:::

### 三、临时替代网线

:::warning
调试期间临时用 WiFi 让相机联网，确认功能没问题后**务必改回有线**。

只适用于**工期紧张、临时验证**的场合，正式交付不建议用 WiFi 传输车牌识别数据。
:::

## 2.4GHz 信道与干扰

| 信道 | 说明 |
|------|------|
| 1 / 6 / 11 | **互不重叠的三个信道**，优先使用 |
| 2 / 3 / 4 / 5 | 与 1 和 6 都有重叠，避免使用 |
| 7 ~ 10 | 与 6 和 11 重叠，避免使用 |
| 12 / 13 | 部分国家/设备不支持，国内可用但兼容性差 |

:::tip
车场里 2.4G 干扰源非常多：
- 其他 WiFi 路由器、手机热点
- 蓝牙设备（同样占用 2.4G 频段）
- 无线监控摄像头、无线门铃
- 微波炉、无线鼠标
- 部分 LED 屏的无线控制卡

**排查方法**：用手机装一个 WiFi 分析 App（如 WiFi Analyzer），看现场哪个信道最干净，把设备固定到该信道。
:::

## 信号强度参考

| 信号强度（RSSI） | 评价 | 表现 |
|------------------|------|------|
| -30dBm ~ -50dBm | 极好 | 满速、稳定 |
| -50dBm ~ -65dBm | 良好 | 正常使用 |
| -65dBm ~ -75dBm | 一般 | 偶发卡顿、重传 |
| -75dBm ~ -85dBm | 差 | 频繁掉线、速度极低 |
| 低于 -85dBm | 不可用 | 基本连不上 |

:::warning
车场设备要求**持续稳定**，建议保证信号强度**优于 -65dBm**，并留 10dB 以上余量（因为雨雪天气、车辆遮挡都会导致信号衰减）。
:::

## 安装与布线注意事项

:::danger
- **天线不要贴在金属面上**：金属会严重屏蔽信号，天线应与金属保持 5cm 以上距离
- **不要把 WiFi 模块放进金属机箱**：金属机箱是完全屏蔽的，必须把**天线引到机箱外**
- 天线不要与电源线、电机线平行走线，避免干扰
- 室外天线接头必须做**防水处理**（自粘胶带 + 热缩管）
- 网桥必须**可靠接地并加防雷器**，雷击是网桥损坏的头号原因
- 供电线径要够，WiFi 发射瞬间电流较大，线损会导致模块反复重启
:::

## 与 4G 模块怎么选

| 维度 | WiFi 模块 | 4G 模块（见 3.1） |
|------|-----------|------------------|
| 网络来源 | 依赖本地局域网 | 走运营商蜂窝网络 |
| 覆盖范围 | 几十到几百米 | 有信号就能用 |
| 月租成本 | 无 | **有流量费** |
| 带宽 | 高 | 受信号影响 |
| 延迟 | 低 | 较高（几十到几百毫秒） |
| 适用 | 场内组网、调试 | 远端联网、无宽带点位 |

:::tip
选择建议：
- 车场**有宽带**，只是某个点位布线困难 → 用 **WiFi 网桥**
- 点位**完全没有网络基础设施**（如偏远路内停车）→ 用 **4G 模块**
- 只需要**近距离调试**，不需要长期联网 → 用设备自带的 **WiFi 热点**
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 手机搜不到设备热点 | 上电未完成 / 热点已关闭 / 距离太远 | 等待 40s、重启设备、靠近到 5m 内 |
| 能连上热点但打不开页面 | IP 地址不对 / 手机没关移动数据 | 查说明书确认管理地址、**关闭手机 4G/5G 数据** |
| 连上就断、反复重连 | 信号弱 / 信道干扰 / 供电不足 | 靠近测试、换信道、测供电电压 |
| STA 模式连不上路由器 | SSID/密码错 / 路由器 MAC 过滤 / 5G 频段不支持 | 核对密码、关闭 MAC 过滤、确认路由器开 2.4G |
| 网桥时好时坏 | 中间有遮挡 / 天线移位 / 风雨影响 | 重新对准、加固支架、检查防水 |
| 网桥雷雨后损坏 | 未接地、未加防雷 | 加装防雷器、可靠接地 |
| 模块发热严重、死机 | 供电不足 / 散热不良 / 长时间满负荷 | 加大电源功率、改善散热 |
| 车场多个设备互相干扰 | 都在同一信道 | 错开到 1/6/11 |

:::info[排查口诀]
**搜不到看供电，连不上看地址，时好时坏看信号，全都不行看干扰。**

先用手机在设备旁边 1m 处测试：如果近距离正常、远距离不行，就是信号/干扰问题；如果距离很近都不行，就是设备或配置问题。
:::
