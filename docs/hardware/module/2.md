# 3.2 4G道闸模块

4G 道闸模块通过移动网络与云端通信，配合微信小程序 **闸机调试助手** 实现道闸的远程开闸、关闸、状态查看，以及主板参数的读取与修改。适合现场没有网络布线、又不便派人到现场调参的场景。

:::tip[模块定位]
- **联网**：模块自身走 4G 上网，不依赖车场本地宽带，不用布网线。
- **远程控制**：手机小程序远程开闸、关闸、停止。
- **远程调参**：在小程序里直接改主板 P 码参数，不用到现场按键调菜单。
- **状态回传**：实时查看电压、电流、电机状态、地感状态、闸杆位置等。
:::

## 一、创建账号

模块首次使用需要先在后台建立车场账号，账号由技术人员开通，不能自行注册。

### 1.1 扫码进入小程序

用微信扫描模块机身（或随货资料）上的小程序码，进入 **闸机调试助手**。

<div className="doc-img-single">

![闸机调试助手小程序码](/img/module/qr-code.png)

</div>

### 1.2 联系技术人员开通账号

进入小程序后联系对接的技术人员，提供以下三项信息，由技术人员在后台创建账号并分配车场权限：

| 需提供信息 | 说明 |
|-----------|------|
| 车场名称 | 用于建立项目，名称要与实际车场对应，便于后期查找 |
| 联系人 | 该车场的日常对接人姓名 |
| 联系电话 | 用于账号绑定及后续问题回访 |

:::warning[注意]
账号是按**车场**分配的，一个车场一个账号。同一车场下的多台设备都挂在同一个账号里，不要重复建号。
:::

账号开通后即可用该手机号登录小程序，进入设备管理界面。

## 二、添加设备

账号建立完成后，把模块绑定到账号下，才能看到设备并操作。

### 2.1 进入添加设备

登录小程序后进入 **首页**，页面会显示当前项目下的设备统计（道闸总数、在线数、故障数），点击 **添加设备**。

<div className="doc-img-single">

![小程序首页与添加设备入口](/img/module/app-home.jpg)

</div>

首页几个区域的含义：

| 区域 | 说明 |
|------|------|
| 顶部项目名 | 当前所在的车场项目，可点右侧「切换项目」切换 |
| 设备统计卡片 | 分别显示设备总数、在线台数、故障台数 |
| 添加设备 | 绑定新模块的入口 |
| 更多功能 | 蓝牙调试、使用说明、工程锁 |

### 2.2 扫描模块二维码

点击 **添加设备** 后调起扫一扫，**扫描模块机身上的二维码**完成绑定。

:::tip[绑定要点]
- 二维码在模块**机身背面/侧面标签**上，扫码时注意对准、避免反光。
- 一台模块只能绑定到一个账号下，已绑定的模块重复扫码不会重复添加。
- 绑定成功后设备会直接出现在设备列表中。
:::

### 2.3 设备列表

绑定完成后进入 **设备列表**，可按状态筛选查看设备。

<div className="doc-img-single">

![设备列表](/img/module/device-list.jpg)

</div>

| 筛选项 | 说明 |
|--------|------|
| 全部 | 显示账号下所有设备 |
| 在线设备 | 当前在线的模块 |
| 离线设备 | 断电或 4G 信号中断的模块 |
| 故障设备 | 主板回报故障状态的设备 |

每条设备记录显示设备名称、所在位置，以及 **在线**、**正常** 两个状态标签，右侧为编辑与删除按钮。

## 三、设备状态与操作

在设备列表中点击某台设备，进入 **道闸设置** 页面。

<div className="doc-img-single">

![道闸设置与设备状态](/img/module/device-status.jpg)

</div>

### 3.1 设备状态信息

页面顶部是主板实时回传的运行数据：

| 字段 | 含义 |
|------|------|
| 设备类型 | 当前设备类型（道闸） |
| 主板型号 | 所接主板的型号 |
| 程序版本 | 主板固件版本号 |
| 当前电压 / 当前电流 | 主板实时供电电压与电机电流 |
| 电机状态 | 电机运行是否正常 |
| 累计运行 | 该设备累计开关闸次数 |
| 地感状态 | 地感线圈检测是否正常 |
| 通行状态 | 正常模式 / 高峰模式等 |
| 闸杆位置 | 开到位 / 关到位 / 运行中 |
| 更新时间 | 该条状态数据的刷新时间 |
| 指令来源 | 本次动作的触发来源（遥控 / 通讯指令等） |

:::tip[排障用法]
现场报"道闸不动"时，先看这一屏：

1. **当前电压**是否在 24V 附近 —— 偏低说明供电或电源故障。
2. **电机状态**是否正常 —— 异常多为霍尔线或电机问题。
3. **地感状态**是否一直有信号 —— 持续有信号会导致关闸不响应。
4. **闸杆位置 / 通行状态**是否卡在高峰模式。
:::

### 3.2 设备控制

页面显示 **（已连接！）** 表示手机已与模块建立通信，可直接下发控制指令：

| 按钮 | 作用 |
|------|------|
| 开闸 | 远程发送开闸信号 |
| 关闸 | 远程发送关闸信号 |
| 停止 | 立即停止当前动作 |
| 遥控清码 | 清空主板已学习的所有遥控器 |
| 车队模式 | 开启车队模式，连续多车依次通过 |
| 解除车队 | 退出车队模式 |
| 进入遥控学习 | 主板进入遥控对码状态 |
| 退出遥控学习 | 退出遥控对码状态 |

:::warning[注意]
远程控制前请确认现场无人员、车辆在闸杆下方，避免误动作造成砸车或伤人。
:::

### 3.3 更多功能

页面底部提供四个入口：

| 入口 | 说明 |
|------|------|
| 常用设置 | 日常高频参数（开/关闸速度、减速区等） |
| 高级设置 | 全部主板参数与高级控制命令 |
| 一键批量设置 | 一次把相同参数下发到多台设备 |
| 故障记录 | 查看主板记录的历史故障 |

## 四、主板参数设置（高级设置）

点击 **高级设置** 进入 **道闸配置** 页面。

### 4.1 高级控制

页面顶部为一次性命令按钮：

| 按钮 | 作用 |
|------|------|
| 开启老化 / 关闭老化 | 开启或关闭老化测试模式 |
| 禁止操作 | 锁定设备，禁止一切动作指令 |
| 解除禁止 | 解除锁定状态 |
| 设备重启 | 远程重启模块/主板 |
| 参数初始化 | 参数恢复到出厂默认值 |

:::warning[安全提示]
「参数初始化」「设备重启」会中断当前运行状态，请在设备空闲、闸杆处于静止状态时执行。初始化后所有参数需要按现场情况重新设置。
:::

### 4.2 常用参数（小程序端）

下列参数以滑块 + 加减按钮方式调节，参数名称与主板菜单一致：

| 参数 | 名称 | 说明 |
|------|------|------|
| P0 | 开闸速度 | 数值越大开闸越快，数值越小越慢 |
| P1 | 关闸速度 | 数值越大关闸越快，数值越小越慢 |

:::info[取值范围说明]
小程序端速度类参数以界面显示的滑块范围为准（例如 P0 为 5~500）；主板按键菜单里的对应参数范围可能不同，两者以其中一个为准设置即可，不必同时改。
:::

## 五、现场操作补充

以下几项为现场用主板按键或遥控器进行的操作，与小程序配合使用。

### 5.1 恢复出厂设置

长按「确定」按键，显示 `-.-.-` 后按 **上 → 下 → 上 → 下 → 上 → 下**（三次以上），再按「确定」键，然后断电重新上电即可恢复出厂设置。

### 5.2 遥控对码与清码

1. 长按「遥控对码」按键 2-3 秒进入该界面，按遥控器上任意按钮：听到短「滴」表示配对成功，听到长「滴」表示该遥控已存在。总共可配 250 对遥控。
2. 在该界面下长按「上键」或「下键」，可清空所有遥控码。
3. 短按「遥控对码」键退出学习状态，**退出设置界面后遥控才会生效**。

### 5.3 高峰模式

道闸开到位后，长按遥控器「停」按键 6 秒，道闸进入高峰模式（显示 `ooo`）：检测到地感过闸信号后不落闸，只有再次收到遥控「关」信号才取消高峰模式并落闸。

:::tip[小程序端对应操作]
设备控制页的 **车队模式 / 解除车队** 即为高峰模式的远程开关方式，无需到现场按遥控器。
:::

## 六、常见故障与处理

主板通过数码管显示故障代码，小程序「故障记录」中也会留痕。

| 代码 | 故障定义 | 原因分析与处理 |
|------|----------|----------------|
| E-1 | 硬件过流保护 | 电机电流超过硬件承载能力。① 检查道闸上/下弹簧平衡度，不平衡则调节弹簧松紧或更换弹簧；② 检查控制板 |
| E-2 | 电机故障 | 霍尔线未接或接触不良。① 检查霍尔线接触；② 检查电机 U/V/W 接线；③ 以上正常则检查电机或控制板 |
| E-3 | 长时间堵转或电机卡住 | 多为道闸上下限位设置问题，机械限位在设定位置之前导致闸机未到位而堵转。① 调节「开/关闸位置」，往运行区间调节；② 检查闸杆是否被卡住 |
| E-4 | 进入高峰模式 | 开闸信号按下超过 6 秒所致，按「下」键可清除高峰模式 |
| E-5 | 关闸未响应，地感保护 | 地感一直有信号。① 地感死机则按复位键或断电重启；② 检查地感线圈是否接触不良或损坏；③ 仍不能排除则更换控制板验证 |
| E-6 | 关闸未响应，防砸保护 | 防砸信号一直存在。① 检查红外/雷达是否被物体挡住，清除遮挡物，若否检查传感器电源；② 检查压力波传感器是否被压住；③ 以上均正常则检查控制板 |
| E-7 | 低电压保护 | 控制器供电电压偏低。① 检查供电电源电压（空载与正常负载下）；② 电源正常则检查控制板 |

## 七、日常维护

1. 定期检查各端子接触情况，保障连接牢固。
2. 检查接地是否良好。
3. 使用前仔细检查供电是否正确。
4. 4G 模块长期离线时，先确认现场是否有 4G 信号覆盖，再检查模块供电。
