## 什么是蓝牙调试模块

:::tip
蓝牙调试模块是设备内部的一个**近距离无线通信接口**，安装/维护人员用**手机（微信小程序或 App）**连上设备的蓝牙，就能在不拆机、不接电脑、不需要网络的情况下：

- 查看设备状态和运行参数
- 修改相机识别区域、灵敏度
- 配置网络（把 WiFi 账号密码"灌"给设备）
- 配置雷达检测框
- 查看日志、升级固件
- 手动开闸、测试语音

**核心价值：站在梯子上用手机就能调完，不用搬电脑拉网线。**
:::

## 为什么停车场设备都在用蓝牙调试

| 传统调试方式 | 痛点 |
|-------------|------|
| 电脑 + 网线直连 | 要带电脑、要爬梯子接网线、相机在杆顶很麻烦 |
| 设备热点（WiFi） | 连上热点后手机**断网**，查不了资料；部分手机自动切回 4G 导致断连 |
| 串口线 | 要拆机、要带 USB 转串口、要装驱动 |
| **蓝牙调试** | **手机连蓝牙不影响上网**，小程序即用即走，站在地面就能调 |

:::info
**蓝牙的最大优势：连着蓝牙的同时手机还能正常上网。**
连 WiFi 热点时手机会断网，想边查说明书边调试就很痛苦；蓝牙不会占用手机的数据连接。
:::

## 技术参数

| 参数 | 常见取值 |
|------|----------|
| 蓝牙版本 | BLE 4.0 / 4.2 / 5.0 / 5.2 |
| 工作频段 | 2.4GHz ISM（与 WiFi 同频段，会互相干扰） |
| 发射功率 | 0dBm ~ 4dBm（BLE 低功耗） |
| **有效距离** | **空旷 10~30m；建议调试时保持在 5m 以内** |
| 连接方式 | 微信小程序（主流）/ 专用 App |
| 配对方式 | 免配对直接连 / 输入 PIN 码（常见 0000、1234） |
| 数据速率 | 1Mbps（BLE 4.x）/ 2Mbps（BLE 5.x） |
| 功耗 | 极低，常驻不影响设备运行 |
| 安全性 | 部分支持连接认证、指令加密 |

:::warning[距离是硬伤]
BLE 是低功耗设计，穿墙能力弱。**隔着机箱金属外壳信号会衰减 10~20dB**。

调试时如果连不上，**先靠近到 1~2m 内再试**，这是最常见的原因。
:::

## 典型应用场景

### 一、相机调试（最常见）

:::tip
行业里已经有不少成熟的微信小程序方案，例如：
- **微信小程序调试工具** —— B 系列相机配套
- **另一款常用调试小程序** —— C 系列等相机配套
- 各相机厂商自有小程序（A 系列、C 系列等均有）

典型功能：
- 搜索附近设备的蓝牙信号并连接
- 实时预览相机画面
- **拖动调整识别区域框**
- 设置灵敏度、补光灯、曝光
- 配置 WiFi/4G 网络参数
- 手动触发开闸测试
- 查看设备序列号、固件版本
:::

### 二、雷达/传感器调试

毫米波雷达、地磁车位检测器普遍支持蓝牙调参：画检测框、设灵敏度、看实时距离曲线。参见「4.2 雷达毫米波防砸」。

### 三、主板/道闸调试

部分新款道闸控制主板支持蓝牙：设置抬杆速度、落杆延时、防砸参数、学习遥控器。

### 四、设备配网（最常用的功能）

:::info
**蓝牙配网**是现在最主流的设备入网方式：

1. 手机打开小程序，搜索设备蓝牙
2. 连上后在小程序里输入车场的 **WiFi 名称和密码**
3. 小程序通过蓝牙把 WiFi 凭据下发给设备
4. 设备自动重启并连上 WiFi
5. 小程序显示"配网成功"

这比早期的"设备开 AP 热点 → 手机连热点 → 浏览器配置"方式**简单太多**，也是蓝牙调试模块最大的价值。
:::

## 使用流程（通用）

:::tip
1. **准备**：手机上打开蓝牙、开启定位权限（**Android 必须开定位才能扫蓝牙**）
2. **打开小程序**：微信搜索对应品牌的小程序
3. **搜索设备**：点击"搜索设备"/"添加设备"，等待列表出现
4. **连接**：点击设备名称（一般显示为**设备类型 + 序列号后几位**）
5. **认证**（如需要）：输入配对码，常见 `0000` / `1234` / `123456`
6. **调试**：进入功能页面，读取参数、修改、保存
7. **断开**：调试完成后退出，长时间不用建议关闭手机蓝牙
:::

:::warning[Android 的权限坑]
**Android 6.0 以上系统，扫描蓝牙需要开启"位置信息（GPS）"。**

很多人搜不到设备就是因为没开定位。这不是小程序要你的位置，是系统层面的限制。
:::

## 与 WiFi 调试的对比

| 维度 | **蓝牙调试** | WiFi 热点调试 |
|------|-------------|--------------|
| 手机是否断网 | **不断网** | 断网（连热点后无互联网） |
| 连接速度 | 快（1~3 秒） | 慢（10~20 秒） |
| 有效距离 | **5~10m** | 20~50m |
| 传输带宽 | 低（无法流畅看视频） | 高（可看实时视频流） |
| 稳定性 | 高 | 易被手机自动切走 |
| 是否需要密码 | 多数免密或简单 PIN | 需要输入 WiFi 密码 |
| 适合 | **调参数、配网、看状态** | **看画面、导录像、升级大固件** |

:::info
**最佳实践：蓝牙配参数 + WiFi 看画面。**

先用蓝牙把网络配好，再通过网络用电脑/手机浏览器看实时画面做精细调整。两者互补，不冲突。
:::

## 安全与建议

:::warning
- **调试后及时断开**：蓝牙长期开启存在被附近人连接修改参数的风险
- **部分设备支持"关闭蓝牙广播"**：交付验收后建议关闭，需要时再打开（部分设备长按复位键可临时开启）
- **修改参数前先截图记录原值**：改坏了能还原
- **不要把配对码写在设备外壳上**：容易被外人利用
- 修改网络参数后设备会重启，**确认车场此时不需要通行**，或提前挂"设备维护中"提示牌
:::

## 常见故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| **搜索不到设备** | 未开定位权限（Android）/ 距离太远 / 蓝牙被占用 | 开定位、靠近到 1~2m、关闭手机已连的其他蓝牙设备 |
| **搜到了但连不上** | 配对码错 / 已被其他手机占用 / 设备蓝牙卡死 | 核对配对码、**让其他人先断开**、设备断电重启 |
| **连上就断** | 手机系统省电限制 / 距离边缘 / 2.4G 干扰 | 关省电模式、靠近、远离 WiFi 路由器 |
| **读不到参数** | 小程序版本旧 / 固件版本不匹配 | 更新小程序、升级设备固件 |
| **配网失败** | WiFi 密码错 / 路由器是 5G 频段 / 开启了 MAC 过滤 | 核对密码、**确认路由器开了 2.4G**、关闭 MAC 过滤 |
| **配网成功但设备不在线** | WiFi 信号弱 / 路由器隔离了 AP | 改善信号、关闭 AP 隔离 |
| **小程序闪退** | 微信版本旧 / 手机内存不足 | 更新微信、清理内存 |
| iOS 能连 Android 不能 | Android 权限/机型兼容 | 检查定位权限、更换测试手机 |
| 设备蓝牙一直广播 | 未关闭广播 | 在设置里关闭蓝牙广播或联系厂家确认 |

:::tip[排查口诀]
**搜不到→开定位、靠近；连不上→让别人先断开；配网失败→查 2.4G 和密码。**

遇到疑难，最有效的一招是：**设备断电 30 秒重启**，大部分蓝牙卡死问题都能解决。
:::
